# 数学物理方法：按问题补工具

数学物理方法不是一门必须先全部学完才能接触声学的前置课程。它是用来回答“声场如何随时间和空间变化”“边界为何改变解”“周期结构为何会筛选频率”的工具箱。

## 工具与触发问题

| 数学工具 | 何时需要它 | 在声学中的作用 |
|---|---|---|
| 复数、欧拉公式与相量 | 出现正弦稳态、幅值和相位 | 简洁表示振动、阻抗和相位差 |
| 常微分方程 | 学受迫振动、阻尼和共振 | 求一个振子的响应 |
| 偏微分方程与分离变量法 | 出现波动方程、管道或腔体边界 | 求声压在空间中的分布 |
| 傅里叶级数与傅里叶变换 | 出现频谱、周期信号和叠加 | 在频率域理解声音与谐波 |
| 复变函数 | 导师指定的超构材料建模需要出现时 | 处理二维势函数、保角映射或特定解析方法 |

## 重要边界

导师提到复变函数对其超构材料方向重要，这很可能对应组内特定的二维声场、结构映射或解析建模方法；它不意味着所有声学超构材料问题都必须先掌握完整复变函数理论。看到组内的具体论文后，再确定应该学到哪一层。

与医学超声相比，超声中更常直接面对传播方程、波束和介质问题；但两条方向都会用到复数、微分方程和傅里叶思想。
