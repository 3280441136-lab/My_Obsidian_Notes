# 声学学习项目约定

当用户说“继续声学学习”“查看学习项目”或讨论本目录中的声学资料时，先阅读：

1. `README.md`
2. `00_项目状态.md`
4. `08_交接日志/` 中日期最新的日志（如存在）

工作原则：

- 用户自己决定每天学到哪里；不要创建按天、按周或按时长的学习计划。
- 以“理解声学超构材料、线性与非线性声学”为目标选择声学基础和数学物理方法内容；习题只用于验证理解，不把笔记写成应试提纲。
- 对话中的解释优先于笔记。必须先把问题讲清楚，再将已确认的理解、待解问题和双语术语更新到项目笔记中。
- 用户明确说“写交接日志”、准备开新对话或上下文不足时，才创建交接日志并更新项目状态；不要为每一次对话自动写日志。
- 输出 Markdown 笔记时，面向 Obsidian：行内数学使用 `$...$`，独立公式必须使用 `$$` 块。需要空间关系、波形或结构图时，创建或更新 `10_图示/` 中可嵌入的 SVG；只有交互确有价值时才创建 HTML。禁止 ASCII 绘图。
- Codex 聊天回复保留行内数学公式：行内公式使用 LaTeX 的 `\(...\)`，独立公式使用 `$$...$$`。不要用 Unicode 数学记号替代公式。输出 Obsidian Markdown 文件时，仍遵循上一条规定，行内公式使用 `$...$`，独立公式使用 `$$...$$`。
