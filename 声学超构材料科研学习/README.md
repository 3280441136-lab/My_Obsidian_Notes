# 声学科研学习项目

这是一个以理解为中心的长期学习档案。它服务于你探索声学超构材料，同时保留医学超声与消费音频的交叉视角；它不是刷题计划，也不替你决定每天学到哪里。

![[声学研究路径.svg|655]]

## 当前背景

- 导师团队有声学超构材料和医学超声两个方向；导师本人能在前者提供更直接的指导，并表达过保研推荐和组内培养的意愿。
- 当前优先探索声学超构材料，但尚未把研究生方向永久锁定。
- 目标是建立可迁移的声学、数学物理、实验与信号处理理解；若未来转向消费音频，仍需额外学习 DSP、自适应滤波与实时实现。

## 项目如何工作

对话是学习发生的地方，笔记只是复习与续接的工具。每次讨论后，只把以下内容写入相应笔记：已经讲清的理解、仍然卡住的具体问题、首次出现的重要术语，以及与资料页码或图号相关的线索。

笔记是对话的产物，而不是对话的替代品。每轮讨论先在对话中把问题讲清楚，再把已经形成的理解、仍待澄清的问题和必要术语写入笔记；随着讨论推进，允许重写、重组和删除旧表述，不把笔记机械地做成只增不减的流水账。

新对话开始时，只要说明“继续声学学习项目”，即可先读取本 README、[项目状态](00_项目状态.md)、[双语术语表](05_术语表/双语术语表.md)和最新交接日志，再从上次的位置继续。文件能保存学习脉络，但不会替代你在新对话中说明当下想读哪一页或想问什么。

只有你明确说“写交接日志”、表示准备开新对话，或指出上下文已不够时，才会新增一份交接日志，并更新项目状态。

## 笔记与图示规范

- 笔记以中文解释为主；英文只保留论文中的术语、缩写和必要原文。
- 术语的重点是“对应什么物理现象、结构或测量量”，不止是英汉翻译。
- 独立数学公式统一写成 LaTeX 块，例如：

$$
Z_{\mathrm a}=\frac{p}{u}
$$

- 当仅靠文字不足以解释波传播、腔体结构、相位或因果关系时，优先在 `10_图示/` 增加 SVG 并嵌入笔记；需要交互探索时才补充 HTML。
- 不使用 ASCII 字符画图。
