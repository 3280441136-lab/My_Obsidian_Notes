# COMSOL Projects Local Instructions

`04_COMSOL_Projects/` 只承担两个用途：

1. 集中保存 COMSOL 项目文件；
2. 作为 Codex APP 中持续进行 COMSOL 仿真学习和项目对话的子项目目录。

不要把这里扩展成通用声学笔记目录。声学学习笔记仍放在 `../01_学习笔记/`，统一图示仍放在 `../03_图示/`。

## 使用的 COMSOL 环境

- COMSOL Multiphysics 版本：`6.4.0.429`
- 操作界面：简体中文
- 官方文档目录：`D:\00_Software\COMSOL\COMSOL64\Multiphysics\doc`

回答 COMSOL 问题时，必须使用已安装的 `comsol-simulation-guide` skill。官方本地文档优先于记忆、网络资料和经验猜测。

## 指导模式与全自动模式

根据用户请求选择模式，不要自行把普通提问升级为自动操作：

- 用户说“教我”“指导我”“我想自己做”“解释为什么”“告诉我怎么点”时，进入指导模式，只解释中文界面操作、物理设置和验证方法，不使用 COMSOL MCP 修改或求解模型。
- 用户明确说“全自动”“直接帮我建模并计算”“不要我手点”“跑完整个扫描”时，才使用 COMSOL MCP 执行。
- 用户明确要求“边做边教”时，使用混合模式：先说明物理问题、关键假设和将要修改的内容，再执行已授权的自动化，最后解释结果。
- COMSOL MCP 未安装、未连接或缺少所需能力时，明确说明，不伪造自动化结果。
- 新项目放在独立子目录中。除非用户明确指定要修改的 `.mph` 文件，否则不覆盖已有模型文件。

## 回答标准

- 不编造 COMSOL 6.4 的菜单路径、物理场节点、边界条件、求解器选项或版本行为。
- 使用用户实际看到的中文界面名称；需要检索官方文档时，可附英文原名。
- 将物理模型、COMSOL 设置、数值验证分开说明。
- 对完全初学者先解释为什么这样设置，再给操作步骤，并说明每一步的检查方法。
- 遇到报错时，优先索取或读取准确的中文报错、警告、求解日志和模型树状态，不凭模糊症状猜原因。
- 不替用户编译 Keil 或 ESP 项目。

## 文件与公式格式

- COMSOL 模型、项目数据和项目说明保存在各自项目子目录中。
- 用于笔记或项目说明的结果图按 `../03_图示/` 规则管理。
- Codex 聊天中，行内公式使用 `\(...\)`，独立公式使用 `$$...$$`。
- Obsidian Markdown 文件中，行内公式使用 `$...$`，独立公式使用 `$$...$$`。
