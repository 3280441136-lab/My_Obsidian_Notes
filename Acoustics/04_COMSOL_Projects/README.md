# COMSOL Projects

这里保存正在进行的 COMSOL 仿真项目。目前处于学习和建立仿真项目管理方式的阶段。

## 文件归属

- 每个独立模型或实验使用一个子目录，例如 `04_COMSOL_Projects/项目名称/`。
- COMSOL 模型文件、配套数据、参数记录和项目说明保存在对应项目子目录中。
- 只有需要嵌入学习笔记或项目说明的结果图才提取到 `03_图示/`：
  - 矢量图示放入 `03_图示/SVG/`
  - COMSOL 导出图或截图放入 `03_图示/位图/`
  - PDF 页面图或页面裁图放入 `03_图示/PDF页面图/`
- 不创建 `tmp/` 或其他平行素材目录。

## 项目说明建议

每个项目子目录可包含一份简短说明，记录：

- 仿真想回答的物理问题；
- 几何、材料、边界条件和激励；
- 网格与求解器设置；
- 结果图对应的观测量；
- 当前尚未验证的假设或错误。

COMSOL 项目用于理解声学问题和验证物理图像，不把参数堆叠当作学习笔记。
