# 声学科研学习项目

这是一个以理解为中心的长期学习档案，用来持续探索声学超构材料，同时保留医学超声与消费音频的交叉视角。项目不制定按天、按周或按时长的学习计划；每次学到哪里由你决定。

## 当前背景

- 导师团队有声学超构材料和医学超声两个方向；导师本人能在声学超构材料方向提供更直接的指导，并表达过保研推荐和组内培养的意愿。
- 当前优先探索声学超构材料，但尚未把研究生方向永久锁定。
- 目前也在学习 COMSOL 仿真，相关模型与项目文件统一保存在 `04_COMSOL_Projects/`。
- 目标是建立可迁移的声学、数学物理、实验、仿真与信号处理理解；若以后转向消费音频，再补充 DSP、自适应滤波与实时实现。

## 如何续接学习

对话是学习发生的地方，笔记只保存已经讲清的理解、仍待解决的问题、必要概念和资料定位。新对话开始时，如需续接，请先阅读：

1. 本 `README.md`
2. [项目状态](02_项目管理/项目状态.md)
3. `02_项目管理/交接日志/` 中日期最新的交接日志（如存在）

只有明确说“写交接日志”、准备开新对话或指出上下文不足时，才新增交接日志并同步更新项目状态。

## 笔记写法

- 笔记面向 Obsidian，以连续、教材式解释为主，不写成术语表、公式清单或问答卷。
- 先把问题在对话中讲清，再写入已经确认的理解；允许重写、合并和删除旧表述。
- 专业概念第一次出现时，用通俗语言说明它解决什么问题，再给出严格定义。
- 公式必须解释变量、物理对象、使用场景和适用条件；公式不能代替解释。
- 重要结论要交代适用范围和容易误用的地方，并用少量连续例子连接概念。
- 不使用 ASCII 字符画图。

## 数学公式格式

Markdown 笔记中，行内公式使用 `$...$`，独立公式使用 `$$...$$`。例如：

$$
Z_{\mathrm a}=\frac{p}{u}
$$

其中 $p$ 为声压，$u$ 为质点速度，$Z_{\mathrm a}$ 为声阻抗。

## 图示与页面图

`03_图示/` 是所有图片资产的统一入口：

- `03_图示/SVG/`：用于解释空间关系、波形、结构和因果链的可嵌入 SVG。
- `03_图示/位图/`：绘图导出、截图或需要保留的位图。
- `03_图示/PDF页面图/`：从学习资源中提取或截取的页面图，用于定位阅读线索。

需要空间关系、波形或结构图时，优先创建或更新 SVG；只有交互确有价值时才创建 HTML。所有已使用的图片都保存在 `03_图示/` 中，不再保留 `tmp/`。

## 原始学习资源

`声学科研学习资源/` 中的 PDF、书籍和材料由你放入，作为只读的原始资料。笔记只记录阅读位置、理解与待解问题，不改动原始文件；PDF 的注解或元数据文件与原文件一起保留。
