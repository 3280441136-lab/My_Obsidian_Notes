# 微机原理与单片机接口技术：教材课后习题详解（期中范围）

范围说明：本文件对应主教材第 1 章至第 6.2 节。第 1~5 章课后习题全部纳入；第 6 章课后习题中，1~10、22~25 和简答 1~4 属于中断系统范围，详细解析；11~21 和简答 5~9 属于 6.3 定时/计数器内容，保留题号并给简要答案，标注为超出严格期中范围。

## 习题 1

### 一、选择题

**1. 世界上第一个微处理器型号是？**

答案：A，Intel 4004。

解析：Intel 4004 是 1971 年推出的 4 位微处理器，通常被认为是世界上第一款商用微处理器。286、386 都是后来的 x86 系列处理器，8051 是单片机。

**2. 8086 微处理器是几位微处理器？**

答案：C，16 位。

解析：8086 的内部数据通路和通用寄存器宽度为 16 位，外部数据总线也是 16 位，所以称为 16 位微处理器。

**3. 微处理器取指令是从哪里获取的？**

答案：C，存储器。

解析：程序以机器码形式存放在存储器中。CPU 执行程序时，先根据 PC/IP 给出的地址到存储器取指令，再译码、执行。

**4. 51 单片机是几位单片机？**

答案：B，8 位。

解析：51 单片机的 CPU 一次主要处理 8 位数据，累加器 A、B 寄存器、P0~P3 端口都是 8 位。PC、DPTR 是 16 位，不改变其 8 位机属性。

**5. PDIP40 封装的 8051 芯片，接地引脚和电源引脚编号分别是？**

答案：C，20、40。

解析：8051 的 20 脚为 GND，40 脚为 VCC。这个题直接考引脚图，不要和 8086 的 GND 1/20 脚混淆。

**6. 51 单片机引脚的高、低逻辑电平分别是？**

答案：B，+5V、0V。

解析：传统 51 单片机使用 5V 逻辑，高电平约 +5V，低电平约 0V。

**7. 51 单片机的可执行文件是？**

答案：D，`*.hex`。

解析：`.c` 是 C51 源文件，`.asm` 是汇编源文件，`.obj` 是编译/汇编后的目标文件，真正下载或烧写到单片机中执行的一般是 `.hex` 文件。

### 二、简答题

**1. 什么是微处理器？微处理器由几部分组成？微处理器的工作过程是什么？**

答案：微处理器是由大规模或超大规模集成电路构成的、具有运算和控制功能的处理器芯片。基本组成包括运算器、控制器、寄存器组、内部总线，以及与外部连接的数据线、地址线、控制/状态线等。

解析：微处理器工作的核心就是执行指令。基本过程为：取指令、译码、取操作数、执行运算、回送结果，然后继续取下一条指令。初学时要抓住 PC 的作用：它给出下一条指令的地址。

**2. 简述 Intel 公司生产的几种不同微处理器的功能特性。**

答案：Intel 4004 是早期 4 位微处理器；8080 是 8 位微处理器；8086 是 16 位微处理器；8088 内部接近 8086，但外部数据总线为 8 位；80286 仍属于 16 位处理器；80386 发展到 32 位；Pentium 系列进一步提高主频、流水线和多媒体处理能力。

解析：这题不是要求背完整年代，而是理解处理器发展趋势：位数变宽、主频提高、集成度提高、寻址能力和处理能力增强。

**3. 什么是单片机？单片机控制系统由哪几部分组成？**

答案：单片机是把 CPU、存储器、I/O 接口、定时/计数器、中断系统等集成在一块芯片上的微控制器。单片机控制系统通常由单片机芯片、电源电路、时钟电路、复位电路、输入电路、输出驱动电路和被控对象组成。

解析：单片机不是单独的 CPU。它的特点是片内集成了完成控制任务所需的基本资源，所以适合按键、LED、数码管、蜂鸣器、电机等控制场景。

**4. 简述单片机设计开发的常用工具。**

答案：常用工具包括 Keil C51 集成开发环境、Proteus 仿真软件、编程器/下载器、仿真器和硬件实验板。

解析：Keil 主要用于写程序、编译、生成 HEX；Proteus 主要用于画原理图并仿真；编程器或下载器负责把 HEX 文件写入芯片。

**5. 简述 51 单片机与 52 单片机的主要区别。**

答案：52 类单片机是在 51 类基础上的增强型，通常程序存储器和数据存储器容量更大，并增加一个定时/计数器，部分型号中断源也更多。

解析：考试中常用表格比较：51 常见为 4KB ROM、128B RAM、2 个定时器、5 个中断源；52 常见为 8KB ROM、256B RAM、3 个定时器、6 个中断源。

### 三、简述 51 单片机的开发流程

答案：一般流程为：明确功能需求，设计硬件电路，编写 C51 或汇编源程序，建立 Keil 工程，选择芯片型号，加入源文件，设置生成 HEX，编译排错，使用 Proteus 或实验板仿真验证，最后把 HEX 文件下载到单片机中运行。

解析：这题考的是从“想做什么”到“单片机真正运行”的链条。源程序本身不能直接运行，必须经过编译/链接生成机器码文件。

### 四、熟悉 Keil C51 和 Proteus 设计环境

答案：Keil C51 用于程序开发，主要操作包括新建工程、选择器件、添加源文件、编译、生成 HEX。Proteus 用于电路绘制和仿真，主要操作包括放置单片机和外围元件、连线、加载 HEX、运行仿真。

解析：掌握这题的关键是区分软件角色：Keil 解决“程序怎么写、怎么变成 HEX”；Proteus 解决“电路怎么连、程序运行效果是否符合预期”。

## 习题 2

**1. 8086 CPU 由哪两部分组成？它们的主要功能是什么？**

答案：8086 CPU 由 BIU（总线接口单元）和 EU（执行单元）组成。

解析：BIU 负责与外部总线打交道，包括取指令、读写存储器/I/O、形成 20 位物理地址、维护 6 字节指令队列。EU 负责指令译码和执行，包括 ALU 运算、通用寄存器操作、有效地址计算和标志位更新。BIU 和 EU 分工使取指和执行可以部分重叠，提高效率。

**2. 8086 CPU 在最大工作模式和最小工作模式下有什么相同点和不同点？**

答案：相同点是 CPU 内部结构和指令执行本质相同，都通过地址、数据、控制总线访问存储器和 I/O。不同点是系统规模和控制信号产生方式不同：最小模式用于单处理器小系统，`MN/MX` 接 VCC，8086 自己产生主要总线控制信号；最大模式用于多处理器或协处理器系统，`MN/MX` 接地，8086 输出状态信号，由 8288 等总线控制器产生控制信号。

解析：最小模式看成“8086 自己管总线”；最大模式看成“8086 只给状态，由外部总线控制器统一管理”。考试常问 `MN/MX` 引脚接法。

**3. 简述 8086 微处理器的存储器分段技术，举例说明物理地址和逻辑地址的关系。**

答案：8086 有 20 根地址线，可寻址 1MB 空间，但内部多数寄存器为 16 位。为得到 20 位物理地址，8086 采用分段方式：逻辑地址由“段地址:偏移地址”构成，物理地址 = 段地址 × 10H + 偏移地址。

解析：例如 `CS=2000H, IP=0100H`，则取指物理地址为：

```text
2000H × 10H + 0100H = 20100H
```

段寄存器 CS、DS、SS、ES 分别对应代码段、数据段、堆栈段和附加段。分段不是把内存物理切成固定块，而是一种地址形成方法。

**4. 简述 8086 CPU 的时钟周期、总线周期和指令周期三者的关系。**

答案：时钟周期是 CPU 工作的最小时间单位；总线周期是 CPU 完成一次总线操作所需时间，通常由 T1、T2、T3、T4 等时钟状态组成，必要时插入等待周期 Tw；指令周期是执行一条指令所需时间，可包含一个或多个总线周期，也可能不发生外部总线访问。

解析：三者从小到大理解：时钟周期构成总线周期，总线周期参与构成指令周期。不同指令复杂度不同，所以指令周期不固定。

**5. 简述 8086 CPU 在最小工作模式下存储器读操作时序。**

答案：存储器读总线周期大致过程为：T1 输出地址，ALE 有效使外部锁存器锁存地址；随后 `M/IO` 指示访问存储器，`RD` 变低表示读；存储器把数据送上数据总线；CPU 在合适时刻采样数据；最后 `RD` 变无效，总线周期结束。如果外设或存储器未准备好，READY 无效时 CPU 插入等待周期。

解析：核心信号是地址、ALE、`M/IO`、`RD`、READY 和数据总线。要特别理解 AD0~AD15 复用：T1 是低 16 位地址，后面才是数据。

## 习题 3

### 一、选择题

**1. 51 单片机的 CPU 是几位？**

答案：C，8 位。

解析：51 的基本运算和数据通路以 8 位为主。

**2. 51 单片机 CPU 的主要功能有哪些？**

答案：A、C、D 较符合教材语境，即产生控制信号，进行算术、逻辑和位操作，并控制 I/O 数据传输。

解析：CPU 的核心是运算器和控制器。存储数据主要由存储器完成，CPU 内部寄存器只暂存数据。

**3. 51 单片机 CPU 的主要组成部分为？**

答案：A，运算器、控制器。

解析：CPU 的两大基本功能部件就是运算器和控制器。

**4. 对于 8031 单片机，EA 引脚总是？**

答案：A，接地。

解析：8031 无片内程序存储器，必须从片外程序存储器取指令，所以 EA 应接低电平。

**5. 在 51 单片机中，中间计算结果通常放在？**

答案：D，数据存储器。

解析：程序存储器主要放程序和常量；中间变量和运行结果通常放在内部 RAM 等数据存储器中。

**6. 51 单片机的程序计数器 PC 用来？**

答案：C，存放下一条执行的指令地址。

解析：PC 指向下一条将要取出的指令。转移、调用、中断、返回都会改变 PC。

**7. 51 单片机的应用程序一般存放在？**

答案：B，ROM。

解析：程序代码放在程序存储器中，传统教材常称 ROM。

**8. 51 单片机复位后，工作寄存器 R0 在？**

答案：A，0 区 00H 单元。

解析：复位后 PSW=00H，RS1=0、RS0=0，选择第 0 组工作寄存器，R0 对应 00H。

**9. 51 单片机的进位标志 CY 在？**

答案：C，程序状态字寄存器 PSW。

解析：CY 是 PSW.7，既是进位标志，也是位处理器中的位累加器。

**10. XTAL1 和 XTAL2 引脚用于？**

答案：D，外接晶振。

解析：这两个脚连接晶体振荡器和电容，为单片机提供时钟源。

**11. 51 单片机复位后，PC 与 SP 的值分别为？**

答案：B，0000H、07H。

解析：复位后从程序存储器 0000H 开始执行，堆栈指针 SP 初值为 07H。

**12. 并行口作输入用途之前必须？**

答案：A，相应端口先置 1。

解析：51 的 I/O 口为准双向口，读外部输入前先写 1，相当于释放引脚。

**13. 既可位寻址又可字节寻址的单元是？**

答案：A，20H。

解析：内部 RAM 的 20H~2FH 是位寻址区，也可按字节访问。30H、70H 只能字节访问；00H 属于工作寄存器区。

**14. 51 单片机片内 RAM 共有多少字节？**

答案：A，128。

解析：标准 8051 片内低 128B RAM 地址为 00H~7FH；80H~FFH 是 SFR 区，不按普通 RAM 理解。

**15. PSW 的 RS0、RS1 分别为 1 和 0 时，选择哪组工作寄存器？**

答案：B，组 1。

解析：寄存器组选择实际看 RS1 RS0。题目给 RS0=1、RS1=0，即 RS1 RS0=01，选择第 1 组，地址 08H~0FH。

**16. 内部 RAM 中可位寻址的地址空间是？**

答案：B，20H~2FH。

解析：这 16 个字节共 128 位，对应位地址 00H~7FH。

**17. PC 为 16 位计数器，其寻址范围是？**

答案：D，64K。

解析：16 位地址可表示 `2^16 = 65536` 个地址，即 64KB 程序空间。

**18. 唯一不能被用户直接修改内容的寄存器是？**

答案：C，PC。

解析：PC 不能用普通数据传送指令直接写入，只能通过转移、调用、中断、返回等改变。

**19. 4 个并行 I/O 端口作通用 I/O 输出时，必须外接上拉电阻的是？**

答案：A，P0 口。

解析：P0 为开漏结构，普通 I/O 输出高电平时需要外接上拉；P1、P2、P3 内部有上拉。

**20. ALE 引脚以晶振频率的多少输出固定频率？**

答案：C，1/6。

解析：ALE 可输出晶振频率 1/6 的脉冲，所以有时也可作外部定时脉冲参考。

**21. 外扩存储器时，低 8 位地址总线和 8 位数据总线由哪个口分时复用？**

答案：A，P0 口。

解析：P0 分时复用为 A0~A7 和 D0~D7。

**22. 外扩存储器时，高 8 位地址总线由哪个口提供？**

答案：C，P2 口。

解析：P2 输出 A8~A15。

**23. 51 单片机位处理器的累加器是？**

答案：B，PSW 寄存器的 CY 位。

解析：位操作中，CY 常作为位数据的暂存和运算核心。

### 二、填空题

**1. 51 单片机存储器分为哪两种？**

答案：程序存储器和数据存储器。

解析：51 采用程序空间和数据空间分开的结构。

**2. 内部 RAM 低 128 单元按用途划分为哪 3 个区域？**

答案：工作寄存器区、位寻址区、用户 RAM 区。

解析：00H~1FH 为工作寄存器区，20H~2FH 为位寻址区，30H~7FH 为用户 RAM 区。

**3. 晶振 12MHz 与 6MHz 时，一个机器周期分别为多少？**

答案：12MHz 时 1us；6MHz 时 2us。

解析：传统 8051 一个机器周期为 12 个时钟周期。`12/12MHz=1us`，`12/6MHz=2us`。

**4. 复位电路有哪两种？**

答案：上电复位和手动复位。

解析：上电复位利用电容充放电形成复位脉冲，手动复位通过按键产生复位信号。

**5. 复位信号持续多长高电平以上可完成复位？**

答案：2 个机器周期以上。

解析：RST 高电平有效，保持足够长时间才能使内部寄存器恢复到规定初值。

### 三、简答题

**1. 什么是时钟周期、状态周期、机器周期和指令周期？24MHz 时一个机器周期多长？最长指令需要多长时间？**

答案：时钟周期是晶振周期；状态周期为 2 个时钟周期；机器周期为 6 个状态周期，即 12 个时钟周期；指令周期是执行一条指令所需时间，通常为 1~4 个机器周期。24MHz 时，一个机器周期为 `12/24MHz=0.5us`，最长 4 机器周期指令约为 2us。

解析：这题本质是时间单位换算。传统 51 的关键比例是：1 机器周期 = 12 时钟周期。

**2. 复位有效时，P0~P3、PC、DPTR、SP、ACC、PSW 内容是什么？复位能否改变内部 RAM 内容？**

答案：P0~P3=FFH，PC=0000H，DPTR=0000H，SP=07H，ACC=00H，PSW=00H。复位不改变内部 RAM 单元内容。

解析：端口复位为 FFH 表示端口锁存器为 1；PC=0000H 表示复位后从程序入口开始执行；SP=07H 表示第一次 PUSH 写入 08H。

**3. 51 单片机有多少个特殊功能寄存器？哪些既可字节操作又可位操作？**

答案：标准 8051 有 21 个特殊功能寄存器。地址能被 8 整除的 SFR 通常可位寻址，如 P0、TCON、P1、SCON、P2、IE、P3、IP、PSW、ACC、B 等。

解析：SFR 位于 80H~FFH 区，不是所有地址都有寄存器，也不是所有 SFR 都能位寻址。

**4. 51 单片机有几根 I/O 线？它们与地址总线、数据总线有什么关系？**

答案：有 4 个 8 位并行 I/O 口，共 32 根 I/O 线。外扩存储器时，P0 分时复用为低 8 位地址线和 8 位数据线，P2 作高 8 位地址线，P3.6/P3.7 可作外部数据存储器写/读控制线。

解析：普通 I/O 和总线复用是 51 引脚的重点。P0、P2 在外扩存储器时不再只是普通端口。

**5. P0~P3 口在结构上有何异同？**

答案：四个口都是 8 位并行 I/O 口，都可作为准双向口使用。不同点是 P0 为开漏结构，普通 I/O 输出高电平需外接上拉；P1 主要作普通 I/O；P2 可作高 8 位地址线；P3 各位有第二功能，如串口、中断、定时计数输入、外部数据存储器读写控制。

解析：考试常把 P0 的上拉、P2 的高地址、P3 的第二功能放在一起考。

**6. 外扩存储器时，为什么只能由 P0 作数据总线，P0 和 P2 作地址总线？**

答案：因为 51 外扩存储器需要 16 位地址和 8 位数据。P0 设计为地址/数据复用口，先输出 A0~A7，再作为 D0~D7 数据总线；P2 输出 A8~A15。P0 上的低 8 位地址由 ALE 控制外部锁存器锁存。

解析：P0 之所以能同时承担地址和数据，是分时复用，不是同一时刻既当地址又当数据。

## 习题 4

### 一、选择题

**1. 下列叙述不正确的是？**

答案：C。

解析：C 程序可以由一个或多个函数组成，必须包含一个 `main()` 主函数，函数是 C 程序的基本组成单位。注释可以单独成行，也可以放在语句后面，不能说只能位于一条语句后面。

**2. C 程序总是从哪里开始执行？**

答案：A，主函数。

解析：C/C51 程序入口是 `main()`。

**3. 最基本的 C 语言语句是？**

答案：B，表达式语句。

**1. 按键 S1 每按下一次，流水灯 D1~D8 的流动方向改变一次。**

参考程序：

```c

#include <intrins.h>

sbit KEY = P1^0;

void delay_ms(unsigned int ms)
{
    unsigned int i, j;
    for (i = 0; i < ms; i++)
        for (j = 0; j < 123; j++);
}

void main(void)
{
    unsigned char led = 0xfe;
    bit dir = 0;

    P2 = led;
    KEY = 1;

    while (1) {
        if (KEY == 0) {
            delay_ms(20);
            if (KEY == 0) {
                dir = !dir;
                while (KEY == 0);
            }
        }

        delay_ms(100);
        if (dir == 0)
            led = _crol_(led, 1);
        else
            led = _cror_(led, 1);
        P2 = led;
    }
}
```

解析：`led=0xfe` 表示低电平点亮时先点亮一端 LED。按键采用低电平有效，检测到按下后延时消抖，再翻转方向变量 `dir`。`_crol_` 和 `_cror_` 实现循环左移/右移。

**2. 8 个数码管动态显示 00000000，每隔 1s 全部加 1，到 99999999 后回到 00000000。**

参考程序：

```c
#include <reg51.h>

unsigned char code seg[10] =
    {0x3f,0x06,0x5b,0x4f,0x66,0x6d,0x7d,0x07,0x7f,0x6f};
unsigned char code bit_sel[8] =
    {0xfe,0xfd,0xfb,0xf7,0xef,0xdf,0xbf,0x7f};

unsigned char num[8] = {0,0,0,0,0,0,0,0};

void delay_ms(unsigned int ms)
{
    unsigned int i, j;
    for (i = 0; i < ms; i++)
        for (j = 0; j < 123; j++);
}

void display_once(void)
{
    unsigned char i;
    for (i = 0; i < 8; i++) {
        P0 = seg[num[i]];
        P2 = bit_sel[i];
        delay_ms(1);
        P2 = 0xff;
    }
}

void add_one(void)
{
    signed char i;
    for (i = 7; i >= 0; i--) {
        num[i]++;
        if (num[i] < 10) break;
        num[i] = 0;
    }
}

void main(void)
{
    unsigned int t;
    while (1) {
        for (t = 0; t < 125; t++)
            display_once();
        add_one();
    }
}
```

解析：动态显示必须不断刷新。`num[8]` 存 8 位数字，`display_once()` 扫描 8 位约 8ms，循环约 125 次接近 1s，然后加 1。实际端口和段码要按教材图中的共阴/共阳、位选有效电平调整。

### 二、简答题

**1. 8051 可以提供几个中断源？同一优先级中的优先顺序如何确定？**

答案：8051 提供 5 个中断源：INT0、T0、INT1、T1、串行口。若它们处于同一优先级，则按自然优先级响应：INT0 > T0 > INT1 > T1 > 串行口。

解析：IP 只能把中断源分成高、低两级；同一级内部仍按固定自然顺序排队。

**2. 与中断控制有关的特殊功能寄存器有哪些？**

答案：IE、IP、TCON、SCON。

解析：IE 控制允许/禁止；IP 控制优先级；TCON 保存外部中断和定时器中断标志及触发方式；SCON 保存串行口中断标志 RI、TI。

**3. 简述 51 单片机响应中断的过程。**

答案：中断源产生请求并置位相应标志；若该中断被允许且总中断 EA 打开，并且满足优先级条件，CPU 在当前指令结束后响应；硬件自动把断点地址压入堆栈；PC 转到对应中断入口；执行中断服务程序；服务程序最后执行 `RETI`，CPU 从堆栈弹出断点地址，返回主程序继续执行。

解析：硬件自动保护断点，但一般寄存器现场需要用户在中断服务程序中用 `PUSH/POP` 或编译器自动代码保护。

**4. 哪些中断在 CPU 响应后可自动撤除请求？不能自动撤除时应采取什么措施？**

答案：边沿触发的外部中断请求在 CPU 响应后由硬件自动清除；定时器 T0/T1 溢出中断标志在中断响应后也可由硬件清除。串行口 RI/TI 不能自动清除，需要在中断服务程序中用软件清零。电平触发外部中断的请求由引脚电平决定，必须在中断返回前撤除外部低电平，否则会再次申请中断。

解析：这题关键是区分“标志位由硬件清”与“外部信号仍保持有效”。电平触发若外部低电平不撤除，即使服务程序返回，也会再次进入中断。

| 5 | 标准 8051 有 T0、T1 两个可编程定时/计数器；工作方式由 TMOD 中 M1、M0 位选择 |

| 8 | 50Hz 方波周期 20ms，半周期 10ms；12MHz 下 10ms 为 10000 机器周期，方式 1 初值为 65536-10000=55536=D8F0H，TMOD 可取 01H |
| 9 | 方式 1 为 16 位计数，最多计数 65536 个机器周期 |
