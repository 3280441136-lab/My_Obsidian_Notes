# 微机原理与单片机接口技术期中学习资料：教材顺序详解版

适用范围：主教材第 1 章到第 6.2 节“单片机中断系统概述”；汇编部分补充教材中与 8086/8088、51 单片机寻址和指令有关的内容；往年期中卷、习题集、程序阅读填空资料中落在该范围内的题型。

这份资料按教材顺序写，不按“我觉得高频”乱跳。每章内部采用同一逻辑：

1. 先讲这章到底在解决什么问题。
2. 再讲教材中容易看不懂但考试会考的概念。
3. 把补充教材内容放到它真正对应的位置。
4. 最后放本章代表题，题目后给出推理过程。

## 第 1 章 微处理器技术简介

### 1.1 先把“微处理器、CPU、单片机”分清

如果完全没学过这门课，第一步不要急着背 8086 或 8051。先建立一个图景：所有这些芯片本质上都是“按程序处理数据的数字电路”。

微处理器是一个大类。CPU、MCU、DSP 都可以算微处理器的一种。课程里真正要学的是 CPU 和 MCU。

| 名称 | 初学者应该怎样理解 | 本课中的角色 |
|---|---|---|
| CPU | 只负责取指令、执行运算和控制总线，本身不是完整计算机 | 8086 是典型 CPU |
| MCU/单片机 | 把 CPU、存储器、I/O 口、定时器、中断等放进一块芯片 | 8051/89C51 是本课主体 |
| 微机系统 | CPU 加存储器、I/O 接口、时钟、复位、电源等构成的系统 | 理解 8086 和 51 的外部连接 |

单片机为什么适合控制？因为很多控制任务不是做复杂数学，而是“读一个输入，判断状态，控制一个输出”。比如按键、LED、数码管、电机、蜂鸣器。单片机自带 I/O 口，可以直接和这些外设连接。

### 1.2 CPU 执行程序的过程

教材说“取指令、译码、执行”，初学者容易觉得抽象。可以这样理解：

```text
程序存储器里放着一串机器码。
PC 告诉 CPU 下一条机器码在哪里。
CPU 取出机器码，译码器判断它代表什么动作。
如果动作需要数据，就去寄存器或存储器取数据。
ALU 或控制电路执行动作。
结果写回寄存器、存储器或 I/O 口。
PC 指向下一条指令。
```

所以 PC 的含义很重要：PC 通常保存“下一条将要执行的指令地址”。往年题问 PC 里装的是什么，答案不是“当前指令地址”，而是下一条指令地址。

### 1.3 引脚是什么，为什么教材总画芯片引脚图

芯片内部再复杂，也必须通过外部金属脚和外界通信。教材的引脚图不是装饰，它告诉你：

- 哪个脚接电源。
- 哪个脚接地。
- 哪些脚可以输入/输出数据。
- 哪些脚是控制信号，如读、写、复位、中断。
- 哪些脚有复用功能，同一个脚在不同场景承担不同任务。

考试不会让你画完整芯片，但会问重要引脚编号和作用。例如：

| 芯片 | 高频引脚 |
|---|---|
| 8051 | VCC 40 脚、GND 20 脚、RST 9 脚、PSEN 29 脚、ALE 30 脚、EA 31 脚、P3.2/INT0、P3.3/INT1 |
| 8086 | VCC 40 脚、GND 1/20 脚、AD0~AD15、A16~A19/S3~S6、BHE、MN/MX、RD、WR、ALE、READY、RESET、INTR、NMI |

### 1.4 51 单片机型号和开发流程

51 和 52 的区别可以简单抓住：

| 系列 | 程序存储器 | RAM | 定时器 | 中断源 |
|---|---:|---:|---:|---:|
| 51 类，如 8051/89C51 | 常见 4KB | 128B | 2 个 | 5 个 |
| 52 类，如 8052/89C52 | 常见 8KB | 256B | 3 个 | 6 个 |

开发流程的考试点很少，通常只考文件后缀：

```text
C51 源程序：.c
汇编源程序：.asm
可下载/烧录文件：.hex
```

### 1.5 本章代表题

**题 1：以下不是构成单片机的部件的是？**

A. LED 显示器  B. I/O 接口电路  C. 存储器  D. 微处理器 CPU

答案：A。

讲解：LED 是外接设备，不是单片机芯片内部组成。单片机内部至少包含 CPU、存储器和 I/O 接口。

**题 2：PDIP40 封装的 8051 芯片，接地引脚和电源引脚编号分别是什么？**

答案：GND 为 20 脚，VCC 为 40 脚。

讲解：教材第 1 章习题直接考过。40 脚双列直插封装中，20 脚接地，40 脚接 +5V。

**题 3：51 单片机的高、低逻辑电平分别是什么？**

答案：高电平约 +5V，低电平约 0V。

讲解：传统 51 是 5V TTL/CMOS 逻辑。题目不是问 RS-232，也不是问电源负压。

## 第 2 章 8086 微处理器及其体系结构

### 2.1 这一章在学什么

8086 是一个 CPU，不是完整计算机。它要工作，必须通过地址线、数据线、控制线去连接存储器和 I/O 设备。

本章要建立三个概念：

1. 8086 内部如何分工：BIU 负责总线，EU 负责执行。
2. 8086 外部如何连接：40 个引脚中有地址、数据、控制和电源。
3. 8086 如何访问内存/I/O：物理地址、存储器组织、I/O 寻址。

### 2.2 8086 的基本规格

| 项目 | 结论 | 为什么重要 |
|---|---|---|
| 数据宽度 | 16 位 | 可一次处理 16 位数据 |
| 地址线 | 20 根 | 可寻址 `2^20 = 1MB` 内存 |
| 数据线 | 16 根 | 数据总线 D0~D15 |
| 封装 | 40 引脚 DIP | 引脚图中有固定编号 |
| 逻辑结构 | BIU + EU | 往年填空直接考 |

### 2.3 BIU 和 EU

8086 内部分成两块是为了解决效率问题。取指令和执行指令可以部分重叠。

#### BIU：总线接口单元

BIU 的工作可以理解为“对外跑腿”：

- 从存储器取指令。
- 从存储器或 I/O 取操作数。
- 把结果写回存储器或 I/O。
- 形成 20 位物理地址。
- 维护 6 字节指令队列。

BIU 包含：

| 部件 | 作用 |
|---|---|
| CS、DS、SS、ES | 4 个段寄存器，保存段地址 |
| IP | 指令指针，保存下一条指令的偏移地址 |
| 20 位地址加法器 | `段地址*16 + 偏移地址` |
| 6 字节指令队列 | 预取指令，提高效率 |
| 总线控制电路 | 产生读写控制信号 |

#### EU：执行单元

EU 的工作可以理解为“真正执行指令”：

- 从指令队列取指令并译码。
- 通过 ALU 做算术/逻辑运算。
- 更新 FLAGS。
- 计算有效地址并交给 BIU。

EU 包含：

| 部件 | 作用 |
|---|---|
| ALU | 算术逻辑运算 |
| AX、BX、CX、DX | 数据寄存器 |
| SP、BP、SI、DI | 指针和变址寄存器 |
| FLAGS | 标志寄存器 |
| 控制电路 | 译码并发出内部控制信号 |

### 2.4 8086 寄存器详解

#### 数据寄存器 AX、BX、CX、DX

每个都是 16 位，也可以拆成高 8 位和低 8 位。

| 16 位 | 高 8 位 | 低 8 位 | 常见用途 |
|---|---|---|---|
| AX | AH | AL | 累加器，乘除、I/O 常用 |
| BX | BH | BL | 基址寄存器，常参与寻址 |
| CX | CH | CL | 计数器，LOOP 和移位常用 |
| DX | DH | DL | 数据寄存器，I/O 间接端口地址常用 |

例：

```asm
MOV AX, 1234H
```

执行后：

```text
AH=12H
AL=34H
AX=1234H
```

注意：`MOV AL, BX` 是错的，因为 AL 是 8 位，BX 是 16 位。

#### 指针和变址寄存器 SP、BP、SI、DI

| 寄存器 | 用途 |
|---|---|
| SP | 栈顶指针，默认配合 SS |
| BP | 基址指针，常访问栈中数据，默认配合 SS |
| SI | 源变址寄存器，串操作和数组寻址常用 |
| DI | 目的变址寄存器，串操作和数组寻址常用 |

含 BP 的内存寻址默认段是 SS；不含 BP 的大多默认 DS。

#### 段寄存器 CS、DS、SS、ES

8086 的地址线有 20 根，但寄存器大多只有 16 位。解决办法是“段地址 + 偏移地址”。

| 段寄存器 | 用途 |
|---|---|
| CS | 代码段，取指令 |
| DS | 数据段，普通数据 |
| SS | 堆栈段 |
| ES | 附加段，串操作目标等 |

物理地址公式：

```text
物理地址 = 段地址 × 10H + 偏移地址
```

例：`DS=2000H, BX=0100H`

```asm
MOV AX, [BX]
```

物理地址：

```text
2000H × 10H + 0100H = 20100H
```

#### FLAGS 标志寄存器：不要把它当成“附属知识”

8086 很多程序阅读题不是让你机械翻译指令，而是让你根据运算结果判断后续跳转。这个判断靠的就是 FLAGS。FLAGS 不是普通数据寄存器，它记录“刚才那次运算产生了什么状态”。

| 标志位 | 名称 | 初学者要抓住的含义 | 典型用途 |
|---|---|---|---|
| CF | Carry Flag，进位/借位 | 无符号运算超出范围时置 1；减法不够减也置 1 | 判断无符号大小、带进位加法 |
| PF | Parity Flag，奇偶 | 结果低 8 位中 1 的个数为偶数时置 1 | 较少考深 |
| AF | Auxiliary Carry | 低 4 位向高 4 位进位/借位 | BCD 调整 |
| ZF | Zero Flag，零标志 | 结果为 0 时置 1 | `JZ/JE` |
| SF | Sign Flag，符号 | 结果最高位为 1 时置 1 | 判断有符号数正负趋势 |
| TF | Trap Flag，陷阱 | 单步调试用 | 一般只知道存在 |
| IF | Interrupt Flag，中断允许 | IF=1 允许响应 INTR；IF=0 屏蔽 INTR | 中断题 |
| DF | Direction Flag，方向 | 串操作地址增减方向 | `CLD/STD` |
| OF | Overflow Flag，溢出 | 有符号运算结果超出范围时置 1 | 判断有符号溢出 |

最容易混的是 CF 和 OF：

```text
CF 看无符号运算：8 位数 255+1 超出 0~255，CF=1。
OF 看有符号运算：8 位有符号数 127+1 得到 80H，数学上应为 128，超出 -128~127，OF=1。
```

例：`AL=7FH`，执行 `ADD AL, 01H` 后：

```text
AL = 80H
CF = 0      ; 无符号 127+1=128，没有超过 255
OF = 1      ; 有符号 +127+1 溢出
SF = 1      ; 结果最高位为 1
ZF = 0      ; 结果不是 0
```

再例：`AL=0FFH`，执行 `ADD AL, 01H` 后：

```text
AL = 00H
CF = 1      ; 无符号 255+1 超过 255
ZF = 1      ; 结果为 0
OF = 0      ; 若按有符号，-1+1=0，不溢出
```

#### 做 8086 寄存器题的顺序

遇到寄存器题，不要一眼就算。按这个顺序：

1. 先看操作数宽度：8 位对 8 位，16 位对 16 位。
2. 再看操作数在哪里：立即数、寄存器、内存、I/O。
3. 如果访问内存，先确定默认段寄存器。
4. 如果是字数据，注意低地址给低字节。
5. 最后看是否影响 FLAGS，是否会改变跳转结果。

例如：

```asm
MOV AX, 1234H
MOV BL, AL
MOV AH, 56H
```

逐句：

```text
AX=1234H，所以 AH=12H，AL=34H。
BL=AL=34H。
AH=56H 后，AX=5634H，不是 1256H。
```

### 2.5 8086 引脚分布和重要引脚

8086 是 40 引脚芯片。教材图像里的重点不是让你把每个脚画出来，而是理解“哪些脚负责地址/数据，哪些脚负责控制”。

#### 8086 引脚图应该怎样读

DIP40 芯片从顶视图看，有缺口或圆点的一端作为上方。左侧从上到下是 1~20 脚，右侧从下到上继续数 21~40 脚；如果把右侧也按“从上到下”写出来，就会看到 40、39、38……21。教材图中左右两列不是随便摆的，它表达的是芯片封装的实际脚位。

下面把教材图转换成文字表。复习时至少要能根据这个表定位重要引脚在哪一组。

| 左侧从上到下 | 信号 | 右侧从上到下 | 信号 |
|---:|---|---:|---|
| 1 | GND | 40 | VCC |
| 2 | AD14 | 39 | AD15 |
| 3 | AD13 | 38 | A16/S3 |
| 4 | AD12 | 37 | A17/S4 |
| 5 | AD11 | 36 | A18/S5 |
| 6 | AD10 | 35 | A19/S6 |
| 7 | AD9 | 34 | BHE/S7 |
| 8 | AD8 | 33 | MN/MX |
| 9 | AD7 | 32 | RD |
| 10 | AD6 | 31 | HOLD / RQ/GT0 |
| 11 | AD5 | 30 | HLDA / RQ/GT1 |
| 12 | AD4 | 29 | WR / LOCK |
| 13 | AD3 | 28 | M/IO / S2 |
| 14 | AD2 | 27 | DT/R / S1 |
| 15 | AD1 | 26 | DEN / S0 |
| 16 | AD0 | 25 | ALE / QS0 |
| 17 | NMI | 24 | INTA / QS1 |
| 18 | INTR | 23 | TEST |
| 19 | CLK | 22 | READY |
| 20 | GND | 21 | RESET |

这张表有三个读法：

- 左上和左下都是 GND，右上是 VCC：这是芯片供电。
- 左侧 2~16 与右上 35~39 基本是地址/数据相关：这是 CPU 和存储器交换信息的通道。
- 右侧 21~34 集中是控制信号：复位、中断、读写、模式选择、锁存、总线方向都在这里。

#### 电源和地

| 引脚 | 名称 | 作用 |
|---:|---|---|
| 40 | VCC | +5V 电源 |
| 1、20 | GND | 接地 |

#### 地址/数据复用引脚

| 引脚范围 | 名称 | 作用 |
|---|---|---|
| AD0~AD15 | 地址/数据复用线 | T1 时输出低 16 位地址；T2~T4 时作为 16 位数据总线 |
| A16/S3~A19/S6 | 地址/状态复用线 | T1 时输出高 4 位地址；后续时钟输出状态信息 |

为什么要复用？因为芯片只有 40 个脚，如果地址线 20 根、数据线 16 根完全分开，再加控制线、电源脚，引脚会不够。复用的代价是外部需要锁存器把 T1 时刻的地址锁住。

具体到一次总线周期，可以这样看：

```text
T1：AD0~AD15 = 地址低 16 位，A16~A19 = 地址高 4 位。
    ALE 有效，外部锁存器把地址保存下来。
T2~T4：AD0~AD15 不再是地址，而是数据 D0~D15。
    RD 或 WR 指示这次是读还是写。
```

所以题目问“8086 为什么需要地址锁存器”，答案不是“因为教材这么画”，而是：AD 线分时复用，地址只在 T1 有效，后面会被数据占用。

#### `ALE` 的意义

| 引脚 | 名称 | 作用 |
|---:|---|---|
| 25 | ALE | 地址锁存允许，高电平有效，用于让外部锁存器锁存复用线上的地址 |

初学者要抓住一句话：`ALE` 是为了解决地址/数据复用后“地址很快会消失”的问题。T1 时 AD0~AD15 上是地址，后面变成数据，所以要趁 T1 把地址锁住。

#### `BHE` 和 A0

8086 数据总线 16 位，但也能访问字节。内存分为偶地址低字节体和奇地址高字节体。

| BHE | A0 | 操作含义 |
|---|---|---|
| 0 | 0 | 从偶地址开始读/写一个字，低 8 位和高 8 位都有效 |
| 1 | 0 | 只访问偶地址字节，D0~D7 有效 |
| 0 | 1 | 只访问奇地址字节，D8~D15 有效 |

若从奇地址读一个字，需要两个总线周期，因为一个字跨越了奇地址和下一个偶地址。

这部分的本质是“16 位数据总线如何兼容字节访问”。可以把 8086 的存储器想成两半：

```text
偶地址存储体：连接 D0~D7，用 A0=0 选中。
奇地址存储体：连接 D8~D15，用 BHE=0 选中。
```

因此：

```text
读偶地址字节：只用低 8 位总线。
读奇地址字节：只用高 8 位总线。
读偶地址字：低、高两半同时工作，一个总线周期完成。
读奇地址字：第一周期读奇地址高半，第二周期读下一个偶地址低半。
```

#### 工作模式控制 `MN/MX`

| 引脚 | 电平 | 模式 | 含义 |
|---|---|---|---|
| MN/MX | 接 VCC | 最小模式 | 系统中主要只有一个 8086，8086 自己产生控制信号 |
| MN/MX | 接 GND | 最大模式 | 多处理器/协处理器系统，需要 8288 总线控制器 |

#### 最小模式常考控制引脚

| 引脚 | 名称 | 有效电平 | 初学者解释 |
|---:|---|---|---|
| 32 | RD | 低有效 | CPU 正在读存储器或 I/O |
| 29 | WR | 低有效 | CPU 正在写存储器或 I/O |
| 28 | M/IO | 高为存储器，低为 I/O | 区分当前访问对象 |
| 24 | INTA | 低有效 | CPU 响应可屏蔽中断 |
| 27 | DT/R | 高发送、低接收 | 控制数据收发方向 |
| 26 | DEN | 低有效 | 允许数据收发器工作 |
| 31 | HOLD | 高有效 | 其他主设备请求占用总线 |
| 30 | HLDA | 高有效 | CPU 同意让出总线 |

#### 公共控制引脚

| 引脚 | 名称 | 作用 |
|---:|---|---|
| 22 | READY | 外设/存储器准备好，高有效；未准备好时 CPU 插入等待周期 |
| 21 | RESET | 复位，高有效，至少保持 4 个时钟周期 |
| 18 | INTR | 可屏蔽中断请求，高有效，受 IF 标志控制 |
| 17 | NMI | 非屏蔽中断，上升沿触发，不受 IF 控制 |
| 19 | CLK | 时钟输入 |
| 23 | TEST | 与 WAIT 指令配合使用 |

容易错点：INTR 是可屏蔽中断，NMI 是不可屏蔽中断。INTR 受 FLAGS 中 IF 位影响；NMI 不受 IF 影响。

### 2.6 存储器组织和小端

8086 每个存储单元是 8 位。一个 16 位字占两个连续地址。低字节放低地址，高字节放高地址，这叫小端。

例：

```text
[20100H] = 12H
[20101H] = 34H
```

执行：

```asm
MOV AX, [0100H]
```

若 `DS=2000H`，AX 读到的是：

```text
AL=12H
AH=34H
AX=3412H
```

### 2.7 8086 I/O 寻址

8086 的 I/O 端口和内存是分开的地址空间。访问 I/O 不能用普通 `MOV`，要用 `IN/OUT`。

```asm
IN  AL, 60H
OUT 60H, AL
IN  AL, DX
OUT DX, AL
```

端口地址若间接给出，必须放在 DX 中。这是往年填空题。

### 2.8 补充教材嵌入：8086 寻址方式

补充教材和程序阅读资料中大量考“这条指令的操作数在哪里”。寻址方式不是死背名字，而是看操作数来源。

| 寻址方式 | 例子 | 怎么判断 |
|---|---|---|
| 立即寻址 | `MOV AX, 1200H` | 数直接写在指令里 |
| 寄存器寻址 | `MOV AX, BX` | 操作数在寄存器里 |
| 直接寻址 | `MOV AX, [1200H]` | 内存偏移地址直接写出 |
| 寄存器间接寻址 | `MOV AX, [BX]` | 内存偏移地址在寄存器里 |
| 寄存器相对寻址 | `MOV AX, 1100H[BX]` | 寄存器 + 位移 |
| 基址变址寻址 | `MOV AX, [BX][SI]` | 基址 + 变址 |
| 相对基址变址寻址 | `MOV AX, 1100H[BX][SI]` | 基址 + 变址 + 位移 |

默认段规则：

| 有效地址中出现 | 默认段 |
|---|---|
| BX、SI、DI、直接地址 | DS |
| BP | SS |
| 串操作目的 DI | ES |

例：

```asm
MOV AX, ES:[BX]
```

寻址方式是寄存器间接寻址；`ES:` 只是段超越，不改变“偏移地址来自 BX”这个事实。

### 2.9 补充教材嵌入：8086 程序阅读

#### `LEA` 与 `MOV`

设 `TABLE` 偏移地址为 3400H，内存 `TABLE` 处内容为 0505H：

```asm
MOV AX, TABLE   ; AX = 0505H，取内容
LEA AX, TABLE   ; AX = 3400H，取偏移地址
```

`LEA` 是 Load Effective Address，只算地址，不访问内存内容。

#### 栈操作

8086 栈按字操作，栈向低地址增长。

```asm
PUSH AX   ; SP = SP - 2，然后把 AX 写到 SS:SP
POP AX    ; 从 SS:SP 读到 AX，然后 SP = SP + 2
```

例：`SP=1000H, AX=2000H, BX=3000H`

```asm
PUSH AX
PUSH BX
POP AX
```

结果：

```text
PUSH AX 后 SP=0FFEH
PUSH BX 后 SP=0FFCH
POP AX 后 AX=3000H, SP=0FFEH, BX=3000H
```

#### 移位和循环移位

| 指令 | 含义 |
|---|---|
| SHL/SAL | 左移，低位补 0 |
| SHR | 逻辑右移，高位补 0 |
| SAR | 算术右移，高位补符号位 |
| ROL/ROR | 不带 CF 的循环移位 |
| RCL/RCR | 带 CF 一起循环 |

例：`AL=0F2H, CF=0, CL=3`，执行 `RCL AL, CL`。

```text
初始：CF=0, AL=1111 0010
第1次：CF=1, AL=1110 0100
第2次：CF=1, AL=1100 1001
第3次：CF=1, AL=1001 0011
结果：CF=1, AL=93H
```

#### AAA 与 DAA

```asm
MOV AX, 4
ADD AL, 7
AAA
```

`AL=0BH`，低 4 位大于 9，`AAA` 调整为：

```text
AX = 0101H
```

若改为 `DAA`：

```text
AX = 0011H
```

`AAA` 用于非压缩 BCD/ASCII 加法调整；`DAA` 用于压缩 BCD 加法调整。考试不会让你写复杂原理，但会让你算结果。

### 2.10 本章代表题

**题 1：8086/8088 微机主要包括哪两个部分？**

答案：BIU 和 EU。

讲解：BIU 对外取指、读写总线；EU 对内译码、运算、执行。

**题 2：8086 的段寄存器有几个？分别是什么？**

答案：4 个，CS、DS、SS、ES。

讲解：它们保存段地址。物理地址由段地址左移 4 位再加偏移地址得到。

**题 3：`DS=2000H, BX=0100H, SI=0002H, [20102H]=56H, [20103H]=78H`，执行 `MOV AX, [BX][SI]` 后 AX 是多少？**

解：

```text
偏移地址 = BX + SI = 0102H
物理地址 = 2000H×10H + 0102H = 20102H
低地址给 AL，高地址给 AH
AX = 7856H
```

答案：`7856H`。

**题 4：判断指令是否错误并说明原因。**

```asm
MOV AL, BX
ADD [SI], [2000H]
POP AL
```

答案：

- `MOV AL, BX` 错，8 位和 16 位宽度不一致。
- `ADD [SI], [2000H]` 错，8086 普通双操作数指令不能两个操作数都在内存。
- `POP AL` 错，栈操作按字进行，不能 POP 到 8 位 AL。

**题 5：8086 的 AD0~AD15 为什么叫地址/数据复用线？ALE 的作用是什么？**

答案：AD0~AD15 在总线周期 T1 输出低 16 位地址，在 T2~T4 用作数据总线；ALE 用来通知外部锁存器在地址有效时把地址锁存下来。

讲解：如果没有 ALE 和锁存器，T1 之后 AD0~AD15 变成数据线，外部存储器就会失去低 16 位地址。复用是为了减少芯片引脚数量，锁存是为了解决复用带来的地址保持问题。

**题 6：8086 最小模式下，`MN/MX` 应接什么电平？`RD`、`WR`、`M/IO` 各表示什么？**

答案：`MN/MX` 接 VCC 时为最小模式；`RD` 低有效表示读，`WR` 低有效表示写，`M/IO` 高电平表示访问存储器、低电平表示访问 I/O 端口。

讲解：最小模式适用于单处理器小系统，8086 自己产生主要总线控制信号。最大模式下这些控制信号要由 8288 等总线控制器根据状态信号产生。

## 第 3 章 单片机的基本结构

### 3.1 本章在学什么

第 2 章的 8086 是 CPU，需要外部配存储器和 I/O。第 3 章开始进入 51 单片机，它把很多东西集成在一个芯片里。

本章重点不是“背一堆英文缩写”，而是看懂 8051 芯片为什么能独立工作：

- 它有 CPU。
- 它有程序存储器和数据存储器。
- 它有 4 个 8 位并行 I/O 口。
- 它有时钟和复位引脚。
- 它有中断、定时/计数器、串口等片上外设。

### 3.2 8051 引脚总览

8051 是 40 引脚 DIP 芯片。按功能分为：

| 类别 | 引脚 |
|---|---|
| 电源 | VCC、GND |
| 时钟 | XTAL1、XTAL2 |
| 复位 | RST |
| 程序存储器控制 | EA/VPP、PSEN |
| 地址锁存/编程 | ALE/PROG |
| I/O 口 | P0、P1、P2、P3 |
| 外部数据存储器读写 | P3.6/WR、P3.7/RD |

#### 8051 引脚图应该怎样读

8051 和 8086 一样是 DIP40。顶视图下，左侧从上到下是 1~20 脚，右侧从下到上是 21~40 脚；教材画成左右两列时，右侧通常从上到下写 40、39、38……21。

| 8 | P1.7 | 33 | P0.6/AD6 |

| 10 | P3.0/RXD | 31 | EA/VPP |

### 3.3 8051 重要引脚编号和作用

#### 电源、复位、时钟

| 引脚编号 | 名称 | 作用 |
|---:|---|---|
| 40 | VCC | +5V 电源 |
| 20 | GND | 地 |
| 9 | RST | 复位输入，高电平有效，保持超过 2 个机器周期触发复位 |
| 19 | XTAL1 | 晶振输入端 |
| 18 | XTAL2 | 晶振输出端 |

RST 为什么要保持超过 2 个机器周期？因为 CPU 需要一个足够长的稳定复位信号，才能把内部寄存器恢复到规定初值，从 0000H 开始执行。

#### 程序存储器相关控制引脚

| 引脚编号 | 名称 | 作用 |
|---:|---|---|
| 29 | PSEN | 外部程序存储器读选通信号，低有效 |
| 30 | ALE/PROG | 访问外部存储器时锁存 P0 输出的低 8 位地址；也可输出晶振 1/6 频率脉冲 |
| 31 | EA/VPP | 选择使用内部/外部程序存储器；也作编程电压输入 |

EA 引脚要特别小心：

```text
EA=1：优先从片内程序存储器取指令，超过片内容量后访问片外程序存储器。
EA=0：只从片外程序存储器取指令。
```

8031 没有片内 ROM，所以 EA 必须接地。8051/89C51 有片内程序存储器，常把 EA 接 +5V。

注意：这里的 EA 引脚不是 IE 寄存器里的中断总开关 EA 位。名字一样，位置和功能完全不同。

#### P0 口

| 引脚编号 | 名称 | 位序 |
|---|---|---|
| 39~32 | P0.0~P0.7 | P0.0 是 39 脚，P0.7 是 32 脚 |

P0 口特点：

- 可作普通 I/O。
- 外扩存储器时，分时复用为低 8 位地址线 A0~A7 和 8 位数据线 D0~D7。
- 作为普通 I/O 输出高电平时，必须外接上拉电阻。
- 作地址/数据总线时不需要额外上拉。

为什么 P0 要复用？因为 51 要访问片外 64KB 地址空间，需要 16 位地址线；P0 提供低 8 位，P2 提供高 8 位。P0 还要传数据，所以先输出地址，再切换为数据。

P0 的另一个重点是“开漏”。初学者可以这样理解：

```text
P0 输出 0：内部电路能把引脚主动拉到低电平。
P0 输出 1：内部电路并不能主动给出强高电平，相当于把引脚放开。
```

所以 P0 作普通 I/O 时，如果外部电路需要稳定高电平，要接上拉电阻。P1、P2、P3 内部有上拉，普通 I/O 使用时通常不额外强调这一点。

外扩存储器时，P0 先输出低 8 位地址，再传输数据。这个“先地址后数据”的转换要靠 ALE 配合外部锁存器：

```text
P0 前半段输出 A0~A7。
ALE 产生脉冲，锁存器保存 A0~A7。
P0 后半段改作 D0~D7 数据总线。
```

因此，看到外扩 RAM/ROM 的图，如果 P0 同时接锁存器和数据总线，不要觉得矛盾：它就是分时复用。

#### P1 口

| 引脚编号 | 名称 | 功能 |
|---|---|---|
| 1~8 | P1.0~P1.7 | 普通 8 位准双向 I/O，内置上拉 |

P1 最简单，常用来接 LED、按键、数码管段选等。

P1 没有外部存储器复用功能，所以做 C51 程序题时，可以优先把 P1 当作“最干净的普通 I/O 口”：

```c
P1 = 0x00;   // P1.0~P1.7 全部输出低电平
P1 = 0xff;   // P1.0~P1.7 全部输出高电平，也可作为输入前释放端口
```

#### P2 口

| 引脚编号 | 名称 | 功能 |
|---|---|---|
| 21~28 | P2.0~P2.7 | 普通 I/O；外扩存储器时作高 8 位地址线 A8~A15 |

若外接数据存储器小于 256B，只需低 8 位地址，P2 可继续做普通 I/O。若外接程序存储器或较大 RAM，P2 要作高 8 位地址线。

P2 和 P0 的区别：

```text
P0：低 8 位地址 + 数据，分时复用，需要 ALE 锁存地址。
P2：高 8 位地址，通常稳定输出，不和数据复用。
```

所以题目问“外扩存储器时地址总线从哪里来”，完整回答是：

```text
低 8 位地址 A0~A7 来自 P0，经 ALE 锁存；
高 8 位地址 A8~A15 来自 P2。
```

#### P3 口

| 引脚编号 | 名称 | 第二功能 |
|---:|---|---|
| 10 | P3.0 | RXD，串行口输入 |
| 11 | P3.1 | TXD，串行口输出 |
| 12 | P3.2 | INT0，外部中断 0 |
| 13 | P3.3 | INT1，外部中断 1 |
| 14 | P3.4 | T0，定时/计数器 0 外部计数输入 |
| 15 | P3.5 | T1，定时/计数器 1 外部计数输入 |
| 16 | P3.6 | WR，外部数据存储器写选通 |
| 17 | P3.7 | RD，外部数据存储器读选通 |

P3 是期中卷特别爱考的端口，因为中断、计数、串口、外部存储器读写都在这里。

P3 的第二功能不是“额外背一列英文”，而是告诉你某些片上外设必须从固定引脚进出：

| 应用场景 | 相关 P3 引脚 | 为什么 |
|---|---|---|
| 串口通信 | P3.0/RXD、P3.1/TXD | 接收线和发送线固定在这两位 |
| 外部中断 | P3.2/INT0、P3.3/INT1 | 外部中断请求从这里输入 |
| 外部计数 | P3.4/T0、P3.5/T1 | 计数脉冲从这里输入 |
| 外扩数据存储器 | P3.6/WR、P3.7/RD | 对外部 RAM 产生写/读控制信号 |

如果程序里写：

```c
sbit KEY = P3^2;
```

它既可以是普通按键输入，也可能被设计成外部中断 0 输入。区别在于程序是否配置了中断允许、触发方式和中断服务函数。

### 3.4 I/O 口读输入为什么要先写 1

教材说 P0~P3 作输入前要先写 1。初学者可以这样理解：

51 的 I/O 口不是简单的一根线，它内部有锁存器和输出管。若你之前向端口写了 0，输出管会把引脚强拉低，此时外部输入信号很难把它拉高。要读外部引脚真实电平，先写 1，让端口处于释放/准输入状态。

所以：

```c
P1 = 0xff;      // 先释放 P1 各位
if (P1_0 == 0)  // 再读按键
```

### 3.5 时钟周期、状态周期、机器周期、指令周期

| 名称 | 含义 |
|---|---|
| 时钟周期 | 晶振振荡周期，最小时间单位 |
| 状态周期 | 2 个时钟周期 |
| 机器周期 | 6 个状态周期 = 12 个时钟周期 |
| 指令周期 | 执行一条指令所需时间，通常 1~4 个机器周期 |

计算：

```text
机器周期 = 12 / 晶振频率
```

若晶振 12MHz：

```text
机器周期 = 12 / 12MHz = 1us
```

若晶振 6MHz：

```text
机器周期 = 12 / 6MHz = 2us
```

若晶振 24MHz：

```text
机器周期 = 12 / 24MHz = 0.5us
```

ALE 输出频率为晶振频率的 1/6，所以 6MHz 时 ALE 周期为 1us。

### 3.6 复位后寄存器状态

常考：

| 寄存器/端口 | 复位后 |
|---|---|
| PC | 0000H |
| SP | 07H |
| ACC | 00H |
| B | 00H |
| PSW | 00H |
| DPTR | 0000H |
| P0~P3 | FFH |
| SBUF | 不确定 |

复位不清除内部 RAM 内容；上电后内部 RAM 内容不确定。考试问“复位能否改变内部 RAM 单元内容”，按教材口径：复位不改变内部 RAM 内容。

### 3.7 51 CPU 内部寄存器

#### ACC/A

累加器 A 是最常用的 8 位寄存器。很多运算都默认通过 A 进行。

```asm
MOV A, 30H
ADD A, #05H
MOV 40H, A
```

含义：把 RAM[30H] 取到 A，加 5，再存到 RAM[40H]。

为什么 A 这么重要？因为 51 的很多运算不是任意两个操作数都能直接算，而是固定让 A 参与。例如：

```asm
ADD A, #10H     ; 合法，A = A + 10H
ADD 30H, #10H   ; 错，51 没有这种普通内存直接加立即数的写法
```

因此做 51 汇编题时，看到算术运算，先找 A；如果数据原来在 RAM 中，往往要先 `MOV A, direct`，算完再 `MOV direct, A`。

#### B 寄存器

B 主要配合乘除法：

```asm
MUL AB   ; A × B，结果高字节在 B，低字节在 A
DIV AB   ; A / B，商在 A，余数在 B
```

#### PSW

PSW 是程序状态字，地址 D0H，支持位寻址。

| 位 | 名称 | 含义 |
|---|---|---|
| PSW.7 | CY | 进位/借位标志，也是位处理器的位累加器 |
| PSW.6 | AC | 辅助进位，BCD 运算相关 |
| PSW.5 | F0 | 用户标志位 |
| PSW.4 | RS1 | 工作寄存器组选位 |
| PSW.3 | RS0 | 工作寄存器组选位 |
| PSW.2 | OV | 溢出标志 |
| PSW.1 | 保留 | 一般不用 |
| PSW.0 | P | 奇偶标志，A 中 1 的个数为奇数时置 1 |

工作寄存器组：

| RS1 | RS0 | 组 | R0~R7 地址 |
|---:|---:|---|---|
| 0 | 0 | 0 组 | 00H~07H |
| 0 | 1 | 1 组 | 08H~0FH |
| 1 | 0 | 2 组 | 10H~17H |
| 1 | 1 | 3 组 | 18H~1FH |

例：`PSW=10H`，二进制中 PSW.4=1、PSW.3=0，所以选第 2 组，R0~R7 地址是 10H~17H。

PSW 还决定很多判断题：

```asm
MOV A, #0FFH
ADD A, #01H
```

执行后：

```text
A = 00H
CY = 1      ; 产生进位
P = 0       ; A 中 1 的个数为 0，是偶数，所以 P=0
```

再看工作寄存器组。若当前 `PSW=08H`，则 RS1=0、RS0=1，当前 R0 实际对应内部 RAM `08H`，不是 `00H`。所以：

```asm
MOV PSW, #08H
MOV R0, #55H
```

结果是：

```text
RAM[08H] = 55H
```

#### PC

PC 是 16 位程序计数器，保存下一条指令地址。用户不能用普通指令直接改 PC，但转移、调用、中断、返回都会改变 PC。

复位后 PC=0000H，所以程序从 0000H 开始。

#### SP

SP 是堆栈指针。51 堆栈是“先加后压”：

```text
PUSH：SP 先加 1，再写入数据
POP：先读出数据，SP 再减 1
```

复位后 SP=07H，第一次压栈写入 08H。由于 00H~1FH 是工作寄存器区，实际程序常把 SP 设到 30H 以后，避免堆栈覆盖寄存器区：

```asm
MOV SP, #60H
```

例：复位后 `SP=07H`，执行：

```asm
MOV A, #12H
PUSH ACC
MOV A, #34H
PUSH ACC
POP B
```

逐步：

```text
PUSH 12H：SP 从 07H 加到 08H，RAM[08H]=12H。
PUSH 34H：SP 从 08H 加到 09H，RAM[09H]=34H。
POP B：从 RAM[09H] 读出 34H 到 B，SP 从 09H 减到 08H。
```

结果：

```text
A=34H, B=34H, SP=08H, RAM[08H]=12H
```

注意：`POP B` 不会把 RAM[09H] 清零，只是 SP 回退，原内容还在。

#### DPTR

DPTR 是 16 位数据指针，由 DPH 和 DPL 组成：

```text
DPH 地址 83H，高 8 位
DPL 地址 82H，低 8 位
```

它常用于访问外部数据存储器或程序存储器查表：

```asm
MOV DPTR, #2000H
MOVX A, @DPTR
MOVC A, @A+DPTR
```

`MOVC` 和 `MOVX` 是区分 51 存储空间的关键：

```text
MOVC：C 是 Code，访问程序存储器，多用于查表。
MOVX：X 是 external，访问片外数据存储器。
```

例：

```asm
MOV DPTR, #TAB
MOV A, #03H
MOVC A, @A+DPTR
```

含义不是去 RAM 里取 `DPTR+3`，而是去程序存储器中的表 `TAB` 第 3 项取常数。

### 3.8 51 存储器结构

51 不是普通 PC 那种“所有东西在一块内存里”。它采用哈佛结构，程序和数据空间分开。

| 空间 | 范围 | 访问特点 |
|---|---|---|
| 程序存储器 | 64KB，0000H~FFFFH | 存程序，查表用 MOVC |
| 片内低 128B RAM | 00H~7FH | 工作寄存器、位寻址区、用户 RAM |
| SFR 区 | 80H~FFH | 特殊功能寄存器，只能直接寻址 |
| 位寻址空间 | 内部 RAM 位 + 部分 SFR 位 | 位操作 |
| 片外数据存储器 | 64KB | 用 MOVX |

#### 低 128B RAM 分区

| 地址 | 名称 | 用途 |
|---|---|---|
| 00H~1FH | 工作寄存器区 | 4 组 R0~R7 |
| 20H~2FH | 位寻址区 | 16 字节，共 128 位，位地址 00H~7FH |
| 30H~7FH | 用户 RAM 区 | 变量、缓冲区、堆栈 |

位寻址区既可以按字节访问，也可以按位访问：

```asm
MOV 20H, #55H   ; 字节访问
SETB 00H        ; 位访问，置 RAM 20H 的 D0 位
```

位地址和字节地址要分清。内部 RAM `20H~2FH` 共 16 个字节，每个字节 8 位，所以一共 128 个可位寻址位：

```text
字节 20H 的 D0~D7 对应位地址 00H~07H。
字节 21H 的 D0~D7 对应位地址 08H~0FH。
……
字节 2FH 的 D0~D7 对应位地址 78H~7FH。
```

例：

```asm
MOV 20H, #00H
SETB 05H
```

`05H` 是位地址，不是字节地址。它对应 RAM `20H` 的第 5 位，所以执行后：

```text
RAM[20H] = 0010 0000B = 20H
```

### 3.9 特殊功能寄存器 SFR

SFR 控制单片机内部资源。常见 SFR：

| 名称 | 地址 | 作用 |
|---|---:|---|
| P0 | 80H | P0 口 |
| SP | 81H | 堆栈指针 |
| DPL | 82H | DPTR 低 8 位 |
| DPH | 83H | DPTR 高 8 位 |
| TCON | 88H | 定时/中断控制 |
| TMOD | 89H | 定时/计数器方式 |
| P1 | 90H | P1 口 |
| SCON | 98H | 串口控制 |
| SBUF | 99H | 串口数据缓冲 |
| P2 | A0H | P2 口 |
| IE | A8H | 中断允许 |
| P3 | B0H | P3 口 |
| IP | B8H | 中断优先级 |
| PSW | D0H | 程序状态字 |
| ACC | E0H | 累加器 |
| B | F0H | B 寄存器 |

地址能被 8 整除的 SFR 通常支持位寻址，例如 P0、P1、P2、P3、TCON、SCON、IE、IP、PSW、ACC、B。

### 3.10 程序存储器入口和中断向量

| 地址 | 含义 |
|---:|---|
| 0000H | 复位入口 |
| 0003H | 外部中断 0 |
| 000BH | T0 溢出中断 |
| 0013H | 外部中断 1 |
| 001BH | T1 溢出中断 |
| 0023H | 串行口中断 |
| 002BH | T2 中断，仅 52 系列 |

用汇编写程序时，通常在 0000H 放跳转：

```asm
ORG 0000H
LJMP MAIN

ORG 0030H
MAIN:
    ; 用户主程序
```

原因：0000H 附近还有中断入口区，主程序直接从 0000H 连续写下去容易覆盖中断入口。

### 3.11 补充教材嵌入：51 单片机寻址方式

51 汇编有 7 种寻址方式。不要先背名词，先看例子。

| 寻址方式 | 例子 | 解释 |
|---|---|---|
| 立即寻址 | `MOV A, #30H` | 30H 是数据本身 |
| 直接寻址 | `MOV A, 30H` | 30H 是内部 RAM 或 SFR 地址 |
| 寄存器寻址 | `MOV A, R0` | 数据在当前寄存器组的 R0 |
| 寄存器间接寻址 | `MOV A, @R0` | R0 中存的是地址 |
| 变址寻址 | `MOVC A, @A+DPTR` | A+DPTR 形成程序存储器地址 |
| 相对寻址 | `SJMP label` | PC 加相对偏移 |
| 位寻址 | `SETB 20H` | 操作位地址 |

`#30H`、`30H`、`@R0` 的区别：

```asm
MOV A, #30H   ; A = 30H
MOV A, 30H    ; A = RAM[30H]
MOV A, @R0    ; A = RAM[R0]
```

### 3.12 本章代表题

**题 1：51 单片机的 CPU 是几位？**

答案：8 位。

讲解：51 的数据宽度是 8 位；PC/DPTR 虽然是 16 位，但不代表 CPU 是 16 位。

**题 2：51 单片机并行口作输入用途之前必须做什么？**

答案：相应端口先置 1。

讲解：先写 1 是释放端口，使外部信号能驱动引脚。

**题 3：51 单片机应用系统扩展外部存储器时，哪个口作低 8 位地址和 8 位数据总线？哪个口作高 8 位地址？**

答案：P0 分时复用为低 8 位地址线和 8 位数据总线；P2 作高 8 位地址线。

讲解：这就是 ALE 存在的原因。P0 上的低 8 位地址会被 ALE 控制的锁存器锁住，然后 P0 切换为数据总线。

**题 4：`(30H)=60H, (60H)=10H, (P1)=0AH`，执行下列程序后关键单元结果是什么？**

```asm
MOV R0, #30H
MOV A, @R0
MOV R1, A
MOV B, @R1
MOV @R1, P1
MOV 10H, #90H
```

逐句：

```text
R0=30H
A=RAM[30H]=60H
R1=60H
B=RAM[60H]=10H
RAM[60H]=P1=0AH
RAM[10H]=90H
```

结果：

```text
A=60H, B=10H, (60H)=0AH, (10H)=90H
```

**题 5：8051 的 P0、P2 在外扩存储器时分别承担什么作用？ALE 为什么必需？**

答案：P0 分时复用为低 8 位地址 A0~A7 和 8 位数据 D0~D7；P2 输出高 8 位地址 A8~A15；ALE 用来锁存 P0 上先出现的低 8 位地址。

讲解：外扩存储器需要完整地址。P0 因为还要传数据，不能一直保持低 8 位地址，所以要在 P0 仍然输出地址的时刻用 ALE 控制锁存器保存地址。P2 不和数据复用，通常直接输出高 8 位地址。

**题 6：8051 中 `P3.2`、`P3.3`、`P3.6`、`P3.7` 的第二功能分别是什么？**

答案：

```text
P3.2 = INT0，外部中断 0 输入
P3.3 = INT1，外部中断 1 输入
P3.6 = WR，外部数据存储器写选通
P3.7 = RD，外部数据存储器读选通
```

讲解：这四个脚都来自 P3 口，但在中断和外扩数据存储器场景下不能只当普通 I/O 看。往年题常把 `P3.2/P3.3` 和中断章节连起来考。

**题 7：复位后 `SP=07H`，执行两次 `PUSH` 后 SP 等于多少？第一次压栈写入哪个单元？**

答案：两次 `PUSH` 后 `SP=09H`；第一次压栈写入 `08H` 单元。

讲解：51 堆栈是先加后压。复位后 SP 指向 07H，不表示 07H 已经有栈顶数据；第一次 `PUSH` 先变成 08H，再把数据写入 RAM[08H]。

### 3.13 补充教材嵌入：51 汇编指令系统

主教材第 4 章讲 C51，但你的资料里另有“汇编部分补充教材”。这部分不能孤立看，因为每条指令都在操作第 3 章刚讲过的 A、B、DPTR、内部 RAM、SFR 和端口。这里把补充教材中 51 相关的指令系统直接接在第 3 章后面。

#### 指令的基本格式

指令由操作码和操作数组成：

```asm
MOV A, #30H
```

其中：

```text
MOV 是操作码：做传送。
A 是目的操作数。
#30H 是源操作数。
```

不是所有指令都有两个操作数。比如：

```asm
CLR C
RET
NOP
```

#### 51 数据传送指令

最常见的是 `MOV`：

```asm
MOV A, R0
MOV A, 30H
MOV A, @R0
MOV 30H, A
MOV P1, #0FFH
MOV DPTR, #1234H
```

`MOVC` 和 `MOVX` 要分清：

| 指令 | 访问空间 |
|---|---|
| `MOV` | 片内 RAM、SFR、寄存器 |
| `MOVC` | 程序存储器，常用于查表 |
| `MOVX` | 片外数据存储器 |

例：

```asm
MOVC A, @A+DPTR   ; 查程序存储器表
MOVX A, @DPTR     ; 读片外 RAM
MOVX @DPTR, A     ; 写片外 RAM
```

#### 51 算术和逻辑指令

| 指令 | 含义 |
|---|---|
| `ADD A,src` | A 加 src |
| `ADDC A,src` | A 加 src 加 CY |
| `SUBB A,src` | A 减 src 减 CY |
| `INC` | 加 1 |
| `DEC` | 减 1 |
| `MUL AB` | A×B |
| `DIV AB` | A/B |
| `ANL` | 按位与 |
| `ORL` | 按位或 |
| `XRL` | 按位异或 |
| `CPL` | 取反 |

多字节减法必须先低字节再高字节：

```asm
CLR C
MOV A, 31H
SUBB A, 11H
MOV 31H, A
MOV A, 30H
SUBB A, 10H
MOV 30H, A
```

原因：低字节减法产生的借位要通过 CY 影响高字节。

#### 51 控制转移与位操作

常见转移：

| 指令 | 含义 |
|---|---|
| `SJMP rel` | 短跳转，范围 -128~+127 |
| `AJMP addr11` | 绝对跳转，同一 2KB 范围 |
| `LJMP addr16` | 长跳转，64KB 范围 |
| `JZ/JNZ` | A 为 0/非 0 跳转 |
| `JC/JNC` | CY 为 1/0 跳转 |
| `DJNZ` | 减 1 后非 0 跳转 |
| `LCALL/RET` | 子程序调用/返回 |
| `RETI` | 中断返回 |

位操作：

```asm
SETB P1.0
CLR  P1.0
CPL  P1.0
MOV  C, P3.2
MOV  P1.0, C
```

51 的位处理能力是它很适合控制系统的原因之一。

#### 51 汇编代表题

**题：设变量 X 在 10H 单元，Y 在 20H 单元，实现：X>0 时 Y=80H，X=0 时 Y=50H，X<0 时 Y=FFH。**

```asm
MOV A, 10H
JZ  ZERO
JNB ACC.7, POSI
MOV A, #0FFH
SJMP DONE
ZERO:
MOV A, #50H
SJMP DONE
POSI:
MOV A, #80H
DONE:
MOV 20H, A
SJMP $
```

解释：

- 51 中常把 8 位数最高位 ACC.7 看作符号位。
- `JZ ZERO` 先判断 0。
- 若不是 0，再看 ACC.7。最高位为 0，则为正；最高位为 1，则为负。
- 最后统一把 A 写入 20H。

## 第 4 章 单片机 C51 语言基础知识简介

### 4.1 为什么学 C51

51 单片机最终执行机器码。汇编能直接控制硬件，但写复杂程序效率低。C51 在标准 C 基础上增加了适合 51 硬件的关键字，让你能直接写：

```c
P1 = 0x00;
```

来控制端口。

### 4.2 C51 和标准 C 的不同点

| 不同点 | 解释 |
|---|---|
| 头文件不同 | `reg51.h/reg52.h` 把 SFR 名称映射出来 |
| 数据类型扩展 | 增加 `sbit`、`sfr`、`bit` 等 |
| 存储类型扩展 | 增加 `data`、`xdata`、`code` 等 |
| 中断函数 | 标准 C 没有，C51 用 `interrupt n` |
| I/O 方式 | 不是键盘屏幕，而是端口、串口等硬件 |

### 4.3 C51 扩展关键字

| 关键字 | 作用 | 例子 |
|---|---|---|
| `sfr` | 定义 SFR | `sfr P1 = 0x90;` |
| `sfr16` | 定义 16 位 SFR | 定义 DPTR 类寄存器 |
| `sbit` | 定义一个可位寻址位 | `sbit LED=P1^0;` |
| `bit` | 定义位变量 | `bit flag;` |
| `data` | 片内低 128B RAM | `data unsigned char x;` |
| `idata` | 片内 RAM 间接访问区 | 较少手写 |
| `xdata` | 片外 RAM | 大数组可放这里 |
| `code` | 程序存储器 | 段码表常用 |
| `interrupt` | 定义中断函数 | `interrupt 0` |
| `using` | 指定寄存器组 | `using 1` |

### 4.4 位定义和端口控制

```c
#include <reg51.h>

sbit LED = P1^0;
sbit KEY = P3^2;
```

这不是普通变量，而是给硬件位起名字。`LED=0` 就是把 P1.0 输出低电平。

正确写法：

```c
sbit P12 = P1^2;
```

错误写法：

```c
bit P12 = P1^2;    // 错，bit 是普通位变量，不绑定端口
sbit P12 = P1.2;   // 错，C51 位写法用 ^
```

### 4.5 C51 数据类型

| 类型 | 位数 | 范围 |
|---|---:|---|
| `unsigned char` | 8 | 0~255 |
| `char` | 8 | -128~127 |
| `unsigned int` | 16 | 0~65535 |
| `int` | 16 | -32768~32767 |
| `bit` | 1 | 0/1 |

期中题常问：C51 无符号整型变量范围是 `0~65535`。

### 4.6 函数和中断函数

普通函数：

```c
void delay_ms(unsigned int ms)
{
    unsigned char i;
    while (ms--) {
        for (i = 0; i < 123; i++);
    }
}
```

中断函数：

```c
void int0_isr(void) interrupt 0 using 0
{
    P1 = ~P1;
}
```

区别：

| 普通函数 | 中断函数 |
|---|---|
| 由程序调用 | 由硬件中断自动调用 |
| 可以有参数和返回值 | 不应有参数和返回值 |
| 返回用普通函数返回 | 返回时编译器生成 RETI |
| 不需要中断号 | 必须写 `interrupt n` |

### 4.7 本章代表题

**题 1：`interrupt m` 是什么？**

答案：C51 用来修饰中断函数的关键字，`m` 是中断号。

讲解：编译器根据 `m` 把函数放到对应中断向量入口。

**题 2：`using n` 的作用是什么？**

答案：指定函数使用的工作寄存器组，n 取 0~3。

讲解：51 有 4 组 R0~R7。中断函数可以指定一组寄存器，减少现场保护负担，但要避免和主程序冲突。

**题 3：写 P1.0 LED 闪烁程序。**

```c
#include <reg51.h>

sbit LED = P1^0;

void delay_ms(unsigned int ms)
{
    unsigned char i;
    while (ms--) {
        for (i = 0; i < 123; i++);
    }
}

void main(void)
{
    while (1) {
        LED = ~LED;
        delay_ms(500);
    }
}
```

解释：

- `sbit LED=P1^0` 把 LED 名字绑定到 P1.0。
- `LED=~LED` 每次把输出状态取反。
- 延时让闪烁能被人眼看到。

## 第 5 章 微处理器控制系统的人机交互接口设计

### 5.1 本章在学什么

人机交互接口就是人和单片机系统打交道的硬件：

| 人到机器 | 机器到人 |
|---|---|
| 按键、矩阵键盘 | LED、数码管、LCD、蜂鸣器 |

本章考试喜欢程序填空，因为它能同时考端口、C51、硬件连接和基本逻辑。

### 5.2 独立按键

按键本质是一个开关。常见连接是按下接地，所以：

```text
未按下：端口为 1
按下：端口为 0
```

机械按键有抖动。软件消抖流程：

```text
第一次检测到按下
延时 10~20ms
再次检测
若仍然按下，才认为有效
等待松手，避免一次按下计多次
```

查询式按键计数：

```c
#include <reg51.h>

unsigned char code seg[10] =
    {0x3f,0x06,0x5b,0x4f,0x66,0x6d,0x7d,0x07,0x7f,0x6f};
sbit KEY = P3^2;

void delay_ms(unsigned int n)
{
    unsigned int i, j;
    for (i = 0; i < n; i++)
        for (j = 0; j < 250; j++);
}

void main(void)
{
    unsigned char count = 0;
    P2 = seg[count];

    while (1) {
        if (KEY == 0) {
            delay_ms(20);
            if (KEY == 0) {
                while (KEY == 0);
                count++;
                if (count == 10) count = 0;
                P2 = seg[count];
            }
        }
    }
}
```

### 5.3 LED 数码管

数码管由 a~g 和 dp 八段组成。

共阴极：公共端接地，某段给 1 则亮。常见段码：

```c
unsigned char code seg[10] =
    {0x3f,0x06,0x5b,0x4f,0x66,0x6d,0x7d,0x07,0x7f,0x6f};
```

静态显示：每个数码管长期给固定段码。简单但占 I/O 多。

动态显示：所有数码管共用段选，轮流打开位选。省 I/O，但程序要不断扫描。

两位数码管显示 0~99：

```c
void display(unsigned char x)
{
    P0 = seg[x % 10];  // 个位
    ge = 0;
    delay(3);
    ge = 1;

    P0 = seg[x / 10];  // 十位
    shi = 0;
    delay(3);
    shi = 1;
}
```

为什么按键等待时也要调用 `display()`？动态显示必须持续刷新。如果程序停在等待按键的循环里不刷新，数码管会暗掉或闪烁。

### 5.4 矩阵键盘

如果有 16 个按键，独立按键需要 16 根 I/O。矩阵键盘用 4 行 + 4 列，只需 8 根 I/O。

扫描思想：

1. 让某一行输出 0，其他行输出 1。
2. 读取列线。
3. 若某列读到 0，说明这一行这一列的键按下。
4. 依次扫描 4 行。

往年中断矩阵键盘核心：

```c
char key_scan[] = {0xef, 0xdf, 0xbf, 0x7f};

for (i = 0; i < 4; i++) {
    P1 = key_scan[i];
    if ((P1 & 0x0f) != 0x0f) {
        for (j = 0; j < 16; j++) {
            if (key_buf[j] == P1) {
                P2 = led_mod[j];
                break;
            }
        }
    }
}
```

解释：

- `0xef` 是二进制 `1110 1111`，表示某一行拉低。
- `P1 & 0x0f` 只看低 4 位列线。
- 若低 4 位不是 `1111`，说明有列被拉低，有键按下。

### 5.5 LCD1602

LCD1602 一行 16 个字符，共两行。常考命令：

| 命令 | 含义 |
|---|---|
| `0x38` | 8 位数据，2 行显示，5×7 点阵 |
| `0x0c` | 开显示，不显示光标 |
| `0x06` | 写入后地址自动加 1 |
| `0x01` | 清屏 |
| `0x80` | 第一行首地址 |
| `0x80+0x40` | 第二行首地址 |

写命令和写数据差别在 RS：

```c
void write_com(unsigned char com)
{
    lcdrs = 0;
    lcdrw = 0;
    P0 = com;
    lcden = 1;
    delay(5);
    lcden = 0;
}

void write_data(unsigned char dat)
{
    lcdrs = 1;
    lcdrw = 0;
    P0 = dat;
    lcden = 1;
    delay(5);
    lcden = 0;
}
```

显示两行：

```c
write_com(0x80);
for (num = 0; num < 11; num++) {
    write_data(table[num]);
}

write_com(0x80 + 0x40);
for (num = 0; num < 13; num++) {
    write_data(table1[num]);
}
```

### 5.6 本章代表题

**题 1：什么是按键抖动？如何消除？**

答案：机械按键按下或松开瞬间，触点会在短时间内反复接通/断开，造成电平不稳定。可用硬件消抖或软件延时消抖。

讲解：软件消抖必须“延时后再次确认”，不是单纯延时。

**题 2：需要扩展 10 个功能键，用独立式还是矩阵式？**

答案：矩阵式按键。

讲解：按键多时，独立式太浪费 I/O；矩阵式用较少 I/O 扩展更多按键。

**题 3：0~99 按键计数中，个位和十位怎么取？**

答案：

```c
ge_value = dd % 10;
shi_value = dd / 10;
```

讲解：`%` 取余得到个位，`/` 整除得到十位。

## 第 6 章 6.1~6.2 微处理器中断系统及单片机中断系统

### 6.1 中断是什么

没有中断时，CPU 只能按顺序执行程序。若想知道按键有没有按下，只能不断查询：

```c
while (1) {
    scan_key();
}
```

中断的思路是：外部或内部事件发生时，硬件主动通知 CPU。CPU 暂停当前程序，转去执行中断服务程序，处理完再回来。

基本名词：

| 名词 | 解释 |
|---|---|
| 中断源 | 引起中断的事件或部件 |
| 中断请求 | 中断源向 CPU 提出的请求 |
| 断点 | 主程序被打断处，即之后要回来的地址 |
| 中断响应 | CPU 接受请求并转向中断入口 |
| 中断服务程序 | 处理中断事件的程序 |
| 中断返回 | 回到断点继续执行主程序 |

### 6.2 中断处理过程

一次中断大致经历：

```text
中断源提出请求
CPU 判断是否允许响应该中断
当前指令执行完
硬件保存断点 PC
PC 装入中断入口地址
执行中断服务程序
恢复现场
RETI 返回断点
```

为什么要保护现场？因为中断服务程序可能使用 A、PSW、R0 等寄存器。如果不保存，主程序回来后这些寄存器值变了，会出错。

### 6.3 8051 的 5 个中断源

| 中断号 | 中断源 | 入口地址 | C51 |
|---:|---|---:|---|
| 0 | 外部中断 INT0 | 0003H | `interrupt 0` |
| 1 | T0 溢出中断 | 000BH | `interrupt 1` |
| 2 | 外部中断 INT1 | 0013H | `interrupt 2` |
| 3 | T1 溢出中断 | 001BH | `interrupt 3` |
| 4 | 串行口中断 | 0023H | `interrupt 4` |

外部中断引脚：

| 中断 | 引脚 | 编号 |
|---|---|---:|
| INT0 | P3.2 | 12 脚 |
| INT1 | P3.3 | 13 脚 |

外部中断触发方式：

```text
低电平触发
下降沿触发
```

由 TCON 中 IT0/IT1 设置。

### 6.4 TCON

TCON 地址 88H，可位寻址。与中断有关的位：

| 位 | 名称 | 作用 |
|---|---|---|
| TCON.0 | IT0 | INT0 触发方式，1 为下降沿，0 为低电平 |
| TCON.1 | IE0 | INT0 请求标志 |
| TCON.2 | IT1 | INT1 触发方式 |
| TCON.3 | IE1 | INT1 请求标志 |
| TCON.5 | TF0 | T0 溢出标志 |
| TCON.7 | TF1 | T1 溢出标志 |
| TCON.4 | TR0 | T0 启动控制，6.3 后内容 |
| TCON.6 | TR1 | T1 启动控制，6.3 后内容 |

考试到 6.2 时，TR0/TR1 只需知道它们属于 TCON，高频完整编程属于定时器章节。

### 6.5 SCON

串口中断由 SCON 中的 TI/RI 触发：

| 位 | 作用 |
|---|---|
| TI | 发送完成标志，硬件置 1，软件清 0 |
| RI | 接收完成标志，硬件置 1，软件清 0 |

串口中断请求是 `TI 或 RI`。进入串口中断后必须判断并清零：

```c
void serial_isr(void) interrupt 4
{
    if (RI) {
        RI = 0;
        /* 读 SBUF */
    }
    if (TI) {
        TI = 0;
        /* 发送完成处理 */
    }
}
```

### 6.6 IE：中断允许寄存器

IE 地址 A8H，可位寻址。

| 位 | 名称 | 作用 |
|---|---|---|
| IE.7 | EA | 总中断允许 |
| IE.4 | ES | 串口中断允许 |
| IE.3 | ET1 | T1 中断允许 |
| IE.2 | EX1 | INT1 中断允许 |
| IE.1 | ET0 | T0 中断允许 |
| IE.0 | EX0 | INT0 中断允许 |

开 INT0 中断：

```c
EA = 1;
EX0 = 1;
IT0 = 1;
```

解释：

- `EA=1` 是总开关。
- `EX0=1` 是 INT0 分开关。
- `IT0=1` 是选择下降沿触发。

### 6.7 IP：中断优先级寄存器

IP 地址 B8H，可位寻址。

| 位 | 名称 | 作用 |
|---|---|---|
| IP.4 | PS | 串口优先级 |
| IP.3 | PT1 | T1 优先级 |
| IP.2 | PX1 | INT1 优先级 |
| IP.1 | PT0 | T0 优先级 |
| IP.0 | PX0 | INT0 优先级 |

某位为 1，表示对应中断是高优先级；为 0，表示低优先级。复位后默认全是低优先级。

同级自然优先级：

```text
INT0 > T0 > INT1 > T1 > 串行口
```

嵌套规则：

```text
高优先级可以打断低优先级。
低优先级不能打断高优先级。
同级不能互相打断。
```

### 6.8 中断响应条件

CPU 不会一有请求就无条件跳过去。需要：

1. 中断源请求有效。
2. 总中断允许 `EA=1`。
3. 对应分中断允许位为 1。
4. 当前没有同级或更高级中断正在服务。
5. 当前指令执行完毕。
6. 若正在执行访问 IE/IP 或返回类指令，通常还要再执行一条指令。

### 6.9 中断请求撤除

| 中断标志 | 撤除方式 |
|---|---|
| TF0/TF1 | CPU 响应后硬件自动清除 |
| 下降沿触发的 IE0/IE1 | CPU 响应后硬件自动清除 |
| 低电平触发外部中断 | 必须由外部电路撤销低电平 |
| TI/RI | 必须软件清 0 |

低电平触发的陷阱：如果中断返回前 INT0/INT1 引脚仍保持低电平，CPU 会认为请求还在，可能再次进入中断。

### 6.10 C51 中断程序模板

INT0 控制 LED 翻转：

```c
#include <reg51.h>

sbit LED = P1^0;

void main(void)
{
    LED = 0;
    IT0 = 1;   // INT0 下降沿触发
    EX0 = 1;   // 允许 INT0
    EA  = 1;   // 开总中断

    while (1) {
        /* 主程序可以做其他事 */
    }
}

void int0_isr(void) interrupt 0 using 0
{
    LED = ~LED;
}
```

### 6.11 汇编中断程序模板

```asm
ORG 0000H
LJMP MAIN

ORG 0003H
LJMP INT0_ISR

ORG 0030H
MAIN:
    SETB EA
    SETB EX0
    SETB IT0
    SJMP $

INT0_ISR:
    PUSH ACC
    PUSH PSW
    CPL P1.0
    POP PSW
    POP ACC
    RETI
```

解释：

- `ORG 0003H` 是 INT0 入口。
- 入口处放 `LJMP`，跳到真正服务程序。
- 进入服务程序后保护现场。
- 最后必须 `RETI`，不是 `RET`。

### 6.12 本章代表题

**题 1：MCS-51 的内部中断源和外部中断源分别是什么？**

答案：

```text
外部中断源：INT0、INT1。
内部中断源：T0、T1、串行口。
```

讲解：这是往年简答高频题。复位入口不是普通中断源。

**题 2：外部中断 INT0 和 INT1 对应的引脚是什么？触发条件是什么？**

答案：

```text
INT0：P3.2，12 脚。
INT1：P3.3，13 脚。
低电平或下降沿触发。
```

**题 3：AT89C51 五个中断源自然优先级从高到低是什么？**

答案：

```text
INT0 > T0 > INT1 > T1 > 串行口
```

讲解：这是同级情况下的查询顺序。若 IP 设置了高/低优先级，要先比较高低优先级，再看自然优先级。

**题 4：为什么 C51 中断函数不能有参数和返回值？**

答案：中断函数不是由普通 C 调用语句调用的，而是由硬件中断入口自动转入。没有调用者传参，也没有调用者接收返回值。返回过程由中断返回指令完成。
