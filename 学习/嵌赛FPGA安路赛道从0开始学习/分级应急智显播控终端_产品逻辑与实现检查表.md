# 分级应急智显播控终端：产品逻辑与实现检查表

> 用途：这是一份“做到了什么”的检查表，而不是学习计划。只有功能已经在 **HX4S20C 实板** 上、脱离电脑后可重复演示，才将对应项改为 `[x]`。
>
> 约定：`[ ]` 未完成；`[~]` 正在联调；`[x]` 已在实板验证；`[!]` 已知问题或返工项。建议每次只更新状态、验证日期和问题记录，保留真实进度。

---

## 1. 产品定义

### 1.1 一句话定义

一台由 FPGA 独立运行的离线应急信息屏：平时播放公共引导信息；收到不同级别的事件输入时，以确定的优先级切入对应分区的疏散路线、告警字幕和提示音；素材或存储卡异常时仍能显示内部故障告警页面。

### 1.2 目标使用场景

展馆入口、厂区通道、公共大厅等需要长期显示宣传、路线或安全提示信息的位置。现场不依赖电脑和网络；比赛中用板载按键或 GPIO 电平模拟外部报警输入，实际产品可连接报警干接点或其他逻辑电平接口。

### 1.3 边界与约束

- [ ] 使用 HX4S20C 开发板及板载安路 EG4S20 FPGA。
- [ ] 所有处理、控制逻辑和数据通路均在 FPGA 内实现，不使用额外处理器。
- [ ] 所有基础功能、扩展功能和创新功能整合为同一个固化镜像，不通过更换镜像分别演示。
- [ ] 固化至板载 Flash 后可上电自动运行，无需电脑重新下载。
- [ ] 首版只处理赛题要求的未压缩 BMP 图片；不把 MP4、MP3、网络播放或摄像头识别纳入核心验收范围。

## 2. 产品运行逻辑

### 2.1 完整信息通路

\[
\text{TF 卡 BMP 素材}
\rightarrow
\text{BMP 解析与缩放}
\rightarrow
\text{SDRAM 双帧缓存}
\rightarrow
\text{图层合成与显示参数处理}
\rightarrow
\text{HDMI 图像输出}
\]

\[
\text{提示音 PCM}
\rightarrow
\begin{cases}
\text{HDMI 音频输出}\\
\text{定点频谱分析} \rightarrow \text{频谱 OSD 图层}
\end{cases}
\]

### 2.2 状态机

事件的优先级必须满足：

\[
\text{紧急模式} > \text{注意模式} > \text{普通模式}
\]

| 状态 | 进入条件 | 屏幕与声音行为 | 退出条件 |
|---|---|---|---|
| 启动/自检 | 上电或复位 | 显示启动状态，初始化时钟、SDRAM、TF 卡和 HDMI | 初始化全部通过或进入故障兜底 |
| 普通模式 | 无高优先级事件 | 自动轮播宣传/路线图片；支持手动切图和参数调整 | 注意或紧急输入有效 |
| 注意模式 | 注意级事件有效 | 保留普通背景，叠加黄色提示条、滚动字幕和对应提示音 | 紧急输入有效或事件解除 |
| 紧急模式 | 紧急级事件有效 | 在帧边界切入对应区域的疏散路线、红色告警和高优先级提示音 | 事件解除并完成恢复确认 |
| 恢复模式 | 紧急/注意事件解除 | 平滑淡出告警图层，恢复普通轮播 | 恢复完成或出现新事件 |
| 故障兜底 | TF 卡读取失败、素材异常或初始化超时 | 显示内部生成的故障/告警 OSD，不允许黑屏或无提示停机 | 故障恢复或人工复位 |

### 2.3 演示闭环

\[
\text{上电自启}
\rightarrow
\text{普通轮播}
\rightarrow
\text{事件输入}
\rightarrow
\text{分级/分区告警联动}
\rightarrow
\text{事件解除}
\rightarrow
\text{平滑恢复}
\]

**完成判据：** 整段流程在同一固化镜像上完成，图像无花屏、切换无明显闪烁、音频无明显断续，且无需重新下载程序。

## 3. 模块清单与实现目标

### 3.1 平台、时钟与人机输入

- [ ] 建立工程、管脚约束和顶层模块；工程可生成可下载配置文件。
- [ ] 完成复位和上电初始化顺序；任何子模块未就绪时不输出异常 HDMI 数据。
- [ ] 用 PLL 生成并标注系统、存储、视频和音频所需时钟。
- [ ] 对按键进行消抖并输出单周期事件脉冲，连续按住不得被误判为多次触发。
- [ ] 定义并实现板载按键/拨码/GPIO 的最终功能映射。
- [ ] 在数码管或 OSD 上显示当前系统状态，便于比赛现场定位故障。

### 3.2 TF 卡、BMP 与素材管理

- [ ] 通过 SPI 读取 TF 卡，能识别插卡、未插卡和读取超时状态。
- [ ] 能读取赛题规定的 \(640\times480\)、\(24\)-bit、非压缩 BMP 图像。
- [ ] 正确解析 BMP 文件头、宽高、数据偏移、行对齐、BGR 到 RGB 顺序和上下行方向。
- [ ] 普通模式能够读取至少三张图片，支持手动切换和自动轮播。
- [ ] 定义普通素材、注意素材、紧急区域 A 素材、紧急区域 B 素材及提示音的固定组织方式。
- [ ] TF 卡异常、文件不存在或格式不支持时，系统进入故障兜底状态并给出可读提示。

### 3.3 FIFO、SDRAM 与帧缓存

- [ ] 写 FIFO 能将 TF/BMP 侧数据稳定交给 SDRAM 写入侧。
- [ ] 读 FIFO 能向视频输出侧连续供给像素，避免存储器突发访问造成输出断流。
- [ ] 能单独向 SDRAM 写入并读回已知图案，读回数据完全正确。
- [ ] 当前显示帧与后台装载帧相互独立；后台写图时前台画面不受影响。
- [ ] 实现双帧缓存，完成新旧图片安全交换。
- [ ] 在 \(640\times480\) 图像连续轮播时无花屏、撕裂或长时间黑屏。

### 3.4 HDMI 图像与基础播放器

- [ ] HDMI 在目标显示器上稳定识别并持续输出图像。
- [ ] 显示画面色彩、行顺序和分辨率正确，不出现整体偏色、镜像或倒置。
- [ ] 手动切换只在安全帧边界生效。
- [ ] 自动轮播的时间参数可配置，轮播过程中无异常闪烁。
- [ ] 从上电到进入普通轮播无需电脑参与。

### 3.5 HDMI 音频与同步

- [ ] 生成符合赛题要求的 HDMI 测试提示音。
- [ ] HDMI 接收端可听到稳定音频，无明显杂音、爆音或周期性中断。
- [ ] 图像与音频在同一 HDMI 输出通路中持续工作。
- [ ] 注意和紧急状态可切换不同的提示音参数或提示节奏。

## 4. 五项扩展要求检查表

### 4.1 扩展 1：图层叠加与字幕效果

- [ ] 建立 OSD 图层，能在 BMP 背景上显示固定文字、图标或状态信息。
- [ ] 建立可用的字库/图标 ROM，至少包含模式、告警和方向提示所需字符。
- [ ] 实现水平滚动字幕，滚动过程中边缘无抖动和残影。
- [ ] 实现多图层 Alpha 混合，且透明层不破坏背景颜色。
- [ ] 普通、注意、紧急三种状态有明显不同且一致的 OSD 布局。

像素混合的目标关系为：

\[
C_{\mathrm{out}}
=
\bigl(\alpha C_{\mathrm{fg}}+(16-\alpha)C_{\mathrm{bg}}\bigr)\gg4
\]

### 4.2 扩展 2：图片轮播与转场特效

- [ ] 双帧缓存中可同时保留旧图和新图。
- [ ] 实现淡入淡出，\(\alpha\) 从 \(0\) 平滑变化到 \(16\)。
- [ ] 转场期间无明显闪烁、撕裂、色块或音频异常。
- [ ] 紧急事件到来时，能够打断普通轮播并以转场方式进入告警画面。
- [ ] 恢复普通模式时，能够以转场方式退出告警画面。

### 4.3 扩展 3：图片缩放适配

- [ ] 从 BMP 文件头获得源图宽度 \(W_s\) 和高度 \(H_s\)。
- [ ] 至少验证 \(320\times240\)、\(480\times360\)、\(640\times480\) 三种输入图片。
- [ ] 在固定 HDMI 输出画面中保持正确宽高比，实现居中显示、留边或受控裁切。
- [ ] OSD 显示当前源图分辨率与缩放状态，便于现场证明该功能真实生效。
- [ ] 实现最近邻缩放并验证缩放后无行错位或越界访问。
- [ ] 可选加分：实现双线性插值，提升放大图像边缘质量。

最近邻缩放的坐标映射为：

\[
x_s=\left\lfloor\frac{x_oW_s}{W_o}\right\rfloor,
\qquad
y_s=\left\lfloor\frac{y_oH_s}{H_o}\right\rfloor
\]

### 4.4 扩展 4：实时参数调节与 OSD 信息叠加

- [ ] 通过板载按键或拨码选择亮度/对比度调节模式。
- [ ] 通过按键改变亮度参数 \(\Delta\) 和对比度系数 \(k\)。
- [ ] 参数变化在当前画面中实时生效，不重新读取图片、不停止 HDMI 输出。
- [ ] OSD 显示当前参数、模式和变化方向。
- [ ] 对最大、最小参数进行限幅，避免 RGB 溢出或回绕。

每个颜色分量的目标变换为：

\[
C'=\operatorname{sat}\left(((C-128)k\gg q)+128+\Delta\right)
\]

### 4.5 扩展 5：音频可视化

- [ ] 将 HDMI 音频所用 PCM 样本同步写入频谱分析模块，而不是使用独立随机动画。
- [ ] 完成定点 \(64\)-点或其他已定义规模的 FFT/DFT 频段能量计算。
- [ ] 将频段能量映射为频谱柱状图或波形，并叠加到 HDMI 画面。
- [ ] 切换提示音频率或模式时，频谱位置/幅度有可观察变化。
- [ ] 频谱渲染不会影响 HDMI 音频连续性和图片播放稳定性。

## 5. 自主创新与产品成熟度检查表

### 5.1 分级、分区应急决策

- [ ] 注意和紧急事件具有明确优先级，低优先级状态不能覆盖高优先级状态。
- [ ] 不同 GPIO/按键输入可选择不同的区域路线或告警模板。
- [ ] 新事件到来时，当前状态机能确定地转入对应状态，不依赖人工重启。
- [ ] 事件解除后按规定条件恢复，不出现状态混乱或错误页面残留。
- [ ] 形成一张状态转移图，能解释每个输入、优先级和退出条件。

### 5.2 可靠性与失效保护

- [ ] TF 卡未插入时，系统能提示原因而非黑屏。
- [ ] TF 卡在轮播期间失效或读取超时时，系统进入安全告警页面。
- [ ] 任意图片加载失败时，当前已显示画面保持稳定或切换到内部兜底页面。
- [ ] 按键抖动、重复输入和同时输入不会导致状态机进入非法状态。
- [ ] 连续运行至少 \(30\) 分钟，轮播、OSD、转场和音频均稳定。
- [ ] 完成至少 \(10\) 次断电冷启动测试，每次均可自动进入可演示状态。

### 5.3 现场演示质量

- [ ] 开机后在合理时间内进入普通轮播。
- [ ] 可完整展示：普通轮播、手动切图、淡入淡出、参数调节、频谱、注意模式、紧急区域 A、紧急区域 B、恢复流程。
- [ ] 显示器在演示全程不黑屏、不丢失 HDMI 信号、不出现明显花屏。
- [ ] 屏幕 OSD 或数码管能展示当前模式，评委不需要猜测系统是否响应。
- [ ] 演示中拔除/禁用 TF 卡后，能展示故障兜底能力；恢复后可回到可用状态。
