## 推荐学习主线

$$
\text{交流阻抗}
\longrightarrow
\text{LC 谐振}
\longrightarrow
\text{频率响应与 }Q
\longrightarrow
\text{带宽与选择性}
\longrightarrow
\text{部分接入与阻抗匹配}
$$

复习时应按这条主线推进。若学校课堂把多个电路类型放在一起讲，笔记仍按“一个核心电路问题一篇”的方式组织，避免概念互相牵连。

## 文件与命名

- 主笔记使用 `第N课_主题.md`；本课程保留下划线分隔，便于把课次与电路主题一眼分开。
- `高频振荡回路与阻抗匹配.assets/` 保存 SVG 电路图、等效模型、相量图、幅频/相频曲线和例题结构图。
- `PPT/` 是教师课件和参考资料。文件存在不等于内容已经掌握，学习进度只以编号笔记和本表为准。
- 新增笔记后，要更新本页“当前学习进度”，并检查相邻课次的链接是否仍然正确。
