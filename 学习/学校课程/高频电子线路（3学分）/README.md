## 新对话必须先执行的上下文检查

用户来提问时，默认这是一次新的课堂学习记录。每次新对话先做以下检查，再开始讲解：

1. 先查看本课程文件夹中的 `README.md`、`AGENTS.md` 和所有编号笔记的文件名与标题。
2. 根据“当前学习进度”判断已经学过哪些电路类型和概念，不要把已经写过的前置内容当作用户完全陌生的知识，也不要假设用户已经掌握后续内容。
3. 用户可能只给出课堂关键词、老师讲课的脉络和自己的疑问。把这些内容当作原始课堂记录，不要逐条机械扩写，而要根据知识依赖关系还原老师这节课为什么这样讲。
4. 对话中先形成连贯的教材式讲解，并针对疑惑解释“为什么这样定义、为什么这样变换、什么时候使用”。此阶段默认只在聊天中回答，不生成或修改笔记文件。
5. 只有用户明确说“整理成笔记”“形成笔记”“保存课堂内容”等，才把对话内容写入本文件夹。

## 整理新笔记时的文件规则

- 按“课次 + 电路类型或核心知识主题”命名，例如 `04 第4课 某类电路.md`。课次从当前最大编号顺延。
- 如果一节课跨越多个彼此独立的电路类型，可以拆成多个 Markdown 文件，但仍需在 `README.md` 中归入同一课次，并说明文件之间的先后关系。
- 参考已有笔记的标题层级、推导顺序、术语写法和例题组织方式，不要退化成术语表、公式清单或问答卷。
- 每个新笔记都要有足够的 SVG 电路图、等效模型图、相量图、幅频/相频曲线或阻抗折算示意图。图放在课程目录下的 `.assets` 文件夹中，文件名要能直接看出图意。
- 每引入一个公式，必须解释变量、物理对象、推导动机、适用条件和常见误用。
- 新笔记完成后，回写 `README.md` 的“当前学习进度”，并同步检查 `高频振荡回路、选频与阻抗匹配.md` 是否需要增加导航入口。
