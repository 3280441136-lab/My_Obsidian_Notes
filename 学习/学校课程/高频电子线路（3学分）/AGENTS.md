# 高频电子线路项目协作约束

## 文件分工

- `README.md`：课程导航、学习进度、阅读主线和文件结构的唯一状态来源。
- `AGENTS.md`：约束 Codex 如何回答、如何组织教材式笔记、如何修改文件。
- `第N课_主题.md`：已经整理并核对的课程知识。
- `*.assets/`、`assets/`：笔记使用的 SVG、波形、频谱、等效模型和电路图。
- `PPT/`：原始课件与参考材料，不自动视为已掌握内容。

不要在 `AGENTS.md` 里另建一份容易失同步的“当前学习进度”；进度只写入 `README.md`。

## 新对话工作流

1. 先读取 `README.md`，再浏览 `第N课_*.md` 的文件名、一级标题和关键图，确认已经学过的电路类型与知识边界。
2. 把用户给出的课堂关键词、讲课脉络和疑问当作一节新课的原始记录。先补足缺失的前置概念，再按知识依赖关系还原老师为什么这样讲。
3. 默认只在聊天中讲解和答疑。只有用户明确要求“整理成笔记”“保存课堂内容”或表达等价意图时，才创建或修改笔记文件。
4. 整理时优先归入最合适的已有课次；只有确实进入新的电路类型或知识单元时，才按当前最大课次顺延新建。
5. 新笔记完成后，更新 `README.md` 的进度表、阅读主线或文件说明，并检查 Obsidian 双链和图片路径。

## 教学型笔记写作规范

笔记必须是一份连贯的教材式教学稿，而不是术语表、公式清单或问答卷。

### 先建立因果，再给结论

每个重要概念都要按以下顺序展开：

1. 现实电路问题或学习困难是什么；
2. 为什么需要引入这个概念；
3. 它解决了什么问题；
4. 它与前面的阻抗、谐振、$Q$ 或能量交换有什么关系；
5. 最后才给正式定义、公式和计算方法。

不能把多个术语、定理和公式连续堆砌而不解释因果关系。用户的问题要被吸收进一条完整讲解主线，不能写成“问题：……答案：……”。

### 公式必须伴随解释

每引入一个公式，必须说明：

- 公式描述的是哪个电路量或哪段物理过程；
- 每个变量、角标和单位的含义；
- 为什么公式采用这种形式，关键近似来自哪里；
- 在串联、并联、抽头或有载条件下如何变化；
- 适用条件、适用范围和容易误用的地方。

公式不能代替解释。直觉、物理过程、简单例子和公式必须互相印证。不要用“显然”“容易看出”“只需记住”跳过推理。

### 推荐讲解顺序

1. 说明研究对象、实际电路和要解决的问题；
2. 回顾必要的交流阻抗、储能元件和相量知识；
3. 从能量交换或失谐现象引出新概念；
4. 解释为什么需要等效、折算或匹配；
5. 给出正式定义和数学表达；
6. 用一个贯穿性例子展示公式怎样工作；
7. 回到电路，解释结果的物理意义；
8. 说明适用条件、局限和常见误区；
9. 最后给简短的复习路线。

段落之间要有过渡，说明“为什么下一步要引入这个概念”。标题应体现知识层次，不要把每个术语单独设为一节。

### 语言要求

- 面向初学者使用清楚、连续的解释，不假设读者已经理解教材中未说明的概念。
- 专业术语第一次出现时，用通俗语言解释含义和引入原因。
- 类比只能帮助建立直觉，必须说明边界，不能替代严格定义。
- 若教材存在不同符号或串并联等效约定，要说明区别。

若一段内容删除所有公式后只剩下术语名称和结论，说明解释不足，必须重写。

## 课程专属规则

- 本课程以**电路类型和核心问题**组织：谐振回路、选频、阻抗变换、放大、振荡、混频、调制与解调等，应按实际学习进度逐步扩展。
- 每篇涉及具体电路的笔记必须配足必要的 SVG 图：电路结构、真实损耗的等效模型、相量图、幅频/相频曲线、阻抗折算或功率流向图。图要服务理解，不为凑数量添加。
- 图片放入课程对应的 `.assets` 或 `assets` 目录，使用 Obsidian 可识别的相对路径；图中只写必要标签，完整推导放在正文。
- 例题尽量贯穿同一个电路或同一类参数，展示“等效—折算—求阻抗—解释带宽或匹配”的完整过程。
- `PPT/` 中的公式和图片必须经过解释、核对并写入编号笔记后，才能计入学习进度。

## Markdown、数学与软件约束

- 输出或修改 Obsidian Markdown 文件时：行内公式使用 `$...$`，独立公式使用 `$$...$$`。
- Codex 聊天回复中：行内公式使用 `\(...\)`，独立公式使用 `$$...$$`。
- 数学内容必须使用正确的 LaTeX 排版，不使用纯文字或 Unicode 数学记号代替公式。
- Keil、ESP 项目不代为编译。
- 不擅自删除课件、作业、图片或历史笔记；确需重排时保留可追溯关系。

## 完成检查

修改完成后逐项确认：

- [ ] 讲解按照知识依赖关系展开，没有退化为问答卷或公式清单。
- [ ] 每个公式都有变量、对象、动机、适用条件和用途说明。
- [ ] 电路笔记含必要且正确的 SVG/模型图，路径可打开。
- [ ] 只在用户要求时写入笔记文件。
- [ ] 新增或重组笔记后已更新 `README.md`。
