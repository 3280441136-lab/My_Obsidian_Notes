## 推荐阅读顺序

如果准备复习，不要按公式名称跳读，而应沿下面的问题链阅读：

1. 先在第1课确定研究对象：观察的是一次输出、离散时刻序列还是连续时间波形，以及各次输出是否独立、统计规律是否平稳。
2. 再在第2课理解信息怎样从“具体结果的意外程度”发展为“整个信源的平均不确定性”。
3. 第3课把一个变量扩展到两个变量，区分整体不确定性、已知某变量后的剩余不确定性，以及熵的分解顺序。
4. 第4课把连续多次输出看成一个大符号，用链式法则解释无记忆信源的熵为什么可加。
5. 第5课反过来考察有记忆信源，说明历史信息如何降低下一符号的不确定性，并比较三种熵。
6. 第5课末尾进一步用熵率统一两类信源冗余，再在第6课建立离散信道的输入、输出和转移概率模型。
7. 第7课从后验概率算出信道疑义度，再用互信息衡量接收端实际获得的信息，并区分特殊信道与多级传输。
8. 第8课固定转移矩阵、优化输入分布，先区分无损与无噪，再计算 BEC、BSC，最后分别检查行列排列、统一正误概率与列分块，辨认对称、均匀和准对称信道。
