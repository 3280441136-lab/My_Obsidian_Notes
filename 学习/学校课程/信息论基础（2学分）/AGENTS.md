# 信息论基础项目协作约束

## 文件分工

- `README.md`：课程导航、学习进度、知识主线和文件结构的唯一状态来源。
- `AGENTS.md`：约束 Codex 如何讲解、如何写教材式笔记、如何维护概率与熵符号。
- `第N课 主题.md`：已经整理并核对的主笔记。
- `assets/`：概率树、信源模型、熵关系、状态转移和计算流程图。
- `PPT/`、`作业留档/`：课件与作业材料，不自动视为已掌握内容。

不要在 `AGENTS.md` 中复制一份学习进度表；状态以 `README.md` 为准。

## 新对话工作流

1. 先读取 `README.md`，再浏览 `第N课*.md` 的文件名、标题和关键图，确认已经覆盖的知识边界。
2. 把用户提供的课堂关键词、讲课脉络和疑问视为一节新课的原始记录。先补齐缺失的概率、随机变量和对数知识，再按知识依赖关系还原课程主线。
3. 默认只在聊天中讲解和答疑。只有用户明确要求“整理成笔记”“保存课堂内容”或等价表达时，才创建或修改笔记。
4. 优先归入最合适的已有课次；只有形成新的知识单元时才新建下一课。信源编码、信道容量、信道编码和率失真理论应分别扩展。
5. 写入后更新 `README.md`，并检查概率和为一、符号一致、极限条件、单位和图片路径。

## 教学型笔记写作规范

### 从不确定性与编码问题出发

每个重要概念都要按以下顺序展开：

1. 信源建模或压缩中遇到什么问题；
2. 为什么概率能够描述“意外程度”；
3. 为什么单个符号的信息量还不够，需要平均量；
4. 新概念与前面的自信息、熵、条件熵或相关性有什么关系；
5. 最后才给定义、性质和计算方法。

不能把定义、定理和公式连续堆砌，也不能写成问答卷。用户的问题要融入一条完整的知识链。

### 公式必须解释

每引入一个公式，必须说明：

- 公式描述的是符号、消息、信源、联合变量还是条件预测；
- 随机变量、取值、概率、对数底和单位的含义；
- 为什么概率或条件概率以这种形式进入；
- 何时是 $H(X)$，何时是 $H(X\mid Y)$，何时是 $H(X,Y)$，何时是互信息；
- 适用条件、极限过程和常见误用。

尤其不要混淆：

- 单条消息的 self-information 与信源 entropy；
- 无记忆信源的 $N$ 次扩展与有记忆信源；
- 条件熵、联合熵和互信息；
- 每个符号的熵与每秒的信息速率。

公式不能代替解释。概率树、单位检查、简单信源和公式必须相互对应。

### 推荐讲解顺序

1. 研究对象、信源和压缩/通信问题；
2. 必要的概率、随机变量和对数知识；
3. 用具体信源发现直观“信息量”不足；
4. 说明为什么需要自信息、熵或条件量；
5. 给正式定义和数学表达；
6. 用一个贯穿性概率分布演示计算；
7. 解释编码长度、冗余和预测意义；
8. 说明适用条件、局限和误区；
9. 给出复习路线。

标题体现知识层次，不要每个术语单列一节。段落之间要说清下一步为什么这样展开。

### 语言要求

- 面向初学者连续解释，不假设读者已经掌握教材外概念。
- 专业术语第一次出现时，用通俗语言解释含义和引入原因。
- 避免“显然”“容易看出”“只需记住”等跳步表达。
- 若不同教材使用 $\log_2$、$\ln$ 或其他底，必须说明对应的 bit、nat 等单位约定。
- 类比必须说明边界，不能代替严格定义。

## 课程专属符号规则

- 随机变量用大写 $X,Y,Z$，具体取值用小写 $x_i,y_j,z_k$；概率写为 $P(x_i)$ 或 $p_i$，并在同一笔记内保持一致。
- 默认以 $\log_2$ 表示信息量，单位为 bit；若使用自然对数，必须明确单位为 nat，并说明换算关系。
- $I(x_i)$ 表示单个事件或符号的自信息，$H(X)$ 表示信源每个符号的平均自信息；不得把二者等同。
- $N$ 次扩展要说明消息长度、扩展信源符号数，以及总熵与平均每符号熵的关系。
- 有记忆信源必须说明平稳性、极限存在条件，以及 $H(X_n\mid X_1,\ldots,X_{n-1})$ 趋于熵率的含义。
- 涉及编码时，应把“熵给出的理论界限”与“某种具体编码的实际平均码长”分开。

## Markdown、数学与软件约束

- 输出或修改 Obsidian Markdown 文件时：行内公式使用 `$...$`，独立公式使用 `$$...$$`。
- Codex 聊天回复中：行内公式使用 `\(...\)`，独立公式使用 `$$...$$`。
- 数学内容必须使用正确 LaTeX，不用纯文字或 Unicode 数学记号替代公式。
- 图片放入 `assets/`，使用 Obsidian 可解析的相对路径。
- Keil、ESP 项目不代为编译。
- 不擅自删除课件、作业、原始汇总稿或历史图片。
