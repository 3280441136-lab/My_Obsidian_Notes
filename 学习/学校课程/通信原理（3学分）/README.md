## 英文考试词汇索引

复习时不要只背中文。对下列重点，应能做到：看到英文题干知道研究对象，看到符号知道变量含义，并能用英文术语识别设问。

### 系统、模型与分类

| English term | 中文 | 需要掌握的识别点 |
|---|---|---|
| message / information / signal | 消息 / 信息 / 信号 | 三者不是同义词：消息是载体内容，信息是不确定性消除量，信号是物理表示 |
| communication system | 通信系统 | 一般模型及各模块的输入输出 |
| information source / transmitter / channel / receiver / destination | 信源 / 发射机 / 信道 / 接收机 / 信宿 | 通信系统一般模型 |
| source encoder / decoder | 信源编码器 / 译码器 | 压缩冗余、提高有效性 |
| channel encoder / decoder | 信道编码器 / 译码器 | 加入受控冗余、提高可靠性 |
| modulator / demodulator | 调制器 / 解调器 | 基带与带通信号之间的转换 |
| analog / digital communication | 模拟 / 数字通信 | 按信道中信号特性分类 |
| baseband / passband transmission | 基带 / 频带（带通）传输 | 是否经过调制搬移频谱 |
| simplex / half-duplex / full-duplex | 单工 / 半双工 / 全双工 | 按通信双方工作方式分类 |
| multiplexing (FDM / TDM / WDM / CDM) | 复用（频分/时分/波分/码分） | 按资源维度共享信道 |
| frequency band / wavelength | 频段 / 波长 | $c=f\lambda$ 及传播特性 |

### 信息度量

| English term | 中文或符号 | 需要掌握的识别点 |
|---|---|---|
| self-information / information content | 自信息 $I(x_i)$ | 单个符号或消息包含的信息量 |
| probability of occurrence | 出现概率 $P(x_i)$ | 概率越小，自信息越大 |
| entropy / average information | 熵 $H(X)$ | 信源每个符号的平均信息量 |
| discrete memoryless source (DMS) | 离散无记忆信源 | 各次输出相互独立 |
| source redundancy | 信源冗余 | 熵小于最大可能熵所反映的可压缩空间 |
| information rate | 信息速率 | 信源每秒产生的平均信息量 |

### 有效性与可靠性

| English term | 中文或符号 | 需要掌握的识别点 |
|---|---|---|
| effectiveness / reliability | 有效性 / 可靠性 | 通信系统性能的两个主要方面 |
| symbol rate / signaling rate | 码元速率 $R_s$ | 单位常用 baud |
| bit rate / information rate | 比特速率 $R_b$ | 单位常用 bit/s |
| bandwidth $B$ | 带宽 | 不要与码元速率直接等同 |
| bandwidth efficiency | 频带利用率 | 单位带宽内传输信息或符号的效率 |
| probability of error / symbol error rate | 错误概率 / 误码元率 | 判断接收符号是否正确 |
| bit error rate (BER) | 误比特率 | 错误比特数与总比特数之比 |
| signal-to-noise ratio (SNR) | 信噪比 | 模拟系统可靠性的重要指标 |

### 英文题干常用动作词

| English verb | 含义 | 答题动作 |
|---|---|---|
| define | 定义 | 给出精确定义并说明符号 |
| derive | 推导 | 展示公式来源和关键步骤 |
| express | 表示、写出 | 用指定变量写出关系式 |
| calculate / determine | 计算 / 确定 | 代入数据并保留单位 |
| compare | 比较 | 指出共同点、差异和适用条件 |
| explain | 解释 | 说明原因和物理意义，不能只写公式 |
| show that | 证明、验证 | 从已知条件推出目标式 |
