## 阅读路线

复习时建议按以下顺序：

1. 先读[[01 第1课 通信系统的基本概念与模型]]，弄清通信系统究竟在传输什么。
2. 再读[[02 第2课 通信系统的分类与通信方式]]，学会判断分类依据。
3. 接着读[[03 第3课 信息及其度量]]，区分具体消息的总信息量和信源的熵。
4. 读[[04 第4课 通信系统的性能指标]]，把码元速率、信息速率、带宽和错误概率放在一起比较。
5. 再读[[05 第5课 从确知信号到随机过程]]，完成从确定波形到随机过程和功率谱描述的过渡。
6. 最后读[[06 第6课 平稳性、高斯随机过程与线性系统]]，掌握平稳性、遍历性、高斯性和 LTI 系统的性质。
