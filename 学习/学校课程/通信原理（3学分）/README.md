# 通信原理（3学分）学习笔记

这门课的笔记不按课件页码堆积，而按知识依赖关系整理。这样既能对应学校的授课进度，也能在复习时沿着“系统模型 -> 系统分类 -> 信息度量 -> 性能指标”的路线连续阅读。

学校“第一讲”对应本笔记第 1、2 课；学校“第二讲”对应第 3、4 课。把一讲拆开，是为了避免系统结构、分类、信息论和性能指标相互耦合。

## 阅读路线

复习时建议按以下顺序：

1. 先读[[第1课 通信系统的基本概念与模型]]，弄清通信系统究竟在传输什么。
2. 再读[[第2课 通信系统的分类与通信方式]]，学会判断分类依据。
3. 接着读[[第3课 信息及其度量]]，区分具体消息的总信息量和信源的熵。
4. 最后读[[第4课 通信系统的性能指标]]，把码元速率、信息速率、带宽和错误概率放在一起比较。
