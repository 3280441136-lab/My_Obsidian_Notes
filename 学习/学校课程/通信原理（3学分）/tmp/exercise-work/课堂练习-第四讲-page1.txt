练习三：Gaussian Random Processes 
判断(T or F): 
(   )  For a general random process, strict-sense stationary implies wide-sense stationary.  
对于一般随机过程，严平稳可以推出宽平稳。 
(   )  If two random variables are uncorrelated, they must be statistically independent.  
      若两个随机变量不相关，则它们一定统计独立。 
(   )  For Gaussian random variables, uncorrelated means statistically independent. 
      对于高斯随机变量，不相关等价于统计独立。
