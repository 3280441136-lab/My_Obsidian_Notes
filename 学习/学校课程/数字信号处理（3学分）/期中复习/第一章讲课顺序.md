# 第一章讲课顺序：离散时间信号与系统

教材范围为 1.1 至 1.4.3（书内第 9—48 页；扫描 PDF 约第 21—60 页）。顺序按知识依赖微调，教材节号仍逐一对应。每行可按理解进度拆成多轮，题目在相应知识讲完后穿插，不按页码堆题。

**讲课节奏修正（2026-11-12）：** 01、02 已讲得过细，后续不再以同等篇幅处理基础运算。02 中尚未讲的绝对可和、能量、平均功率只在遇到对应题或章末公式归纳时用短表补齐，不单独开长课。03 只快速建立解卷积所需的冲激、阶跃和矩形序列。04、06—11 是主要做题单元；05 与 12 按实际作业和试卷题压缩或展开。每个单元的长短以题型和理解困难决定。

| 单元 | 教材位置 | 核心理解目标 | 配套题目与归纳 |
| --- | --- | --- | --- |
| 01 序列和样点编号（已讲，后续快速调用） | 1.1.1，1.1.2 的移位、翻褶 | 识别整数下标及简单位置变换 | 只在题目需要时复用下标映射 |
| 02 序列的数值运算与尺度（已讲基本运算） | 1.1.2 | 识别逐点运算、累加、差分、抽取、插零；能量等只作短表归纳 | 不再单独用图示逐点讲基础操作 |
| 03 冲激、阶跃和典型序列（快速前置） | 1.1.5 与 1.1.7 的必要前置 | 掌握冲激筛选、阶跃和矩形序列的最低限度用法 | 紧接卷积题，不单独拉长 |
| 04 卷积和的来源与计算 | 1.1.3、1.1.7、1.2.3 | 输入由移位冲激组成，LTI 输出由移位响应叠加；求和边界取交集 | 作业 1.1、1.2 全部、1.14 的卷积部分；教材卷积例题；有限与无限等比和 |
| 05 相关运算（简讲） | 1.1.4 | 知道错位配对的含义及其与卷积的区别 | 先给最小对照，遇相应题再展开 |
| 06 序列的周期性 | 1.1.6 | 相位每步增加固定量，整数步后能否回到原值 | 作业 1.4 指定五小问；周期判断流程和退化情况 |
| 07 一般系统与 LTI | 1.2.1 至 1.2.3 | 对同一输入输出映射分别检验线性、时不变，并理解冲激响应 | 作业 1.7 指定四小问；试卷对应判断题 |
| 08 因果性与稳定性 | 1.2.4 至 1.2.5 | 一般系统用定义，LTI 系统用冲激响应判据 | 作业 1.8 指定三小问及 1.7 的对应性质；判据层级对比 |
| 09 常系数线性差分方程 | 1.3 | 方程、边界条件和初始静止共同决定系统；递推求冲激响应 | 作业 1.5、1.14；教材差分方程例题；零输入与零状态区分 |
| 10 从连续波形到理想抽样 | 1.4.1 | 抽样间隔与样点、理想冲激抽样以及频谱副本 | 教材抽样例题；与序列的区别 |
| 11 时域抽样定理 | 1.4.2 | 频谱副本何时重叠、最低抽样率及理想恢复 | 教材抽样定理例题；混叠判断 |
| 12 实际抽样 | 1.4.3 | 脉冲抽样与保持等实际环节如何影响频谱和恢复 | 教材实际抽样图示及例题；理想与实际模型对照 |

单元 04 在教材 1.1.3 与 1.1.7、1.2.3 之间往返，是为了先建立冲激与系统模型，再完整讲卷积；单元 05 回到 1.1.4。第一章范围外的 1.4.4 至 1.4.7 暂不讲。
