# 期中复习对话约束

- 先读本目录的 `复习进度.md`、`第一章讲课顺序.md`、`第一章题目清单.md`，再开始授课；同时遵守上级 `AGENTS.md`。
- 期中总范围以 `../教材/期中和期末考试参考教材学习内容.jpg` 为准：第一章 1.1 至 1.4.3，第二章 2.1 至 2.4，第三章 3.1 至 3.4.9 与 3.5.1，第四章 4.1 至 4.2、4.5、4.9.1。这里的文件只安排第一章；后续章节在新对话另建安排。
- 本次对话只复习第一章。按知识依赖小节推进，每轮只处理一个能独立理解的单元。先用具体序列或系统呈现问题和变化，再给术语、公式和解题步骤；不要把课表一次性当作讲稿发送。
- **按考试作用分配篇幅。** 备课先看老师布置的作业与已核对的试卷题型，再决定某个教材内容需要详讲、简讲还是只在做题时补一句。覆盖考试范围不等于平均讲解每个定义。第一章的主要解题训练放在卷积、周期性、系统性质、因果与稳定、差分方程和抽样。
- **先筛考点再授课（用户 2026-11-13 明确要求）。** 教材范围图只是可考章节的上界，不要求逐节、逐例题覆盖。以老师实际布置的作业题和往年试卷中出现的题型为主要依据；两者都没有涉及、老师也未特别强调的教材内容，默认不安排独立讲解和例题。它若是解已考题的必要前置，只用最短说明补上。不要为了“教材里有”而继续推进一整节。相关运算及其后续例题本次已被用户判定为非考点，不再继续讲；直接转向周期性。
- **基础工具讲到够用就停。** 序列的移位、翻褶、累加、差分、抽取、插零，以及绝对可和、能量和平均功率等若没有相应重点题，只给简明含义、最小例子或一张对照表；不要单独做长篇推导、逐点列值或连续贴多幅图。遇到真正要用它的题再补必要步骤。
- 不用篇幅、复杂措辞或反复提醒制造“这很难、很重要”的感觉。开讲时先说清本小节在考试题中的用途；容易的部分平实、快速讲完，难点留给需要建立模型或容易误判的题。用户认为某段不重要时立即调整节奏，不按原计划继续展开。
- 每节讲完前交代研究对象、与邻近概念的区别、适用条件、一个可逐项核对的例子；在相应位置整理公式、常用变换及同类题方法。图形重要时贴出教材或题目原图并引导读图。
- 题目按 `第一章题目清单.md` 追踪。选来讲的题必须写全已知条件和全部设问，图形关系用文字说明并贴原图；需要建模或辨析的题不跳关键步骤，同类题归纳解题入口。机械代入题保留关键一步即可。课后只把本轮实际讲完的范围记入进度，不能把已有解析误记为已复习或已掌握。
- 聊天行内公式用 `\(...\)`，独立公式用 `$$...$$`；写入 Obsidian Markdown 用 `$...$` 与 `$$...$$`。因果与状态变化用 Mermaid flowchart，知识层级用 mindmap；仅在关系确实需要图示时使用。
- 本目录存跨对话安排和进度，不在用户未明确要求时创建成品课程笔记。若用户表示没懂，停在当前对象补前置理解，再继续原顺序。
