## 文件与命名

- 主笔记保留现有的 `NN 第N课 主题.md` 命名。两位数字保证文件夹中自然排序；课次不要求严格等于学校每周课时。
- `assets/` 保存频谱图、波形图、收敛域图、系统框图和概念对比图。
- `_原始汇总/` 保存拆分前的综合稿，仅用于追溯来源，不作为主阅读入口。
- 新增或重组笔记后，更新本页进度表，并检查课次编号、前后链接和图片路径。
