# 3. 模块 A1：信号与系统

## 3.1 它在生物医学超声中的定位

信号与系统不是一门孤立的基础课。它是把超声研究拆成可分析环节的语言：**什么东西随时间或空间变化？它经过什么过程？该过程怎样改变它？最后得到什么可测量的数据？**

在一个基础脉冲回波超声实验中，可以先把研究链写成：

$$
x(t)\rightarrow H_{\mathrm{TX}}\rightarrow p_{\mathrm{tx}}(t)\rightarrow H_{\mathrm{body}}\rightarrow p_{\mathrm{echo}}(t)\rightarrow H_{\mathrm{RX}}\rightarrow r(t)\rightarrow \mathrm{ADC}\rightarrow r[n]
$$

上式暂时不要求你计算。它只表达如下事实：

```text
发射电压波形
-> 发射端与探头
-> 进入组织的声压波形
-> 组织中的传播、反射和散射
-> 返回探头的回波声压
-> 接收探头与电子前端
-> 连续电压回波
-> 模数转换
-> 计算机中的离散回波数据
```

其中：

- `x(t)`、`p_tx(t)`、`p_echo(t)`、`r(t)` 和 `r[n]` 都是不同阶段的**信号**；
- `H_TX`、`H_body`、`H_RX` 分别代表发射/探头、组织传播、接收链路这些**系统或过程**；
- 研究者不能只看最后一条曲线。若回波变弱，原因可能来自发射、组织衰减、反射、接收增益或采样设置。信号与系统帮助你定位该从哪里查证。

对你的导师方向而言，这个模块尤其重要，因为“非线性”意味着某一段过程的响应可能随输入声压幅度改变。在线性近似下，输入加倍，输出会按比例变化；发生明显非线性时，可能出现新的谐波或波形畸变。以后我们会用这个框架理解为什么不能把所有过程都当成同一种简单系统。

# 4. 当前单元 A1-01：信号、系统、输入输出与边界

**状态：进行中**  
**本单元只解决一个问题：在超声科研中，什么是信号，什么是系统，它们如何被明确区分？**

## 4.1 信号是什么

信号是某个可观测量随自变量变化而携带的信息。自变量最常见是时间，也可以是空间位置、探头阵元编号、频率或图像坐标。

在你未来的超声研究中，以下都可能是信号：

| 名称 | 自变量 | 振幅代表什么 | 为什么研究者关心它 |
| --- | --- | --- | --- |
| 发射电压波形 | 时间 | 加到发射端或探头上的电压 | 决定探头被如何激励 |
| 声压波形 | 时间与空间 | 介质中声压的扰动 | 描述声波强弱、波形变化和谐波 |
| 射频回波 | 时间 | 接收端得到的连续或采样电压 | 保留原始回波信息，是许多处理步骤的输入 |
| 频谱 | 频率 | 各频率成分的幅度或能量 | 可观察基频、谐波、带宽和噪声 |
| B 超图像 | 空间位置 | 回波处理后的亮度 | 用于观察组织结构和成像质量 |
| 某个定量指标 | 实验条件/样本编号等 | 例如谐波幅度、信噪比、分辨率 | 用于比较方法、条件或样本差异 |

“信号”不等于“声音”。发射电压、探头输出电压、数字采样数组和图像都是信号；超声声压只是其中一个物理阶段。

## 4.2 系统是什么

系统是一个把输入按某种物理规律、电子规律或计算规则转化为输出的对象或过程。

它可以是一个实体设备，也可以是一段物理传播过程，或一段算法：

| 系统/过程 | 输入 | 输出 | 在研究中可能要确认什么 |
| --- | --- | --- | --- |
| 发射探头 | 电压激励 | 发射声压波形 | 中心频率、带宽、效率、是否饱和 |
| 生物组织或仿体 | 入射声波 | 透射波、反射波、散射回波 | 声速、衰减、散射、非线性、边界条件 |
| 接收探头 | 回波声压 | 微弱电压信号 | 灵敏度、频响、噪声 |
| 接收前端 | 微弱电压 | 放大和滤波后的电压 | 增益、带宽、噪声、饱和、动态范围 |
| ADC | 连续电压 | 离散样本 | 采样率、量化位数、触发与同步 |
| 波束形成算法 | 多通道离散回波 | 扫描线或图像 | 延时规则、孔径、聚焦方式、插值 |

“系统”也不等于“一台仪器”。例如，组织本身就是一个重要系统；一个接收前端加上 ADC 也可以合成一个更大的系统。研究开始前，先划定系统边界，才能知道哪些因素被控制、哪些因素会干扰结论。

## 4.3 输入、输出和系统边界：科研里最常用的三句话

面对一张论文的结果图，你应先写出下面三句话：

```text
研究者控制或提供的输入是：______。
研究者关心并测量的输出是：______。
在这两者之间，作者定义/隐含的系统边界是：______。
```

举例：若论文研究“提高激励幅度后，二次谐波是否增强”，一个初步标注可以是：

```text
输入：不同幅度的发射电压或入射声压。
输出：接收信号频谱中的二次谐波幅度。
系统边界：探头发射、传播介质、反射/接收与频谱分析流程。
```

但这还不够。你还要识别作者是否控制了探头增益、传播距离、温度、样本差异和接收设置；否则“谐波增强”可能不是所研究非线性机制造成的。
