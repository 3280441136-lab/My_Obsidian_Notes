# 国内本科生科研名词地图：保研、考研与读研视角

> 面向零基础本科生。先记住一句最重要的话：  
> **SCI、一区、IEEE、影响因子、第一作者，不是在描述同一件事。**  
> 它们分别可能在说“论文在哪里发表”“被哪个数据库收录”“期刊在同类期刊中的位置”“谁做了主要工作”。

---

## 1. 先看全图：一篇论文身上可以同时贴很多标签

假设有一篇论文的信息是：

> 小王是一作，导师是通讯作者；论文发表在 *IEEE Transactions on Ultrasonics, Ferroelectrics, and Frequency Control*；该刊由 IEEE 出版；论文被 Web of Science 的 SCIE 和 Scopus 收录；该期刊在某个 JCR 学科类别为 Q1，且在某年度中科院分区表的某一口径为二区。

这段话看起来很复杂，其实是在回答六个不同问题：

| 它在问什么 | 上例中的回答 | 这类词的作用 |
| --- | --- | --- |
| 谁贡献了工作 | 小王一作、导师通讯作者 | 作者与责任 |
| 文章放在哪里 | 某一本具体期刊 | 发表载体 |
| 谁运营/出版它 | IEEE | 学会或出版社 |
| 哪个数据库能检索到它 | SCIE、Scopus | 文献索引/数据库 |
| 这本期刊在同类期刊中大致排在哪 | JCR Q1、中科院二区 | 期刊评价/分区 |
| 文章处于什么状态 | 已发表、已收录 | 出版进度 |

**关键结论**：

- “IEEE”通常是出版者或学会，不等于“SCI”，也不等于“一区”；
- “SCI/SCIE”是索引，不是某一本期刊，更不是论文奖项；
- “一区/二区/三区/四区”通常是在说期刊分区，不是在给单篇论文分等级；
- “一作”说的是作者贡献顺序，不保证期刊一定高，也不因为期刊高就自动成为一作；
- 同一篇论文可以同时拥有上表里的多个标签，彼此不冲突。

把学术术语想成填写一张信息卡，而不是背一串名头：

```text
论文题目
├─ 作者：谁是一作？谁通讯？是否共同一作？
├─ 载体：具体是哪本期刊或哪个会议？
├─ 出版方：IEEE、Elsevier、Springer、Nature Portfolio、某学会……
├─ 收录：SCIE、EI Compendex、Scopus、PubMed、CSCD……
├─ 评价：JIF、JCR Q1–Q4、中科院一区–四区……
└─ 状态：投稿、外审、返修、录用、在线、见刊、收录……
```

# 2. 你目前所处的路径：保研、考研、读研分别是什么

## 2.1 保研：推免，不是“有论文就一定能去读研”

“保研”的正式说法是**推荐优秀应届本科毕业生免试攻读研究生**，常简称“推免”。一般是：

```text
本校根据官方规则给出推免资格/名额
-> 你向目标高校或院系报名（夏令营、预推免或正式推免阶段）
-> 目标院系考核、面试或复试
-> 获得拟录取资格并完成推免系统流程
```

对多数学校的大多数专业而言，能否首先获得本校推免资格，**核心仍是课程成绩排名和学校的推免细则**。科研、竞赛、英语、志愿服务等是否折算加分、占多大权重、能否破格，完全由本校当年的正式规则决定。

科研在保研中的真实价值通常是：

- 对争取到目标院校导师或项目的认可有帮助；
- 在面试中证明你知道研究为何物，且能完成长期任务；
- 有真实论文、项目或复现成果时，能成为材料亮点；
- 但它通常**不能替代基础成绩、英语和推免资格本身**，更不能用“挂名论文”替代能力。

你现在最实际的策略是“双线并行”：守住成绩与英语的基本盘，同时用稳定、真实的科研准备提高面试竞争力。不要把全部时间押在“短期凑一篇论文”上。

## 2.2 考研：统考初试加复试，不是保研失败者才走的路

“考研”通常指全国硕士研究生招生考试及院校复试。大体流程是：

```text
报名 -> 初试（公共课与专业课）-> 国家线/院校线 -> 复试 -> 拟录取
```

科研经历对考研的作用主要在复试：你能讲清读过什么、做过什么、为什么选该方向，会比空泛地说“我热爱科研”可信。可是在初试分数不足时，科研经历通常不能代替笔试成绩；具体权重由目标院校招生简章和复试办法决定。

所以，考研准备的优先顺序不能本末倒置：先按目标院校要求确保初试能力，再用科研经历支撑复试表达和导师联系。

## 2.3 读研：不是“继续上课”，而是进入课题组做研究

硕士研究生常见两种培养类型：

| 名称 | 常见特点 | 需要避免的误解 |
| --- | --- | --- |
| 学术学位硕士，常称学硕 | 通常更偏学术研究与继续读博训练 | 不代表一定比专硕“更好”，要看目标、导师与培养方案 |
| 专业学位硕士，常称专硕 | 通常更强调专业实践和应用能力 | 不代表完全不做科研；许多专硕同样在课题组做研究并可发表论文 |

具体毕业要求、是否必须发表论文、要求什么作者位次或期刊分区，**每个学校、学院、专业、入学年份都可能不同**。只认本校研究生院、学院培养方案和导师的最新说明，不能拿别人的截图或旧规则当依据。

研究生三年常见节奏是：

```text
前期：补课程、读文献、进入课题、学方法
中期：复现、实验/仿真/数据分析、形成一个可回答的小问题
后期：补证据、写论文/学位论文、答辩、求职或申博
```

导师、课题组、实验室通常不是同义词，但日常会混用：

- **导师**：对你的培养、课题指导和学位过程承担责任的教师；
- **课题组**：围绕一位或数位教师、一个研究方向共同工作的学生和研究人员；
- **实验室**：可能指物理场地、仪器平台，也可能泛指一个更大的研究组织。

# 3. 论文发表在哪里：期刊、会议、出版社和学会

## 3.1 期刊：按卷、期持续出版的论文载体

**期刊（journal）**类似一个持续出版的专业刊物，但它不是面向大众的杂志。一篇期刊论文通常经历编辑初筛和同行评审，篇幅相对完整，方法、结果、讨论和参考文献也更详细。

在声学与生物医学超声中，你日后可能见到的不是“叫 SCI 的期刊”，而是具体名称，例如：

- *IEEE Transactions on Ultrasonics, Ferroelectrics, and Frequency Control*；
- *Ultrasound in Medicine & Biology*；
- *The Journal of the Acoustical Society of America*；
- *Physics in Medicine & Biology*。

这些是**具体期刊名**。看论文时，应先问“它具体发表在哪一本期刊”，再查其出版方、数据库收录、分区和口碑。

常见书目信息的含义：

```text
作者. 文章题目. 期刊名. 年份; 卷(期): 页码或文章号. DOI
```

- **卷（volume）**：期刊按年度或其他规则累计的出版单位；
- **期（issue）**：一卷中的某一期；
- **页码/文章号**：定位文章的位置；
- **DOI**：数字对象唯一标识，通常是找论文最稳的钥匙；
- **引用格式**：按学科和期刊要求书写的文献信息格式，不是论文的质量等级。

## 3.2 会议：研究者交流的场合，会议论文是另一种载体

**学术会议（conference）**是研究者在某一时间、主题下交流成果的活动。可能包含口头报告、海报、教程、圆桌、会议摘要和论文集。

**会议论文（conference paper / proceedings paper）**则是收录在会议论文集中的论文。不同学科差异很大：

- 在计算机科学和部分电子信息方向，顶级会议论文可能是非常重要的正式成果；
- 在医学、物理、声学等方向，会议常用于先报告阶段性结果，期刊论文往往仍是完整研究的主要载体；
- 有些会议只收一页摘要或海报摘要，这与完整同行评审会议论文并不相同。

因此听到“我发了个会议”时，必须继续问：**哪个会议？是摘要、海报、全文论文，还是会议后的期刊扩展稿？是否经过何种审稿、被何处收录？**

## 3.3 IEEE：一个专业学会和出版者，不是一个“论文等级”

**IEEE** 全称是 Institute of Electrical and Electronics Engineers，是电气、电子、通信、计算机、超声换能器等许多工程领域的重要专业学会。它会：

- 组织学术会议；
- 出版期刊和会议论文集；
- 制定部分技术标准；
- 运营 IEEE Xplore 等文献平台。

所以，“IEEE 会议”通常表示由 IEEE 或其下属组织举办/技术支持、论文进入 IEEE 体系的会议；“IEEE 期刊”表示由 IEEE 出版的具体期刊。二者不等价，且 IEEE 旗下不同会议和期刊的声誉、审稿严格程度、收录情况差异很大。

特别要会判断这一句：

> “这是一篇 IEEE 会议论文。”

它只说明载体和组织关联。你还需要查：会议的全称和历届情况、收录范围、是否被 **EI Compendex** 或 **Scopus** 收录、论文是全文还是摘要、是否符合你学校对成果的认定。**IEEE 不会自动等于 EI，也不会自动等于 SCI，更不自动等于一区。**

## 3.4 出版社与数据库不是一回事

| 名称类别 | 它做什么 | 例子 | 不应该把它误认为 |
| --- | --- | --- | --- |
| 学会/出版社 | 组织同行评审与出版、运营期刊/会议 | IEEE、Elsevier、Springer Nature、Wiley、AIP、ASA | 期刊分区或论文收录等级 |
| 文献平台 | 让你检索、阅读或下载文章 | IEEE Xplore、ScienceDirect、SpringerLink、知网 | 同行评审本身或索引体系 |
| 引文数据库/索引 | 收录和关联文献、作者、引用数据 | Web of Science、Scopus、EI Compendex、PubMed、CSCD | 出版社或期刊名称 |
| 期刊评价体系 | 基于某种规则给期刊做统计或分区 | JIF、JCR Quartile、中科院分区 | 对单篇文章的直接判决 |

# 4. SCI、SCIE、EI、Scopus、PubMed：它们是“检索系统”

## 4.1 SCI 和 SCIE：国内口语里的“SCI 论文”到底是什么

**SCI** 是 *Science Citation Index* 的缩写；**SCIE** 是 *Science Citation Index Expanded*。它们与 Clarivate 的 Web of Science 引文索引体系有关。

在国内校园口语中，“发 SCI”通常是指“论文发表在被 Web of Science 的 SCIE 收录的期刊中”。这种说法方便，但不严谨，因为：

- SCI/SCIE 是**索引体系**，不是出版社、期刊名或研究方法；
- 被 SCIE 收录的期刊有很多，学科、影响力和要求差异巨大；
- 某篇论文是否已能在 Web of Science 检索到，还涉及文章类型、出版时间和数据库更新；
- 学校若写“SCI 论文”，究竟认可哪些文献类型、以录用还是检索时间为准，必须看本校正式文件。

把它翻成一句人话：

> SCI/SCIE 解决的是“这篇论文能否被一个国际主流引文数据库按其规则检索和追踪引用”，不是“它一定非常厉害”。

## 4.2 EI：工程领域常见的另一套检索体系

**EI** 通常指 Engineering Village 中的 **EI Compendex** 工程文献数据库。工程学生常说“EI 期刊”或“EI 会议”，意思通常是相关期刊或会议论文集被 EI Compendex 收录。

它与 SCI/SCIE 的关系是“不同索引体系”，不是小学式的高低排序。对一个具体成果，正确问法是：

```text
它是期刊论文还是会议论文？
具体期刊/会议是什么？
它被 EI Compendex 收录了吗？本校是否认定这种收录？
```

不少 IEEE 会议希望被 EI 检索，但“希望”“宣称”与“最终已收录”不同。必须以数据库实际检索结果或学校认可证明为准。

## 4.3 Scopus 和 Web of Science：两套常用国际文献数据库

- **Web of Science（WoS）**：包含 SCIE、SSCI、AHCI、ESCI 等不同索引；
- **Scopus**：Elsevier 运营的另一套大型摘要与引文数据库。

两者收录范围、指标和更新节奏不同。同一刊物可能被两者都收录，也可能只被其中之一收录。不能说“Scopus 就是 SCI”或“Scopus 一定不如 SCI”。如果培养方案明确要求某一数据库，就只按该要求核对。

## 4.4 PubMed：医学文献入口，不是“SCI 的医学版”

**PubMed** 是美国国立医学图书馆提供的生物医学文献检索入口。医学超声、临床研究、生命科学文献常在这里检索。

它帮助你找医学论文，但“能在 PubMed 搜到”不等于“这是 SCI 论文”，也不等于期刊分区。它与 Web of Science 的角色不同。

## 4.5 还会见到的索引名词

| 名词 | 主要语境 | 你只需先记住 |
| --- | --- | --- |
| SSCI | 社会科学引文索引 | 社科方向常见，与你的声学方向通常无直接关系 |
| AHCI | 艺术与人文引文索引 | 人文艺术方向常见 |
| ESCI | Web of Science 中的一个索引 | 不能想当然与 SCIE 完全等同；看本校具体认定 |
| CPCI | 会议论文引文索引 | 有些会议论文会被它收录，仍要确认学校是否认可 |
| CSCD | 中国科学引文数据库 | 国内自然科学期刊语境常见 |
| CSSCI，常被叫“C 刊” | 中文社会科学引文索引 | 人文社科常见，通常不是超声科研的主战场 |
| 北大核心 | 《中文核心期刊要目总览》体系 | 国内中文期刊评价口径之一，不等于 SCI |
| 科技核心 | 中国科技论文统计源期刊等语境中的称呼 | 国内中文科技期刊的一种常见口径，需看具体认定文件 |

# 5. 一区、二区、三区、四区：说的是期刊，不是论文，也不只有一套

## 5.1 为什么同一句“这篇论文是一区”会让人困惑

“一区”至少可能是在说两套不同体系之一：

| 说法 | 属于谁的体系 | 基本划法 | 最常见误解 |
| --- | --- | --- | --- |
| JCR Q1、Q2、Q3、Q4 | Clarivate 的 Journal Citation Reports | 在某个学科类别中按排名分成四等份 | Q1 与中科院一区不是同义词 |
| 中科院一区、二区、三区、四区 | 中国科学院文献情报中心期刊分区表 | 有自己的分区规则和学科口径 | 把它当作 JCR 四分位的中文翻译 |

## 5.2 JCR 的 Q1–Q4：每类期刊中的四分位

JCR 会把某一学科类别中的期刊按指标排名并分成四段。口语中常用的理解是：

| JCR 分位 | 在该学科类别中的大致位置 |
| --- | --- |
| Q1 | 前 25% |
| Q2 | 25% 至 50% |
| Q3 | 50% 至 75% |
| Q4 | 后 25% |

但必须加上三句限制：

1. 一份期刊可能属于多个学科类别，在不同类别中 Q 值可能不同；
2. Q 值按年度变化，不能不写年份；
3. 这描述的是**期刊相对位置**，不直接证明其中每一篇文章的质量。

## 5.3 中科院分区：国内招生、毕业和考核中常被提到

国内口头所说“中科院一区、二区、三区、四区”，通常指**中国科学院文献情报中心期刊分区表**的结果。常见的入门理解为：

| 中科院分区 | 在本学科同类期刊中的常见位置理解 |
| --- | --- |
| 一区 | 前 5% 左右 |
| 二区 | 约 6% 至 20% |
| 三区 | 约 21% 至 50% |
| 四区 | 后 50% 左右 |

它不是简单的“四等分”，所以不能把“JCR Q1”翻译成“中科院一区”。例如，一本期刊可能是 JCR Q1，但在中科院分区口径下是二区或三区；反之也不能凭直觉判断。

## 5.4 查分区时必须问的四个问题

当有人说“这是一区”时，请立刻追问或自己确认：

1. 是 JCR Q1，还是中科院一区？
2. 是哪一个年份的版本？
3. 是大类分区还是小类分区？
4. 你所在学院、申请学校或导师在评价时认哪个口径？

不问这四个问题，单独说“一区”信息是不完整的。

## 5.5 影响因子：一个期刊的统计数，不是论文的分数

**影响因子**英文通常写作 Journal Impact Factor，简称 JIF 或 IF。它由 JCR 按其规则计算，用来描述某期刊近年文章的平均被引情况。它是期刊层面的指标。

以某一年为例，可用下面的简化式理解：

$$
\mathrm{JIF}_{Y}=\frac{\text{年份 }Y\text{ 对该期刊在 }Y-1\text{ 和 }Y-2\text{ 年发表可计入论文的引用次数}}{\text{该期刊在 }Y-1\text{ 和 }Y-2\text{ 年发表的可计入论文数量}}
$$

它不等于：

- 这篇具体论文被引用多少次；
- 一位作者的水平；
- 研究是否严谨；
- 你保研时必然能获得多少加分。

不同学科引用习惯差异很大，不能拿医学、材料、计算机、声学等方向的 IF 直接横向比较。

# 6. 作者、导师和论文贡献：一作、二作、通讯到底是谁

## 6.1 最常见的作者角色

| 名称 | 通常意味着什么 | 不能据此推断什么 |
| --- | --- | --- |
| 第一作者/一作 | 通常承担主要研究实施、分析与初稿写作 | 不代表其一个人完成所有工作 |
| 第二作者/二作及其他作者 | 有实质研究贡献 | 不等于“没什么用”或“必然比一作差很多” |
| 共同第一作者 | 论文明确注明两人或多人同等贡献 | 各学校是否按一作认定，必须查细则 |
| 通讯作者 | 负责投稿、学术责任与发表后联系；常为导师 | 不一定是做实验最多的人 |
| 共同通讯作者 | 多人共同承担通讯角色 | 认定方式取决于论文与学校规则 |
| 共同作者 | 论文署名中的所有作者 | 不代表每个人贡献相同 |

作者排序是课题组合作分工的记录，同时伴随学术责任。不要把它看成“名次游戏”。你应该尽早养成贡献留痕习惯：保存任务说明、实验记录、数据来源、代码提交、版本和汇报材料。这样当研究形成论文时，贡献讨论才有事实基础。

## 6.2 本科生最该避免的误区

- **误区**：“先拿一篇挂名论文再说。”  
  正解：没有实质贡献的署名存在学术诚信和培养风险，复试时也很容易被追问穿。
- **误区**：“非一作毫无意义。”  
  正解：真实、能解释清楚的合作贡献有价值；但在一些项目的硬性评价中，作者位次确实不同，必须早查目标单位规则。
- **误区**：“通讯作者就是老板，所有事都他做。”  
  正解：导师常负责研究方向、资源、质量和学术责任，学生会承担大量具体工作。

# 7. 从写完到检索到：一篇论文的状态词

```text
研究完成
-> 写稿（manuscript）
-> 投稿（submitted）
-> 编辑初筛（可能直接拒稿，desk reject）
-> 外审（under review）
-> 小修/大修（revision）
-> 录用（accepted）
-> 校样（proof）
-> 在线发表（online first）
-> 分配卷期/见刊（issue publication）
-> 被相应数据库检索（indexing）
```

这些状态不是同义词。尤其要分清：

- **投稿**：只是提交，绝不等于发表；
- **录用**：编辑决定接收，通常尚未完成排版与数据库更新；
- **在线发表**：文章已公开，可能尚未分卷期；
- **见刊**：编入正式卷期，具体认定因期刊和学校而异；
- **检索**：数据库已能查到，更新有滞后；
- **引用**：后来的其他文章在参考文献中使用了它，和“收录”不是同一件事。

## 7.1 同行评审与审稿意见

- **编辑（editor）**：判断论文是否适合期刊、是否送审，并在参考评审意见后作决定；
- **审稿人/评审人（reviewer）**：同行专家，重点检查问题、方法、证据和表述；
- **审稿意见（review comments）**：要求补充解释、补实验、改图、改统计，或指出严重问题；
- **回复信（response/rebuttal letter）**：逐条说明如何修改、为什么不能修改，必须有证据和礼貌；
- **撤稿（retraction）**：已发表论文因严重错误、失信或其他原因被正式撤回，后果严重。

# 8. 评价、引用与“顶刊”：哪些词需要降温理解

| 名词 | 是什么 | 正确用法 |
| --- | --- | --- |
| 被引次数 | 某篇论文被其他文献引用的次数 | 随时间、学科和数据库不同而变化，不能脱离领域比较 |
| h 指数 | 同时考虑发文数量和被引次数的作者/机构指标 | 只作粗略背景，不用来判断一个本科生是否值得培养 |
| 高被引论文 | 某一数据库按领域与年份给出的高引用标识 | 具体口径依数据库而定，不等于所有“被引多”的论文 |
| 顶刊 | 非正式口语，通常指本领域公认有影响力的期刊 | 必须说具体期刊和具体领域，不能把所有学科混在一起 |
| Nature/Science | 两本具体的综合性科学期刊 | 很有影响力，但不是所有好研究的唯一目标 |
| 预印本 | 正式同行评审前或过程中的公开稿件 | 用于交流新进展，阅读时核对其后续正式版本 |
| 开放获取（OA） | 读者可免费读到的出版模式 | 不等于低质量，也不等于必须收费 |
| APC/版面费 | 有些期刊要求作者支付的文章处理费 | 合规收费存在；不能因为收费就断定好或坏，要核验期刊真实性 |
| 掠夺性期刊/会议 | 以收费为核心、审稿和出版质量可疑的机构或活动 | 遇到“包录用、超快录用、代投代写”要远离并问导师 |

# 9. 对你这个方向最实用的判断方法

你将来最常碰到的成果描述，可能像下面这样：

> “我们准备向某医学超声期刊投一篇非线性传播建模论文；导师通讯，博士生一作，你负责复现仿真、参数扫描和结果图。”

把它拆开：

| 信息 | 你应该理解成什么 |
| --- | --- |
| 医学超声期刊 | 论文拟投的具体载体；需要查其研究范围是否匹配 |
| 非线性传播建模 | 研究主题与方法线索，不是评价等级 |
| 导师通讯 | 导师承担投稿沟通和学术责任，常见 |
| 博士生一作 | 博士生通常承担主要研究推进和论文初稿 |
| 你复现仿真、参数扫描、作图 | 清晰的潜在贡献模块；是否形成作者资格取决于工作实质与团队约定 |

再如：

> “某 IEEE 会议 EI 检索，二区。”

你不能只听到“看起来很厉害”，而应写出待确认项：

```text
1. 会议全称是什么？论文是全文还是摘要？
2. IEEE 是主办、出版还是技术支持？
3. EI Compendex 是否已经实际收录，还是仅计划送检？
4. “二区”是中科院二区还是 JCR Q2？哪个年度、哪个学科口径？
5. 我的学校/目标院校在保研或毕业评价时如何认定它？
```

这五个问题比背十个“论文等级”更像真正的科研判断。

# 11. 给你的行动建议：先做“会判断”的人，不做“会背名词”的人

在联系非线性声学与生物医学超声方向导师前，你不用承诺“我要发一区 SCI”。这句话既不具体，也不由你一个人决定。

更可信的表述是：

> 我已经区分了期刊、会议、数据库收录和分区评价，也读了一篇本组方向论文。我目前希望先从文献梳理、仿真复现或数据处理开始，建立可追溯的研究记录；请问组内更看重哪些基础能力，我该先补哪一项？

本周请完成以下三步：

1. 找到导师的一篇近年论文，按第 1 节的信息卡填出它的作者、期刊/会议、出版方、收录和分区信息；查不到的写“待确认”，不要猜。
2. 查阅你本校最新推免细则和你想申请院校的夏令营/推免通知，只记录原文明确写出的成绩、英语、科研材料与成果认定要求。
3. 选一个目标：保研、考研或暂未确定。无论哪一个，先保证课程成绩和英语，再把每周稳定的一段时间留给真实科研训练。

当你能向别人解释“这篇论文发表在哪里、谁出版、被谁收录、期刊属于哪个分区体系、我自己贡献了什么”时，科研最容易混乱的名词层已经真正打通了。
