# 智能门锁项目总览

> 西门子杯工业嵌入式赛道参赛项目。基于 GD32F4xx 平台，实现密码门锁系统，含按键输入、LCD 显示、舵机驱动、串口通信、RTC 时钟等功能。

## 项目架构

```text
┌─────────────────────────────────────────┐
│                  main.c                  │
│              初始化 + 调度器              │
└──────────────────┬──────────────────────┘
                   │ 轮询调度
    ┌──────────────┼──────────────┐
    ▼              ▼              ▼
┌─────────┐  ┌──────────┐  ┌──────────┐
│ key_app │  │ lcd_app  │  │servo_app │
│ 按键处理 │  │ 显示处理  │  │ 门锁执行  │
└────┬────┘  └────┬─────┘  └────┬─────┘
     │            │             │
     └────────────┼─────────────┘
                  │
         ┌────────▼────────┐
         │   event_bus     │  ← 全局事件总线
         │   模块间通信      │
         └─────────────────┘
```

关键设计：
- **按键模块**：底层扫描 → 消抖 → 事件枚举 → 对外输出事件（不直接控制业务）
- **显示模块**：读事件 → 刷新显示 → 写门锁命令（不直接调用舵机）
- **门锁模块**：轮询 door_cmd → 执行 Lock/Unlock
- **模块间通信**：通过 `event_bus` 全局事件总线，不互相暴露内部变量

## 关键技术点

| 技术点 | 说明 |
|---|---|
| 按键消抖 | 10ms 周期扫描，连续多次相同才认定稳定值 |
| 事件枚举 | 短按/长按/双击 → 统一事件枚举 → 业务层消费 |
| EventBus | 全局结构体 `g_evt`，模块间只通过事件通信 |
| DMA 发送 | USART0 DMA 异步发送，printf 风格格式化输出 |
| 调度器 | 时基中断只做 uwtick++，任务表轮询调度 |

## 项目文件结构

```text
Project/
├── main.c              # 主程序入口
├── scheduler.c/h       # 调度器（纯时基 + 任务表）
├── event_bus.h/c       # 全局事件总线
├── key_app.c/h         # 按键处理
├── lcd_app.c/h         # LCD 显示
├── servo_app.c/h       # 舵机/门锁
├── usart.c/h           # 串口通信
└── HardWare/           # 底层驱动
    ├── Key/            # 按键 GPIO
    ├── Lcd/            # LCD 驱动
    ├── Servo/          # PWM 舵机
    └── Usart/          # USART 驱动
```
