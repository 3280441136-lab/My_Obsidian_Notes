## 常用电容

### 电容的作用

电容本质上是"电压缓冲器"：

- 电压突然下降时，电容放电补一下。
- 电压突然上升时，电容吸收一下。
- 在电源电路中主要用于滤波、去耦、储能、降低纹波。

> 电容管电压突变——电压别想在我这儿跳。

### 常见电容类型

| 类型 | 特点 | 常见用途 | 注意事项 |
|---|---|---|---|
| 陶瓷电容 MLCC | 反应快、低 ESR、无极性 | 芯片去耦、DCDC 输入/输出高频滤波 | 大容量高耐压时实际容量会因直流偏压下降 |
| 电解电容 | 容量大、便宜、有极性 | 电源输入大缓冲、低频滤波 | 有正负极，耐压要留余量 |
| 钽电容 | 容量较大、ESR 较稳定 | 电源滤波 | 反接/浪涌容易损坏，初学慎用 |
| 薄膜电容 | 稳定、损耗低 | 高精度、交流、EMI 场景 | 体积较大 |

### 常用容值

| 容值 | 常见用途 |
|---|---|
| 10pF~100pF | 高频补偿、晶振负载、反馈前馈 |
| 1nF~10nF | 高频滤波、小信号滤波 |
| 0.1uF | 最常见芯片去耦电容 |
| 1uF | 局部电源滤波、LDO 输入/输出 |
| 4.7uF | 电源滤波、LDO 输出 |
| 10uF | DCDC 输入、LDO 输入/输出 |
| 22uF | DCDC 输出滤波 |
| 47uF~100uF | 电源入口大缓冲 |
| 220uF 以上 | 大电流、低频能量缓冲 |

### 常用封装

| 封装 | 尺寸 | 适合程度 |
|---|---|---|
| 0402 | 1.0mm × 0.5mm | 太小，新手不推荐 |
| 0603 | 1.6mm × 0.8mm | 常用，可手焊但偏小 |
| 0805 | 2.0mm × 1.25mm | 新手友好 |
| 1206 | 3.2mm × 1.6mm | 电源电容常用，手焊舒服 |
| 1210 | 3.2mm × 2.5mm | 大容量陶瓷常用 |

### 选电容的基本规则

- 普通芯片电源脚：每个电源脚附近放 `0.1uF` 陶瓷。
- 电源入口：常用 `47uF~100uF` 电解 + `0.1uF/1uF/10uF` 陶瓷。
- DCDC 输入：靠近芯片放 `10uF + 0.1uF` 陶瓷，入口可加电解。
- DCDC 输出：常见 `22uF × 2` 陶瓷。
- 耐压建议：
  - 5V 电源：电容耐压选 10V 或 16V。
  - 12V 电源：选 25V。
  - 24V 工业电源：陶瓷常选 50V 或 100V，电解选 35V/50V/63V。

## 常用电阻

### 电阻的作用

- 限流：LED 串联电阻。
- 分压：DCDC/LDO 反馈电阻。
- 上拉/下拉：给数字信号默认状态。
- 采样：电流检测采样电阻。
- 阻尼：串联在 SPI/I2C/高速信号上减小振铃。

### 常用阻值

| 阻值 | 常见用途 |
|---|---|
| 0Ω | 跳线、调试、可选连接 |
| 10Ω~100Ω | 信号串联阻尼、限流 |
| 220Ω~1kΩ | LED 限流，较亮 |
| 2.2kΩ~10kΩ | LED 限流、上拉/下拉 |
| 4.7kΩ | I2C 上拉常用 |
| 10kΩ | 最常见上拉/下拉 |
| 47kΩ~100kΩ | 低功耗上拉/下拉、反馈分压 |
| 1MΩ | 高阻输入、弱上拉/下拉 |
| 0.01Ω~1Ω | 电流采样 |

### 常用封装

| 封装 | 特点 |
|---|---|
| 0402 | 小，不适合新手手焊 |
| 0603 | 最常见，贴片密度适中 |
| 0805 | 新手友好 |
| 1206 | 功率稍大，手焊舒服 |
| 2512 | 大功率采样电阻常用 |

### 电阻功率估算

公式：

```text
P = I² × R
P = V² / R
```

例：5V 输出 LED，LED 压降约 2V，限流电阻 2.2kΩ：

```text
I = (5 - 2) / 2200 = 1.36mA
P = I² × R ≈ 0.004W
```

普通 0603/0805 足够。

## 常用电感

### 电感的作用

电感本质上是"电流缓冲器"：

- 不喜欢电流突然变化。
- DCDC Buck 中用于储能和平滑电流。
- LC 滤波中用于抑制电流纹波。

> 电感管电流突变——电流别想在我这儿跳。

### 常见电感类型

| 类型 | 用途 | 注意事项 |
|---|---|---|
| 功率电感 | DCDC 主电感 | 看电感值、饱和电流、DCR |
| 磁珠 | 高频噪声抑制 | 不是普通电感，常用于电源隔离/EMI |
| 共模电感 | EMI 滤波 | 常用于输入接口、通信接口 |

### DCDC 电感常用值

| 电感值 | 常见场景 |
|---|---|
| 1uH~2.2uH | 高频 DCDC、大电流低压 |
| 4.7uH | 常见 5V/3.3V 小电源 |
| 10uH | 常见 12V/24V 降压到 3.3V |
| 15uH | 24V 降压到 5V 常见 |
| 22uH~47uH | 较低频率或小纹波需求 |

### 选功率电感看什么

| 参数 | 意义 |
|---|---|
| L | 电感量，决定纹波电流 |
| Isat | 饱和电流，超过后电感失效、纹波暴涨 |
| Irms | 温升电流，决定发热能力 |
| DCR | 直流电阻，越低损耗越小 |
| 屏蔽/非屏蔽 | 屏蔽电感 EMI 更好 |

## 常用二极管

### 普通二极管 vs 肖特基二极管

| 类型 | 特点 | 用途 |
|---|---|---|
| 普通二极管 | 压降约 0.7V~1V，速度较慢 | 整流、防反接、低速保护 |
| 肖特基二极管 | 压降约 0.3V~0.6V，速度快 | 电源防反接、续流、DCDC |
| TVS 二极管 | 瞬态浪涌保护 | 输入口、通信口防浪涌/ESD |
| 稳压二极管 | 反向击穿稳压 | 简单钳位、保护 |

### 肖特基选型

看三个参数：

```text
反向耐压 VR ≥ 最高输入电压并留余量
平均电流 IF ≥ 实际电流并留余量
封装散热能力足够
```

例：24V 工业输入、最高 36V，防反接可选：

```text
SS56：5A / 60V 肖特基
```

SS56 不是唯一型号，只是常见、便宜、余量合适。

## LDO 原理与设计

### LDO 是什么

LDO 是线性稳压器。它像一个自动可变电阻，把输入电压稳成较低输出电压。

优点：

- 电路简单。
- 噪声低。
- 纹波小。

缺点：

- 效率低。
- 压差大、电流大时发热严重。

### LDO 效率

```text
效率 ≈ Vout / Vin
```

例：5V 转 3.3V：

```text
效率 ≈ 3.3 / 5 = 66%
```

24V 转 5V：

```text
效率 ≈ 5 / 24 ≈ 21%
```

所以 24V 转 5V 不适合直接用 LDO。

### LDO 发热计算

```text
P_loss = (Vin - Vout) × Iout
```

例：5V 转 3.3V，输出 200mA：

```text
P = (5 - 3.3) × 0.2 = 0.34W
```

例：24V 转 5V，输出 500mA：

```text
P = (24 - 5) × 0.5 = 9.5W
```

这会非常热，不适合。

### LDO 周边电路

常见连接：

```text
Vin —— 输入电容 —— LDO —— 输出电容 —— Vout
                       |
                      GND
```

常用配置：

- 输入电容：`1uF~10uF`。
- 输出电容：按数据手册要求，常见 `1uF~10uF`。
- ADJ 型 LDO：需要反馈电阻设置输出。
- EN 脚：高电平使能，低电平关闭。

注意：

- 输出电容类型和 ESR 要符合数据手册，否则可能振荡。
- LDO 输入必须高于输出至少一个 dropout 电压。

## DCDC Buck 原理与设计

### Buck 是什么

Buck 是降压型开关电源。它通过高速开关，把输入能量一份一份送入电感，再由电感和电容平滑成稳定输出。

核心结构：

```text
Vin → 开关管 → SW → 电感 → Vout
                       |
                    输出电容
                       |
                      GND
```

理想关系：

```text
Vout ≈ D × Vin
```

`D` 是占空比。

### Buck 常见引脚

| 引脚 | 含义 | 设计注意 |
|---|---|---|
| VIN | 输入电源 | 旁边必须放输入电容 |
| GND | 地 | 大电流回流，铺铜要好 |
| SW/LX | 开关节点 | 噪声大，走线短小，远离 FB |
| FB | 反馈脚 | 通过电阻分压检测输出 |
| EN | 使能脚 | 注意电压范围，不要乱接高压 |
| BST/BOOT | 自举脚 | 接小电容到 SW，靠近芯片 |
| COMP | 补偿脚 | 外接补偿网络，按手册设计 |
| SS | 软启动 | 接电容控制启动速度 |
| PG/POK | 电源良好信号 | 可接上拉给 MCU 检测 |

### Buck 为什么要算反馈电阻

芯片 FB 脚通常只认识一个基准电压，例如：

```text
Vfb = 0.6V / 0.8V / 1.25V
```

用两个电阻把输出电压分成 FB 电压：

```text
Vout → Rtop → FB → Rbottom → GND
```

公式：

```text
Vout = Vfb × (1 + Rtop / Rbottom)
```

意义：告诉芯片目标输出是多少。

### Buck 为什么要算电感

电感决定电流纹波。

纹波太大：

- 输出纹波变大。
- 发热增加。
- 可能触发限流。

纹波太小：

- 电感体积大。
- 成本高。
- 动态响应变慢。

常用设计：

```text
ΔIL = 20%~40% × Iout_max
```

Buck 电感公式：

```text
L = (Vin - Vout) × Vout / (Vin × Fsw × ΔIL)
```

电感峰值电流：

```text
IL_peak = Iout_max + ΔIL / 2
```

选电感时：

```text
Isat > IL_peak，并留足余量
```

### Buck 为什么要算输入电容

DCDC 从输入端取电是脉冲式的，输入电容负责就近供电。

输入电容不足会导致：

- 输入电压抖动。
- EMI 变差。
- 芯片工作不稳定。

常见做法：

```text
输入端：电解/固态电容 + 陶瓷电容
芯片 VIN 旁：10uF + 0.1uF 陶瓷
```

输入电容耐压：

```text
电容耐压 > 最大输入电压，并留余量
```

### Buck 为什么要算输出电容

输出电容决定输出纹波和负载突变时的电压跌落。

纹波估算：

```text
ΔVout ≈ ΔIL × (ESR + 1 / (8 × Fsw × Cout))
```

意义：

- ESR 越小，纹波越小。
- Cout 越大，纹波越小。
- Fsw 越高，所需电容可更小。

### Buck PCB 关键规则

| 规则 | 原因 |
|---|---|
| 输入电容靠近 VIN/GND | 缩小高频输入电流环路 |
| SW 线短、小 | SW 是高噪声高速跳变点 |
| 电感靠近 SW | 减小开关节点面积 |
| 输出电容靠近电感和芯片 GND | 降低输出纹波和回流阻抗 |
| FB 远离 SW/电感 | 避免噪声进入反馈 |
| GND 大面积铺铜 | 降低回流阻抗和温升 |

## 常见电源芯片外围电路

### 固定输出 LDO

```text
Vin → Cin → LDO → Cout → Vout
```

需要关注：

- 输入电压范围。
- 输出电流。
- dropout 电压。
- 输出电容要求。
- 发热。

### 可调输出 LDO

```text
Vout = Vref × (1 + Rtop / Rbottom)
```

需要额外关注反馈电阻。

### Buck DCDC

常见外围：

- 输入电容。
- 自举电容。
- 电感。
- 输出电容。
- 反馈电阻。
- 使能分压或控制。
- 补偿网络（若芯片需要）。

### Boost DCDC

Boost 是升压电源：

```text
低电压输入 → 高电压输出
```

常见外围：

- 电感。
- 肖特基二极管（非同步 Boost 常见）。
- 输出电容。
- 反馈电阻。

理想关系：

```text
Vout ≈ Vin / (1 - D)
```

### Buck-Boost

用于输入电压可能高于或低于输出电压的场景，例如电池供电。

设计复杂度比 Buck/LDO 高，新手优先使用成熟参考设计。

## 电源设计常用计算总结

| 计算 | 公式 | 意义 |
|---|---|---|
| 电阻限流 | `R = (Vin - Vf) / I` | LED、简单限流 |
| 电阻功耗 | `P = I²R` 或 `P = V²/R` | 判断封装功率够不够 |
| LDO 损耗 | `P = (Vin - Vout) × Iout` | 判断是否会发热 |
| LDO 效率 | `η ≈ Vout / Vin` | 判断适不适合用 LDO |
| Buck 占空比 | `D ≈ Vout / Vin` | 理解开关导通比例 |
| Buck 反馈 | `Vout = Vfb × (1 + Rtop/Rbottom)` | 设置输出电压 |
| Buck 电感 | `L = (Vin-Vout)×Vout / (Vin×Fsw×ΔIL)` | 控制电感纹波 |
| 电感峰值 | `IL_peak = Iout + ΔIL/2` | 选择电感饱和电流 |
| 输出纹波 | `ΔV ≈ ΔIL × (ESR + 1/(8×Fsw×Cout))` | 估算输出纹波 |
| 电容耐压 | `Vrated > Vmax` 并留余量 | 防止击穿 |

## 新手画电源板顺序

```text
1. 确定输入电压范围、输出电压、输出电流
2. 决定用 LDO、Buck、Boost 还是 Buck-Boost
3. 查芯片数据手册推荐电路
4. 按数据手册选输入电容、电感、输出电容、反馈电阻
5. 计算反馈电压、电感纹波、电感峰值、电容耐压、芯片发热
6. 原理图分模块画：输入保护、芯片主回路、反馈、输出、指示、接口
7. PCB 先摆功率器件，再走大电流线，再走反馈线
8. DRC/ERC 检查
9. 首次上电必须限流，先空载，再假负载，再接真实负载
```

## 记忆口诀

```text
电容管电压突变，电感管电流突变。
去耦 0.1uF 靠芯片，入口电解做缓冲。
LDO 简单噪声低，压差太大热得急。
Buck 高效省电，SW 短 FB 远铺地好。
数据手册是第一优先级，耐压电流余量不能少。
```
