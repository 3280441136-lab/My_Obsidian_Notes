## Buck 是什么

Buck 是降压型开关电源。它通过高速开关，把输入能量一份一份送入电感，再由电感和电容平滑成稳定输出。

核心结构：

```text
Vin → 开关管 → SW → 电感 → Vout
                       |
                    输出电容
                       |
                      GND
```

理想关系：

```text
Vout ≈ D × Vin
```

`D` 是占空比。

## Buck 常见引脚

| 引脚 | 含义 | 设计注意 |
|---|---|---|
| VIN | 输入电源 | 旁边必须放输入电容 |
| GND | 地 | 大电流回流，铺铜要好 |
| SW/LX | 开关节点 | 噪声大，走线短小，远离 FB |
| FB | 反馈脚 | 通过电阻分压检测输出 |
| EN | 使能脚 | 注意电压范围，不要乱接高压 |
| BST/BOOT | 自举脚 | 接小电容到 SW，靠近芯片 |
| COMP | 补偿脚 | 外接补偿网络，按手册设计 |
| SS | 软启动 | 接电容控制启动速度 |
| PG/POK | 电源良好信号 | 可接上拉给 MCU 检测 |

## 为什么要算反馈电阻

芯片 FB 脚通常只认识一个基准电压，例如：

```text
Vfb = 0.6V / 0.8V / 1.25V
```

用两个电阻把输出电压分成 FB 电压：

```text
Vout → Rtop → FB → Rbottom → GND
```

公式：

```text
Vout = Vfb × (1 + Rtop / Rbottom)
```

意义：告诉芯片目标输出是多少。

## 为什么要算电感

电感决定电流纹波。

纹波太大：

- 输出纹波变大。
- 发热增加。
- 可能触发限流。

纹波太小：

- 电感体积大。
- 成本高。
- 动态响应变慢。

常用设计：

```text
ΔIL = 20%~40% × Iout_max
```

Buck 电感公式：

```text
L = (Vin - Vout) × Vout / (Vin × Fsw × ΔIL)
```

电感峰值电流：

```text
IL_peak = Iout_max + ΔIL / 2
```

选电感时：

```text
Isat > IL_peak，并留足余量
```

## 为什么要算输入电容

DCDC 从输入端取电是脉冲式的，输入电容负责就近供电。

输入电容不足会导致：

- 输入电压抖动。
- EMI 变差。
- 芯片工作不稳定。

常见做法：

```text
输入端：电解/固态电容 + 陶瓷电容
芯片 VIN 旁：10uF + 0.1uF 陶瓷
```

输入电容耐压：

```text
电容耐压 > 最大输入电压，并留余量
```

## 为什么要算输出电容

输出电容决定输出纹波和负载突变时的电压跌落。

纹波估算：

```text
ΔVout ≈ ΔIL × (ESR + 1 / (8 × Fsw × Cout))
```

意义：

- ESR 越小，纹波越小。
- Cout 越大，纹波越小。
- Fsw 越高，所需电容可更小。

## Buck PCB 关键规则

| 规则 | 原因 |
|---|---|
| 输入电容靠近 VIN/GND | 缩小高频输入电流环路 |
| SW 线短、小 | SW 是高噪声高速跳变点 |
| 电感靠近 SW | 减小开关节点面积 |
| 输出电容靠近电感和芯片 GND | 降低输出纹波和回流阻抗 |
| FB 远离 SW/电感 | 避免噪声进入反馈 |
| GND 大面积铺铜 | 降低回流阻抗和温升 |

## 记忆口诀

```text
Buck 高效降压靠开关，SW 是噪声源，FB 是敏感点。
反馈电阻定电压，电感决定纹波大小。
输入电容就近供脉冲，输出电容平纹波。
PCB：SW 短 FB 远铺地大，数据手册是最高权威。
```
