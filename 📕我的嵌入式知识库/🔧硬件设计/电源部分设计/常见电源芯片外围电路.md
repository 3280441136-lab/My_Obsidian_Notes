## 固定输出 LDO

```text
Vin → Cin → LDO → Cout → Vout
```

需要关注：

- 输入电压范围。
- 输出电流。
- dropout 电压。
- 输出电容要求。
- 发热。

## 可调输出 LDO

```text
Vout = Vref × (1 + Rtop / Rbottom)
```

需要额外关注反馈电阻。

## Buck DCDC

常见外围：

- 输入电容。
- 自举电容。
- 电感。
- 输出电容。
- 反馈电阻。
- 使能分压或控制。
- 补偿网络（若芯片需要）。

## Boost DCDC

Boost 是升压电源：

```text
低电压输入 → 高电压输出
```

常见外围：

- 电感。
- 肖特基二极管（非同步 Boost 常见）。
- 输出电容。
- 反馈电阻。

理想关系：

```text
Vout ≈ Vin / (1 - D)
```

## Buck-Boost

用于输入电压可能高于或低于输出电压的场景，例如电池供电。

设计复杂度比 Buck/LDO 高，新手优先使用成熟参考设计。

## 记忆口诀

```text
LDO 外围最简单：两颗电容就搞定。
Buck 外围六件套：输入电容、自举电容、电感、输出电容、反馈电阻、补偿网络。
Boost 升压多颗肖特基。
Buck-Boost 电池专用，新手先用参考设计。
```
