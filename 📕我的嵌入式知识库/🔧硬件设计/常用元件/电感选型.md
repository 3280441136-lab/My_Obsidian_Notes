## 电感的作用

电感本质上是"电流缓冲器"：

- 不喜欢电流突然变化。
- DCDC Buck 中用于储能和平滑电流。
- LC 滤波中用于抑制电流纹波。

> 电感管电流突变——电流别想在我这儿跳。

## 常见电感类型

| 类型 | 用途 | 注意事项 |
|---|---|---|
| 功率电感 | DCDC 主电感 | 看电感值、饱和电流、DCR |
| 磁珠 | 高频噪声抑制 | 不是普通电感，常用于电源隔离/EMI |
| 共模电感 | EMI 滤波 | 常用于输入接口、通信接口 |

## DCDC 电感常用值

| 电感值 | 常见场景 |
|---|---|
| 1uH~2.2uH | 高频 DCDC、大电流低压 |
| 4.7uH | 常见 5V/3.3V 小电源 |
| 10uH | 常见 12V/24V 降压到 3.3V |
| 15uH | 24V 降压到 5V 常见 |
| 22uH~47uH | 较低频率或小纹波需求 |

## 选功率电感看什么

| 参数 | 意义 |
|---|---|
| L | 电感量，决定纹波电流 |
| Isat | 饱和电流，超过后电感失效、纹波暴涨 |
| Irms | 温升电流，决定发热能力 |
| DCR | 直流电阻，越低损耗越小 |
| 屏蔽/非屏蔽 | 屏蔽电感 EMI 更好 |
