## 电阻的作用

- 限流：LED 串联电阻。
- 分压：DCDC/LDO 反馈电阻。
- 上拉/下拉：给数字信号默认状态。
- 采样：电流检测采样电阻。
- 阻尼：串联在 SPI/I2C/高速信号上减小振铃。

## 常用阻值

| 阻值 | 常见用途 |
|---|---|
| 0Ω | 跳线、调试、可选连接 |
| 10Ω~100Ω | 信号串联阻尼、限流 |
| 220Ω~1kΩ | LED 限流，较亮 |
| 2.2kΩ~10kΩ | LED 限流、上拉/下拉 |
| 4.7kΩ | I2C 上拉常用 |
| 10kΩ | 最常见上拉/下拉 |
| 47kΩ~100kΩ | 低功耗上拉/下拉、反馈分压 |
| 1MΩ | 高阻输入、弱上拉/下拉 |
| 0.01Ω~1Ω | 电流采样 |

## 常用封装

| 封装 | 特点 |
|---|---|
| 0402 | 小，不适合新手手焊 |
| 0603 | 最常见，贴片密度适中 |
| 0805 | 新手友好 |
| 1206 | 功率稍大，手焊舒服 |
| 2512 | 大功率采样电阻常用 |

## 电阻功率估算

公式：

```text
P = I² × R
P = V² / R
```

例：5V 输出 LED，LED 压降约 2V，限流电阻 2.2kΩ：

```text
I = (5 - 2) / 2200 = 1.36mA
P = I² × R ≈ 0.004W
```

普通 0603/0805 足够。

```text
电阻四大用：限流、分压、上下拉、采样。
LED 限流 1k~4.7k，I2C 上拉 4.7k，普通上下拉 10k。
功率 P = I²R，算完再选封装。
```
