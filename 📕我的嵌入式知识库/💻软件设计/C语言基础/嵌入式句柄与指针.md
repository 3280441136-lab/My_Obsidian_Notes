## 句柄的本质

ESP-IDF 里很多 `handle` 本质上是**结构体指针的别名**。

可以理解成：

```c
typedef struct i2c_master_bus_t *i2c_master_bus_handle_t;
```

所以：

```c
i2c_master_bus_handle_t bus_handle;
```

本质等同于：

```c
struct i2c_master_bus_t *bus_handle;
```

人话：

```text
句柄就是一个指针，指向驱动内部维护的一个结构体。
你不需要知道结构体里面有什么，只需要拿着句柄调用 API。
```

## 创建 vs 使用：传参规律

这是新手最容易搞混的地方：

```text
创建句柄：传 &句柄变量    （函数要把创建结果写回你的变量）
使用句柄：传 句柄变量     （你告诉函数用哪个已创建好的对象）
读取配置：传 &配置结构体   （函数只需读配置，不需要修改它）
```

### 图解

```c
// 创建：第二个参数是 &bus_handle
// 含义：读取 bus_config，创建总线，把结果写入 bus_handle
i2c_new_master_bus(&bus_config, &bus_handle);
```

```c
// 使用：第一个参数是 bus_handle（没有 &）
// 含义：使用 bus_handle 这条已创建的总线，在上面添加设备
i2c_master_bus_add_device(bus_handle, &dev_config, &dev_handle);
```

```c
// 使用：第一个参数是 dev_handle（没有 &）
// 含义：使用 dev_handle 这个已创建的设备发送数据
i2c_master_transmit(dev_handle, data, sizeof(data), 1000);
```

## 以 I2C 为例走一遍

完整流程：

```c
// 第 1 步：声明句柄变量（此时值是无效的）
i2c_master_bus_handle_t bus_handle;
i2c_master_dev_handle_t dev_handle;

// 第 2 步：创建总线，&bus_handle 让函数把结果写回来
i2c_new_master_bus(&bus_config, &bus_handle);

// 第 3 步：在总线上添加设备
// bus_handle 没有 &：因为总线已经创建好了，直接使用
// &dev_handle 有 &：因为设备还没创建，函数需要写回结果
i2c_master_bus_add_device(bus_handle, &dev_config, &dev_handle);

// 第 4 步：用设备句柄收发数据
// dev_handle 没有 &：设备已创建好，直接使用
i2c_master_transmit(dev_handle, data, sizeof(data), 1000);
```

## 常见句柄类型速查

| 句柄类型 | 创建 API | 使用 API |
|---|---|---|
| `i2c_master_bus_handle_t` | `i2c_new_master_bus(&cfg, &handle)` | `i2c_master_bus_add_device(handle, ...)` |
| `i2c_master_dev_handle_t` | `i2c_master_bus_add_device(bus, &cfg, &handle)` | `i2c_master_transmit(handle, ...)` |
| `uart_port_t` | `uart_driver_install(port, ...)` | `uart_write_bytes(port, ...)` |
| `spi_host_device_t` | `spi_bus_initialize(host, ...)` | `spi_bus_add_device(host, ...)` |

规律是一样的：

```text
创建时传指针的地址（&handle），让函数填充
使用时传指针本身（handle），让函数使用
```

## void * 万能指针与 intptr_t

### void * 是什么

`void *` 是"万能指针"，可以临时保存任意类型的地址。

```c
void *arg;
```

它只表示"这是一个指针"，但不知道指向的具体类型。如果要真正使用里面的数据，必须转回原来的类型。

### intptr_t 是什么

`intptr_t` 来自 `<stdint.h>`：

```text
int      = integer，整数
ptr      = pointer，指针
_t       = type，类型
intptr_t = 能够安全保存指针值的整数类型
```

完整含义："integer type capable of holding a pointer"。

### 用途

在 API 只给了 `void *arg` 的场景，想传小整数时有用。

## 整数值塞进 void *arg

### 写法一：intptr_t 中转（常见但不推荐新手用）

有时 API 只给了 `void *arg`，但我们想传一个小整数，例如 GPIO 编号：

```c
gpio_isr_handler_add(GPIO_NUM_21,
                     gpio_isr_handler,
                     (void *)(intptr_t)GPIO_NUM_21);
```

中断里还原：

```c
gpio_num_t gpio_num = (gpio_num_t)(intptr_t)arg;
```

两边是对称的：

```text
发送时：gpio_num_t → intptr_t → void *
取回时：void * → intptr_t → gpio_num_t
```

为什么中间需要 `(intptr_t)`：指针和整数大小可能不同，`intptr_t` 是专门用于指针和整数安全互转的整数类型。

### 写法二：传地址（推荐新手用）

更直观的写法是传变量地址：

```c
static const gpio_num_t s_gpio_num = GPIO_NUM_21;

gpio_isr_handler_add(GPIO_NUM_21,
                     gpio_isr_handler,
                     (void *)&s_gpio_num);
```

中断里：

```c
const gpio_num_t gpio_num = *(const gpio_num_t *)arg;
```

含义分解：

```text
arg 是 gpio_num_t 变量的地址
先把 void * 转回 const gpio_num_t *
再用 * 取出里面的 GPIO 编号
```

这个写法更长，但更容易理解。

## 记忆口诀

```text
句柄就是结构体指针，藏起内部细节。
创建传 &句柄（要写回），使用传句柄（直接拿）。
配置结构体永远是 &结构体（只读不写）。
掌握这一个规律，所有 ESP-IDF 驱动都能看懂。
```
