# 双层 PCB 设计检查清单

## 原理图检查

- [ ] 电源输入、保护、滤波、去耦完整。
- [ ] MCU/FPGA 最小系统：供电、复位、时钟、下载接口、启动配置。
- [ ] 接口电平匹配。
- [ ] 连接器方向、引脚编号、封装一致。

## PCB 检查

- [ ] 电源线宽足够。
- [ ] 去耦电容靠近电源引脚。
- [ ] 关键信号线尽量短且路径清楚。
- [ ] 测试点足够。
- [ ] 丝印能帮助焊接和调试。
- [ ] DRC 通过。
