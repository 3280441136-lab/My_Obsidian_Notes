# 硬件调试入门检查清单

## 调试顺序

1. 电源：$V_{in}$、$V_{out}$、电流、短路、发热。
2. 复位 / 时钟 / BOOT：关键引脚状态是否正确。
3. 下载口：是否识别、连线是否正确。
4. 通信信号：UART/I2C/SPI 是否有波形。
5. 外设执行结果：LED、屏幕、电机、传感器数据。
6. 定位责任：原理图、PCB、焊接、代码、配置或测量方法。
