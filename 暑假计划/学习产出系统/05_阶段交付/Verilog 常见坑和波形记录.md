# Verilog 常见坑和波形记录

## 阻塞赋值与非阻塞赋值

- 组合逻辑中通常使用阻塞赋值 `=`。
- 时序逻辑中通常使用非阻塞赋值 `<=`。

## 待补充坑位

- [ ] 复位极性不统一。
- [ ] 状态机漏默认分支。
- [ ] 组合逻辑没有覆盖所有赋值，推导锁存器。
- [ ] 仿真通过但上板失败，没有考虑时序约束。
- [ ] 跨时钟域直接采样，没有同步或 FIFO。
