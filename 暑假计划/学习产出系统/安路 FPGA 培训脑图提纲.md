      - VGA显示原理
        - 行同步(HSYNC)/场同步(VSYNC)
        - 有效显示区/消隐区（前肩/后肩/同步脉冲）
        - 640×480@60Hz完整时序参数表
      - VTC视频时序控制器
        - 行计数器(0~799, 640有效)
        - 场计数器(0~524, 480有效)
      - 彩条测试图案生成
        - 8个竖条→红/绿/蓝/青/品/黄/白/黑
      - 上板验证
    - HDMI显示——TMDS编码与差分输出
      - HDMI vs VGA
        - VGA：模拟信号（需DAC芯片）
        - HDMI：数字差分信号（LVDS直出）
      - TMDS编码原理
        - 8位RGB→10位TMDS（减少EMI+嵌入时钟）
      - HDMI驱动模块
        - 3对差分信号(R/G/B)
        - 1对差分时钟
      - 上板验证
    - I2C协议与摄像头寄存器配置
      - I2C协议
        - 起始条件(SCL高+SDA↓)
        - 停止条件(SCL高+SDA↑)
        - 应答位(ACK/NACK)
      - SCCB vs I2C
        - OV5640用SCCB（兼容I2C）
      - I2C控制器状态机
        - IDLE→START→SEND_BYTE→WAIT_ACK→STOP
      - OV5640初始化序列
        - 分辨率640×480
        - RGB565输出
        - 30fps帧率
      - 竞赛前瞻：寄存器配不对→采集乱码
    - 摄像头DVP接口数据采集
      - DVP接口信号
        - PCLK（像素时钟，摄像头输出）
        - VSYNC（帧同步）
        - HREF（行同步）
        - DATA[7:0]（8位并行数据）
      - 时序解析
        - VSYNC拉高→新帧开始
        - HREF高→数据有效
        - 2个PCLK拼1个RGB565像素
      - 采集状态机
        - WAIT_VSYNC→COLLECT_LINE→WAIT_FRAME_END
      - 竞赛前瞻：数据采对→后续才有意义
    - 图像数据存储——SDRAM/DDR3缓存与乒乓操作
      - 为什么需要帧缓存
        - 摄像头PCLK与显示时钟不同域
      - DDR3/SDRAM控制器
        - 安路TD提供IP核，需跑通官方例程
      - 乒乓操作（Ping-Pong Buffer）
        - 写Ping时读Pong
        - 写Pong时读Ping→轮流切换
      - 缓存控制器设计
        - 读写地址指针
        - 帧切换逻辑
        - 读写仲裁
      - 竞赛前瞻：乒乓→AI加速器也复用
    - 以太网/UDP协议栈精简实现
      - 以太网基础
        - MAC地址(6B)/IP地址(4B)/UDP端口号(2B)
        - RGMII接口（4位数据+时钟）
      - UDP协议栈架构
        - MAC层（CRC校验+前导码）
        - IP层（首部组装/解析）
        - UDP层（端口识别+数据载荷）
      - UDP发送模块
        - UDP首部→IP首部→MAC首部→RGMII发送
      - UDP接收模块
        - MAC匹配→IP匹配→端口匹配→提取数据
      - 竞赛前瞻：2025年赛题以太网传输系统
    - 多模块数据流设计——AXI4-Stream
      - AXI4-Stream协议
        - TVALID（发送方数据有效）
        - TREADY（接收方准备好）
        - TDATA（数据）
        - TLAST（包结束）
        - TUSER（侧带信息）
      - 为什么用AXI4-Stream

      - 接口封装
        - 采集模块→AXI4-Stream Master

      - 竞赛前瞻：AXI4-Stream是工业标准（就业加分项）
    - 时钟域跨域处理——异步FIFO与复位同步

        - 三个不同时钟域
      - 亚稳态
        - 跨时钟域采样→建立/保持时间不满足
      - 异步FIFO
        - 写时钟域写入/读时钟域读出
        - 格雷码同步读写指针
      - 复位同步器

      - 状态观测点与GPIO调试
        - 关键信号→LED指示
      - 实战排错：摄像头无图像
        - I2C配置是否成功（读ID）
        - PCLK是否有信号
        - VSYNC/HREF是否正常
        - 数据线是否接反
      - 竞赛前瞻：调试能力是能完赛的分水岭

      - 资源报告解读
        - LUT（查找表）

        - BRAM（块RAM）

        - ≤80%（留余量）

        - 资源共享（多计算共用DSP）

        - 面积换速度vs速度换面积

  - 模块六：拓展拔高专项
    - 2026年赛题方向解读与系统架构
      - 2026年AI赛题三大方向（举例）
        - ①图像分类（CIFAR-10/MNIST）
        - ②手势/物体识别（轻量级YOLO）
        - ③语音指令识别（关键词唤醒）
      - 关键要求
        - LUT < 50k
        - 实时推理≥30fps
        - 保持较高准确率
      - 系统架构总览
        - 采集→预处理(缩放/灰度)→CNN加速器→结果→HDMI叠加标签
      - 目标网络选型
        - 3层卷积+2层池化+1层全连接（≈10万参数）
      - 开发流程总览
        - Python训练模型
        - INT8量化导出权重
        - 权重→BRAM初始化文件
        - Verilog实现加速器
        - 集成到模块五系统
        - 上板验证
      - 不推荐：YOLO/ResNet等大模型
    - 模型训练与INT8量化
      - 模型定义（PyTorch）
        - Conv1(1→16)→ReLU→Pool→Conv2(16→32)→ReLU→Pool→FC(3277→10)
      - 训练目标
        - MNIST准确率≥95%
      - INT8量化原理
        - q = round(float/scale) + zero_point
        - 节省75%存储空间
      - 量化实施
        - torch.quantization（PTQ）
      - 权重导出
        - .coe/.mem格式（每行1个字节十六进制）
      - 竞赛前瞻：逐层校准→提高准确率
    - 卷积层RTL实现
      - 卷积硬件映射
        - 3×3卷积=9次乘法+8次加法
      - 并行策略
        - 输入通道并行
        - 输出通道并行
        - 滑动窗口流水线
      - 滑动窗口生成器
        - 行缓存（Line Buffer）+ BRAM
